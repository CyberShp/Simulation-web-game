# 模拟仙府 · 余烬立山

单人 2.5D 仙侠经营 Web 游戏，EA 1.0.1。直接在浏览器游玩，无需账号或后端。

**在线游玩：[cybershp.github.io/Simulation-web-game](https://cybershp.github.io/Simulation-web-game/)**

你是栖霞沈氏遗孤沈砚：天资卓绝，炼气六层，父母以生命掩护你带走部分家传。先在云岫旧药庐养伤、救人、恢复生活，再调查灭门旧案、筹备筑基、削弱敌手，重返栖霞。第一大篇章有实际决战与结局，结局后继续经营。

## 这个 EA 可以玩什么

- **掌门**：玩家只直接控制掌门。行走、采集、修炼、研习、讲法、服丹、出行与战斗共用时间和精力。炼气至筑基后期；条件齐备可稳妥突破，也可选择有明确代价和失败后果的提前冲关。
- **门人**：自主工作、休息、学习、用膳、服丹、突破、游历与去留。志向、性格、能力、供给、关系和制度影响选择。玩家通过机会、沟通和邀请影响门人，不能强制派工或学习。
- **传承**：12 部主修/辅修功法，有真实来源、前置、熟练度、主辅修容量、相克、转修成本与授业条件。共同传承逐渐发展为不同峰的路数。
- **经营**：14 类建筑、4 种丹方、7 种资源，涵盖生活供给、维护、布局、通路、搬迁、修缮、坊市批量买卖与委托。保留掌门采集和交易等短缺恢复路径。
- **门派**：从共同山院到正式立派，再到两个方向不同的峰。主持、任职、拜师和同行需要能力与意愿；峰有实际预算、生产和传承效果。
- **门规与经历**：私取丹药、私阅典籍与违约外出可能发生，发现后才公开证据。处置影响公平感、关系、意愿与长期记忆；人物支线、来客、师徒和同门关系各有有限的可完成内容。
- **山外**：9 个地区，可靠调查路径、天气影响、经营准备、主动移动和范围战斗、预警、守御、闪避、撤离、伤势恢复与两种篇章结局。
- **界面**：青绿山水、宣纸和篆印风格，地图、管理抽屉、人物档案、任务指引、禁用原因、视听开关、大字与减少动态设置；音乐和音效各自可调音量。

## 存档与续玩

开启网页后选择三个世界档位之一。每 5 秒、重要操作和切到后台时尝试保存；下次选择「继续修行」即可恢复最后成功保存的进度。关闭期间不推进游戏。

每档保留最近三份有效备份；恢复、导入和旧档迁移会保留被替换的原文。支持 v1–v4 迁移、完整 JSON 导出/导入（最大 2 MiB）、损坏档案恢复资料导出。所有复杂活动、人物经历、随机种子和已决定结果均进入存档。

存档属于**同一设备、浏览器和网站来源**。没有账号云同步；换设备须导出后导入。清理网站数据或无痕模式可能影响保留。存储被禁用、已满或冲突时显示失败并暂停，不冒充保存成功。使用 Web Locks 实现同档单写者，另一窗口可请求接管；不支持安全写锁的浏览器只读，提供明确的内存试玩与文件导出。

## 操作

- 地图拖动平移，滚轮或 `＋ / −` 缩放；营造后点空地安置，点建筑查看详情。
- 掌门行走模式点地移动，或使用 `WASD / 方向键`。
- `空格` 暂停或继续，`Esc` 取消营造或关闭弹窗。
- 战斗点击敌人攻击，点击地面移动；`J` 攻击、`K` 术法、`L` 闪避、`H` 守御、`R` 撤离。手机可用画面按钮。
- 管理抽屉可收起；弹窗、后台和只读状态不推进模拟。

## 开发与验证

无构建依赖。用静态服务器提供 `dist/`，不要直接双击 HTML：

```sh
python3 -m http.server 8080 --directory dist
node --test tests/*.test.mjs
node qa/ea-ui-smoke.mjs
node qa/ea-normal-play.mjs --reference
node qa/ea-long-session.mjs
```

当前入口是 `dist/ea-game.mjs`。核心数据、模拟、社会、篇章、存档、UI、绘制各自分模块；旧模块保留用于旧档迁移与回归，不是新版的第二套计时循环。

完整需求见 [EA-ROADMAP.md](docs/EA-ROADMAP.md)，故事基线见 [EA-DESIGN.md](docs/EA-DESIGN.md)，实际证据和未测项见 [EA-ACCEPTANCE.md](docs/EA-ACCEPTANCE.md)。公开操作驱动从普通新档通关、立派、分峰，并构建 30 门人 / 40 建筑参考世界；长模拟与真人会话明确区分。

## 发布

GitHub Pages 使用 `gh-pages` 分支根目录。`qa/prepare-release.py --tag <版本>` 输出附统一缓存版本号的静态文本树；图片沿用 `dist/assets/`。`--preview` 可产生隔离的 `ea-preview/` 测试目录。主仓库 `dist/` 使用原始相对模块引用，便于本地运行和测试。

本版是有完整可玩循环的 EA，内容模板、后期消耗和平衡仍需真实玩家反馈。没有多人联机、账号云存档、离线结算、无限生成故事或无限规模宗门。iOS/Android 真机生命周期、数小时真人会话和朋友盲测尚未完成，不能以逻辑测试代替。

仓库不包含服务器凭据、生产用户存档或个人平台数据。本次发布只使用 GitHub Pages。
