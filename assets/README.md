# 游戏素材

- `courtyard/`：当前桌面山院实际使用的底图、人物和东台图层。
- `web/`：现有网页运行素材，构建后保持原 `assets/` 地址。
- `manifest.json`：原有素材来源记录；文件迁移不改变作者或许可。

当前山院图稿与来源提示见 [山院母稿](../docs/art/pixel-courtyard-prototype-20261014/README.md)及 [像素素材记录](../archive/prototypes/pixel_scene_validation/assets/prompts.md)。第三方字体和库的许可随源文件及构建产物保留。设计参考稿仍由 `docs/art/` 管理；运行时只依赖本目录和明确登记的网页资源。
