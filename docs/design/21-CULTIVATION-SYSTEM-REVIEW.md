2026-10-11 作者方案。承接[五洲修行谱](19-FIVE-CONTINENT-ARTS.md)、[现行数值首稿](20-ARTS-GROWTH-COMBAT.md)、[人物](01-CHARACTERS.md)、[运行时](05-RUNTIME-CONTRACTS.md)、[危机与死亡](10-CRISES-RESCUE-DEATH.md)及[五洲修炼地评看稿](22-WORLD-CULTIVATION-SITES-REVIEW.md)。用户已确认严格区分普通技法与改写局部规则的神通，并确认世界天然修炼地点与适配营造点的方向；其余细目仍供评看，尚未替换 U-114/R-37 的正式配额与数值，也未改游戏行为。四千九百种仍按**每项可独立修成的内容计一次**；神通虽不能像剑谱一样直接教会，仍可作为一项可独立参悟、修成的内容计数。

## 一、心法是宗门经营的根基

主修心法定义一名修士怎样吸纳、储存和运转力量，以及突破时怎样重塑功体；招式、术法和神通各有自己的学习状态。心法定义至少包含：功体倾向、当前境界可练篇章、可支持的突破境界、成长倾向、灵力容量与回复、寿元与抗性底色、必要供给、最适地点／时段、环境风险、转修和授业条件。相容辅修只补一项明确能力，不能把多个主修的完整成长向量相加。

人物成长建议分成五个可见方向：**体魄**（气血、负伤承受）、**灵力**（容量、回复）、**神识**（控制、辨识）、**身法**（移动与反应）、**道法**（施术精度与环境感应）。境界提供主要台阶；资质影响学习与吸纳；长期实际修行形成这五向的功体印记；当前心法与身体状态决定这些印记如何发挥。每部心法须给出有偏有缺的成长向量，不用“全属性更高”区分好坏。换主修保存已经形成的个人成长和知识，但需要真实调息、身体适应与相容性检查；突破所得的功体倾向按此前实际修行形成的印记计算，不能靠突破前一刻换心法拿另一套永久成长。这是成长来源的记账，并非给所有境界新增统一的悟道门槛。

心法的日常修行应具体占用山院的土地、工位、材料和时间。下表是需求机制示例；五行、鬼道、妖道、魔道及远古道痕的地点谱系另见[五洲修炼地](22-WORLD-CULTIVATION-SITES-REVIEW.md)：

| 心法需求 | 世界中的供给与容量 | 经营后果 |
| --- | --- | --- |
| 灵脉、灵石 | 有位置和强度的灵脉点；灵石按来源与库存消耗 | 静修位可预约，集中修行会争用灵脉及采购预算 |
| 丹药 | 可获得的配方、实物、炼制工位与服药间隔 | 丹房和药田成为修行供给；药力与毒性不能被反复服用绕过 |
| 地火、寒潭 | 实际可到达的热源／寒源和安全练位 | 同属门人争位置，需营造、维护与轮班；离场只有基础修行效率 |
| 日精、夜修 | 当地时辰、天气和可到达的采光／阴地 | 门人日程改变，夜修牺牲睡眠或白日工作时间 |
| 煞气等危险媒介 | 可追溯来源、收容位置、防护与排浊手段 | 魔道心法有可用路线，也带来伤势、环境和关系成本 |

建议用`有效修炼量 = 基础练习量 × 资质适性 × 场所／时段契合 × 供给完整度`作为调参起点，场所／时段合计修正先约束在 `0.5–1.35`，并分别记实际材料消耗与危险；某些突破篇章可要求特定地点或媒介。基本练习与高效练习应有不同门槛，避免一个地火位缺席就让门人永久停摆。例：八名火修每天各需一个地火时段，若两处地火位每天各可安全开放四个时段，正好满负荷；第九人要等待、改日程或另建练位。这些时段只是容量例，具体世界步与工期须实机调校。

火倾向可增加耐热与爆发，道法强而回气慢；水倾向可加快回复与潮湿地感应；它们仍能跨行学技。心法带来的寿元以当前大境界寿限为基座，普通心法差异先小于一成；真正延寿须有独立资源、风险和可追溯效果。心法不能凭名字让人物直接获得火球、飞剑或护身动作。门人会因志向和自身条件选择心法，掌门通过建位、预算、藏经与导师影响可行选择，而不直接替每个人点技能。

## 二、战斗技的分类看施展依赖

**武学与术法保留为目录入口，动作机制允许交叉。** 武学的核心是身体或真实兵器的轨迹、力道、招架和站位；术法的核心是灵力塑形、媒介、术式与环境过程。持剑施法可以同时有两种标签，但每个独立可学动作仍只占一个目录号。`是否要兵器、是否要手印、能否被缴械、距离、命中方式、物理／术法份额、环境媒介`由动作逐项声明；伤害通道不从目录类型自动推定。术法可以有瞬发篇，武学也可以有蓄势篇，施展快慢不足以划分类别。

| 例子 | 目录归类建议 | 实际结算与反制 |
| --- | --- | --- |
| 长虹贯日 | 剑武学，可能带灵力贯注标签 | 真人持剑疾刺；位移与刺击占真实路径，伤害可由兵器、体魄、灵力和熟练共同构成，再按物／法份额过抗性。拦路、逼停与缴械有效 |
| 万剑朝宗·御真剑 | 御剑武学与阵列标签 | 需要多柄有归属和位置的真实飞剑；共享一次动作的目标、总伤害预算和灵力，剑可被拦截或损坏 |
| 万剑朝宗·凝剑影 | 术法与剑形标签；与御真剑是不同教法时才单列 | 灵力凝成剑形，无实剑库存；打断塑形、法抗及破坏媒介有效，不借真实兵器额外领取伤害 |
| 冰剑砸落 | 凝出巨冰剑为冰术法；给实剑覆冰并投掷为复合战技 | 冰剑有生成时间、体积、落点与遮挡；冲击伤害和寒滞积累分别结算。冰剑形状不使其自动变成武学 |

战技原始效果由**境界基础、动作系数、实际兵器／媒介、人物相关成长、理解与熟练、场景条件**共同决定。伤害可以含相对固定的破甲量、力量加成、灵力加成与异常积累，但每项说明自身来源和上限；“冰+剑”只增加一次可学动作，不能将两套满额输出简单相加。战斗中先走空间和动作校验，再按该动作声明的物／法份额及异常积累结算。旧数据中的`武学/术法`主类型和 4900 配额暂保留，待这套动作字段与具体目录统一后再定稿分类预算。

## 三、神通由道而生，改写一条局部规则

神通与战技的分界建议采用**效果机制**：常规武学、术法在既定命中、位置、伤害和状态规则内运作；神通临时改写一条经过白名单声明的局部规则。神通可被导师指引、典籍启发和前人印证，最终必须由人物自己的功体、经历与实践修成；得到卷册不会直接获得按钮。修成状态、来源、触发条件与代价仍属于同一人物档案。视觉上的不念咒、不结印可作为表现，但不能成为唯一判据：神通仍有可观察征兆和真实起效时刻。

六个机制方向为：**结算路径**（伤及血、灵力或心神）、**命中条件**（预留剑痕、已标记目标）、**时间**（延迟、预记伤）、**空间**（领域、回环、换位）、**承伤者**（有条件转移）、**行动权**（限制特定动作）。改变哪一环、改多久、影响谁、是否波及友方、如何破除和结束后如何恢复，必须逐项写。绕开物抗时仍要有另一个明确抵抗或中断途径；局部免疫须有时长、空间或通道限制。任何神通都不能改写已经提交的死亡事实、凭空制造傀儡、装备与符箓，或越过同一世界步的动作和存档顺序。

### 神意：战斗中的一次转折资源

建议战斗神通共用该人物一条 `0–100` 的神意槽；一次发动消耗 100，同一真实战斗会话通常至多发动两次，读档、切镜头或暂退不能重置已用次数。不同道途用不同**有效行动**积累同一槽：剑修命中且承担近战风险、符修实际消耗有归属的符箓、五行修士在相应环境中成功完成相关动作、魔修承受敌方造成的真实伤害或完成排煞、鬼道在阴地完成施术或感应一场真实事件。自伤、反复打空招、焚烧廉价符循环和原地等待不产生可刷取的神意；有人身死的事件以死亡记录 ID 只算一次，也不能通过牺牲同伴无限充能。途径、单次收益和环境加成按道途调参，环境单独供能设上限。NPC使用同一规则。

神通可以没有传统读条，但要在效果前显露剑鸣、阴风、符纹等可观察征兆。现行世界小步约为 0.1 秒，提前一个小步不足以构成真实反应机会；主动神通首轮建议给同境对手约 0.6–1.2 秒的可辨征兆，或者一个足以完成既有反制动作的完整窗口。征兆开始、神意扣除、反制成功、效果生效各有唯一时刻；假如对方没有合适手段，看到征兆也不等于必然能闪开。境界、距离和先手可改变窗口，具体时长须以实机操作校准。预先布好的被动替身也须在布设时付真实时间和资源。神意只管理战斗神通的发动节奏；常驻身体变化或修行获得的非战斗能力由其自身条件管理，不强塞进战斗槽。

### 对示例的首轮处理

先用一个严格判据排除“名字大、特效大”的普通招式：若效果仍可用现有命中、物／法伤害、异常积累和有时限的地面效果结算，就归武学或术法；只有确实改变目标、承伤人、结算时刻、路径连通或行动许可等公共规则，才归战斗神通。下表名称均为暂拟，不登记为新目录 ID；它们是机制检查样例，不能因列在表中就计入已写成的六十七种。

| 道途 | 样例与可保留的机制 | 必须写进正式定义的边界与反制 |
| --- | --- | --- |
| 剑 | 斩念：剑击转为心神积累；剑痕：斩痕短时成为危险地形；归鞘：停手换近身反斩 | 心神抗可抵抗斩念；剑痕有可见位置并伤及友方；归鞘只回应近身实际来袭，远术与等待可破 |
| 魔 | 蚀骨：短时压低生命上限；同殇血契：已命中的血印转移后续外来伤；魔躯不倒：死亡判定前短时濒危行动；心魔牢：限制一人的行动权 | 蚀骨走血损／净化，伤害上限与治疗路径明确；血契限比例、范围和次数，双方不得反弹递归，自伤不转嫁；魔躯不倒在死亡事务前触发并持续恶化，结束仍逐人判死；心魔牢经心神抗性检验且可由同伴救出 |
| 鬼 | 摄魂：改打神魂；阴身：短时避开实体兵器；鬼打墙：改区域通路 | 摄魂受神魂防护且对无魂实体无效；阴身仍受术法、阳火和锚定作用；鬼打墙有可抵达并可破坏的锚点，不改变世界实际坐标或制造第二身体 |
| 傀儡 | 偶替：预置傀儡代承一击；牵丝：暂夺物件控制；千机同发：多偶同步攻击 | 替身是附近实际傀儡，先于死亡判定换位并承担损毁；牵丝可见、可斩且受神识抗，牵动真人肢体只在有限抵抗后成立；同发占一次动作预算，偶可分别被遮挡或拆除，收势统一延长 |
| 符 | 万符同燃：实有符箓一次发动；符记伤：将一部分伤害延迟记账；画地为牢：以可见地符限制站位 | 每张符真实耗尽且群发有总预算；记下的伤不会因提前治疗空血而消失，符破时依序结算；地符有起手、范围和可踏出的时间窗 |
| 金、木 | 断法：切断有实体或持续灵路的术法造物；种魔藤：命中后形成渐进束缚 | 断法需击中可辨的术法结构，不能一句“断法”废除所有心法；藤受心法抗性与清除动作约束，火或静止可抑制生长 |
| 水 | 柔水化劲：把一次重击拆成若干有期限的承伤；玄冥重水：局部减速逐次累积 | 化劲保存未结清伤害和来源，分期仍可致伤；重水积累有上限、地形和移出办法 |
| 火、土 | 业火焚元：燃烧灵力回复；镇岳：封锁地面范围内的身法／遁法；石化金身：短时不受普通打击但本人也无法行动 | 焚元可断火、撤出及恢复；镇岳留普通步行与空中路径，有锚点可破；石化有明确短时、解除代价和任务时钟，封印／搬离等非伤害手段仍成立 |
| 体、兵家 | 法天象地：暂改体型、占地和攻击范围；同袍：自愿成阵者分担伤害 | 巨化更新碰撞与通路，也增加被范围术法命中的风险；分伤写入每个人真实伤势，不能把一人死亡平均成无人死亡 |
| 毒、妖 | 万毒归一：消耗目标已有的异常积累并引爆；本相：切换妖身可用动作 | 引爆不自产异常，逐类核对抗性与上限；本相保留同一人身份、位置和已学知识，换的是身体可执行的行动，不抹除原本修为 |

按此判据，**斩念、心魔牢、种魔藤、玄冥重水、业火焚元、画地为牢、万毒归一**目前描述的是异常、控制、地面效果或组合引爆，优先写成武学／术法；仅凭伤害目标特殊或效果华丽，不占神通目录。这不删掉玩法，只是将学习来源、神意消耗和结算路径放在适合的位置。**剑痕、法天象地、本相**还要看最终具体规则：普通危险地形、体型增益或妖身变化可由常规技实现；若进一步改变碰撞、行动栏或真实路径，才有神通版本。**归鞘、同殇血契、偶替、千机同发、万符同燃、符记伤、柔水化劲、鬼打墙、镇岳**则有较清楚的反应次数、承伤人、时序或空间改写价值；其余逐项以同一判据裁定。这意味着现行“神通 400 种”仍是规划预算，不能拿普通术法硬凑数量。

真正的神通价值在于改变问题，而非把常规伤害乘以更大的数。现行[20号稿](20-ARTS-GROWTH-COMBAT.md)的五品“熟练收益固定 6%–20%”与规则改写不能直接等价，须随下节一并改写；具体同境价值要用目标完成、反制成本、资源和再用间隔校准。20 号稿的总减伤 80% 上限继续约束普通抗性和护持；阴身、石化金身等若允许短时免疫一个伤害通道，属于待确认的**条件性规则例外**，须以失去行动、暴露其他通道、持续时间和破除手段换取，不能叠成全伤害免疫。境界差仍是力量边界，较低境界的奇招可以争取撤离或破局，不能常态消掉大境界差。

## 四、两种战术阵法

| 形式 | 成立条件 | 效果与失败 |
| --- | --- | --- |
| 个人布阵 | 一人学会阵图，到实际地点勘地；阵旗、阵盘、石材或天然阵眼有归属、位置和耐久；需要布设时间 | 能守窄路、预警、护持或改变局部通路；离开阵眼、拔旗、断供或改地形后衰减。阵图知识属可学项目，实物旗不是额外功法 |
| 多人结阵 | 至少两人自愿同意、理解同一阵图及各自站位；有可达队形和共同起势时间。三才阵必须三人 | 不必用道具；提供小幅攻、防、机动协同，例如首轮各方向约 5%–8%，由阵员共同占用维持精力。缺人、破位、距离拉开或意愿改变便失衡；不把多个人的修为加成一个人越境力量 |

护山大阵是长期工程：固定地形、阵基、维护人、供能与权限仍由宗门建造和经济系统记录。它可以使用与个人阵相同的原理，但其建筑实例、覆盖范围和维护账本是另一层事实。阵法项目按**独立阵图／结阵法**计数一次；同一三才阵中的天、地、人三个岗位是该阵的角色训练，不自动拆成三种。若某一岗位后来形成可独立授业、独立使用的招式，才另列项目。运行时队员仍各有一具身体和自主决定；掌门只能邀请、约定战术及控制自己。

## 五、品级改为多轴描述，境界跨度另记

建议重新定义“品质”。现行 20 号稿把一品至五品直接映射到熟练后的固定百分比，适合首轮试算，却无法解释一门筑基期极强但金丹无续篇的法门，也不能解释稀有的炼气至渡劫一脉相承。新模型把下列维度分开：

| 维度 | 表示什么 | 玩家看得见的区别 |
| --- | --- | --- |
| 品相 | 本门在适用境界中的结构、稳定性、战术或经营价值；仍可用一至五品表达 | 高品可能更精密、更省损耗或有额外机制，不能简单读成同境固定增伤 |
| 境界跨度 | 实际有可靠篇章支持到哪一境，某些阶段是否出现新特质 | 筑基止步的心法不能靠原卷提供金丹突破；高境界使用低境界招式可能只剩基础用途 |
| 篇章完整度 | 人物实际取得并理解的篇章、残缺与版本可靠性 | 传承本可到渡劫，手上只有炼气篇时仍须寻找后文、师父或校勘途径 |
| 契合与代价 | 个人体质、其他主辅修、地点、时辰、媒介、转修成本 | 同一法门对不同人、不同山院产生不同效益；无供给时收益下降或出现伤势 |
| 流传稀度 | 哪些组织掌握、谁愿意教、是否能买到完整版本 | 稀有不自动更强，普及入门法仍有可靠来源 |

每部心法声明`minRealm / supportedThroughRealm / chapterByRealm / growthProfile / supplyProfile / newTraitsByRealm`。在已支持境界内有自身效果曲线；到上限后知识仍在，基础招式可能继续能用，但主修无法据它取得下一境的突破篇章，相关攻击也会因敌方境界和防御提高而失去主力价值。人物可转修有金丹篇的高阶心法，保留原来的理解、关系和练习经历，实际调息重建功体；转修风险与可回头途径预先可见。

贯穿炼气至渡劫的绝顶传承应是少数完整谱系：同一个`artId`跨境，**每到新境才解开相应篇章与特质**，不是炼气拿到全效果。谱系本身仍需真实载体、名师、机缘与高境界资源；一部心法的跨境跨度不能替它的攻防技自动升级。为控制目录膨胀，续篇不另计一种，真正独立的剑式、术法和神通仍各自计数。绝顶法门的具体数量、名字与真相卡待总目录逐项创作时确定，先不将“稀有”强行等于五品。

## 六、正式定稿前的核对

本稿建议先以青岚主修、赤嶂重刀、石桥水术、个人护脉阵和三人三才阵制作五条完整样例：每条写取得、所需山院供给、炼气与筑基成长、动作前置、同境对手、反制、转修／伤势、存读；再用一门筑基止步心法和一门多境界传承检验品级与篇章规则。神通先从剑痕、偶替、柔水化劲、魔躯不倒四例做结算顺序审阅，尤其检查空间、承伤记账与永久死亡。完成评看后再调整[19](19-FIVE-CONTINENT-ARTS.md)的类型预算、[20](20-ARTS-GROWTH-COMBAT.md)的数值、决策登记与 SR-XF-013/014；本稿不把建议直接记成用户确认或游戏已实现。
