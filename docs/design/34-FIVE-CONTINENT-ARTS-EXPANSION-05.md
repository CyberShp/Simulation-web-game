# 五洲修行谱 · 扩写第五批：五行与兵器交融

2026-10-11 作者评看稿。接续[五洲修行谱](19-FIVE-CONTINENT-ARTS.md)、[修行成长与斗法](20-ARTS-GROWTH-COMBAT.md)、[修行体系评看](21-CULTIVATION-SYSTEM-REVIEW.md)、[扩写总账](28-FIVE-CONTINENT-ARTS-LEDGER.md)与[首批逐项复评](33-ARTS-INITIAL-CALIBRATION.md)。本稿登记 `Y-235–272` 三十八项可独立学习内容；`Y-228–234` 属于[五条入门传承](32-OPENING-INHERITANCE.md)。本稿的地名、持有人、篇章和机制仍待评看、作者卡与实际地图校准，尚未接入游戏或存档。

`炼／筑／丹／婴／化`分别指炼气、筑基、金丹、元婴、化神；境界范围表示该门拟有可靠篇章支持到的上限，并非持有人已经取得全本。每项只有一个主类型；续篇、实物、阵位和熟练阶段不再占号。心法提供功体与成长取舍，攻击和护持须另学；复合动作只按一次行动预算结算。下表每行都给出一条独立用途、具体接触路径、练习供给、失效条件与授业边界。地点名均为待落图的作者提案。
