# 设计决策登记

设计编号：DB-2026-10-05；版本：1.2。与 [统一基准](00-BASELINE.md) 一起读取。v1.1根据最新用户指令修订NPC死亡边界；历史v1.0不再覆盖该规则。

## 状态与使用方法

- `user-confirmed`：用户明确表达、或本次重申的方向。后续模型不能自行改动。
- `recommended`：本版设计建议。它是可实施的默认方案，但不能汇报为用户逐项批准；用户可调整。
- `tunable`：数值、体量与节奏起点；必须用平衡/体验数据调整，不能暗中改变规则含义。
- `deferred`：明确后置，初版不依赖它完成核心循环。

模型不得把自己的偏好添加为user-confirmed。改变状态需要明确来源、理由与受影响的文档/数据/验收；新增用户指令优先于本表。
