## 1. 容量、身份与玩家目标

- 第一篇章在籍门人上限为十五人，`person:master` 不占名额；离宗或身死后释放在籍名额，可继续招收新成员。
- 可收录人数受十五人上限、现有住居、基本供给、组织阶段、相关道具与布局的正式容量约束；修炼位和工位另按实际可用量显示，不把每人都须占高级练位当作入门条件。
- 十五是同时在籍容量，不是剧情要求、保底招募数或预制的十五个角色；少人山院仍可凭专业分工、掌门行动和外部合作推进篇章。
- 访客、短期帮工、受托商旅与外部盟友保持各自关系和所属；实际占用床位、工位、库存与时间仍计入相应服务负荷。
- 门籍人数由正式成员关系派生；外出随行仍占在籍名额，离宗及身死才释放名额，失踪在确认离宗或死亡前不被提前当作空位。
- 在籍空席以正式注销记录产生：自愿离宗当场登记；死亡先按世界事实停止身体活动、释放工位，可靠死讯到达后注销门籍。死讯未明时仍显示失联并暂占席，不能通过容量突变泄露远方死亡；玩家可通过回访、证人或遗物查证后完成注销。
- 人物注册表保存每个出现过的人的唯一 `personId`；名额释放不复用旧 ID，不删除其经历、关系、师承、物品归属和死亡事实。
- 旧档若已有超过十五名门人，先原样保留全部旧成员与既有关系；在籍数回到上限以下前暂停新增收录，不自动逐人除籍。
- 容量变化不会让现有门人突然消失；住居或供给损坏进入可见的安置、修复与协商流程。
- 玩家直接操控掌门；门人是否工作、学法、服丹、任职、拜师、归峰、同行与离宗，仍按本人情况作决定。
- 新档第一篇章本宗人物最高成长到金丹初期；高境界旧档继续保留原有境界与进度，不以新范围反向降境。

## 2. 随机求道者从哪里来

| 来源 | 玩家怎样接触 | 生成与机会约束 |
| --- | --- | --- |
| 山门求见 | 山院安全、公开接待条件和传承消息吸引来客 | 来客真正抵达山门才成为可交谈的人，不凭菜单刷新候选 |
| 坊市与委托 | 交易、救治、护送或完成公开委托结识个人 | 双方经历形成关系；受助并不自动转为求徒 |
| 山谷与驿路 | 实际旅行、观察、同路行动中遇见有目标的人 | 遭遇保存地点和时间，同一人重逢沿用原身份 |
| 熟人引荐 | 已认识的人愿意向另一人传递消息 | 引荐提供一次可追踪接触，后续仍需到场、条件与本人意愿 |
| 共同危机 | 避险、救援或守护中的相识 | 人物先有自己的安置需要，不能把获救者直接写入门籍 |

- 各来源由当前世界事实触发：可达路线、公开名声、已知关系、真实委托与接待容量影响出现机会。
- 基础山门求见与可达坊市承担可靠补招来源；随机顺序、候选个性和到访时间可变化，不能因一次坏抽取永远缺某项必需人才。
- 候选在首次成为世界人物时一次生成并存入人物注册表；到访、对话、拒绝、离开和再次相遇只更新其状态。
- 候选未到场时可保存有来源的邀约或引荐，不提前向玩家展示完整属性和秘密。
- 候选总数可由世界时间、路程和接待机会调节；候选离开后不会因关闭卷册又立刻换一个人占同一脚点。
- 同一来源人物可以选择不求见、不入宗或稍后再来；可靠补招指持续存在的社会途径，不保证每名来客同意。
- 商人、药师、阵匠等可靠服务可用委托与雇约取得；主要进度不能依赖从随机池抽中唯一技能组合。

### 2.1 生成后固定的资料

- 注册时分配不可复用 ID，保存生成来源、专用随机流位置或种子、姓名与别名、出身、年龄阶段、基础灵根、可见外观配方。
- 同时保存修行适性、悟性、已有技能、志向、性格倾向、既有关系、真实经历与个人知识；表面自述和实际事实分开。
- 生成条件受来源和地区影响，例如坊市学徒较可能已有手艺，山谷采药者较可能识草；这只改变起点分布，不保证身份或能力。
- 外观在肖像、山院、旅行与战斗读取同一配方；装备可改变衣物与所持物，人物特征保持可辨认。
- 名字可重，肖像与编号不能拿来充当 ID；新角色的多项外观特征应组合而非按四幅肖像循环。
- 生成使用存档内已登记的随机流，只有真正创建人物才推进；打开卷册、看详情、重绘、读档均不能再抽一次。
- 已定求见机会、候选意愿与邀请答复随事实保存；重复点击同一邀请不能刷同意或刷更好资质。
- 旧门人通过稳定迁移映射保留既有资质、外观、技能和故事结果；缺少的新维度由确定规则补齐，不拿新生成人物覆盖老成员。

### 2.2 天赋和本领的试调分布

下表仅用于**新生成的普通求道者的修行适性起点**，四档互斥且合计 100%；它不预定十五个名额的档次，也不限制已写定剧情人物。

| 修行适性起点档 | 作者试调概率 | 对应体验 |
| --- | ---: | --- |
| 平实 | 55% | 修行较慢，仍可学可靠入门法并在专业技艺上长期成长 |
| 灵慧 | 30% | 常见的顺遂修行者，路线契合和教学会改变表现 |
| 出众 | 12% | 更快积累修为，仍受材料、法门、时间和本人选择约束 |
| 罕见 | 3% | 有机会超过掌门的天赋，不保证已学会高阶知识或愿意入宗 |

- 档次在内部用于抽取连续的适性数值；具体数值区间与现行 `talent` 迁移映射，须经成长速度试跑后确定，不能用档名直接取代既有存档数值。
- 悟性、灵根契合、手艺经验、身体状态、志向与性格分别生成；修行适性不直接决定医术、阵法、种植、守信或是否愿意劳动。
- 出身和已有经历为若干技能提供合理起点，其余技能仍可通过学徒期、实践、教师与工具训练；不得同时把全部高能力绑在少数罕见档人物身上。
- 作者应检查随机变量的相关性：同一经历可同时影响知识与技能，但不把所有强项独立叠到同一幸运角色身上。
- 普通资质也能成为可靠药师、丹师、阵匠、庶务或护院；关键生产链依靠可学习技能、导师与可取得的外部服务。
- 高资质人物可以超过掌门，但其承诺、师恩、目标和待遇仍是关系事实，不能用高境界自动推导忠诚或叛离。
- 玩家先知道年岁、可辨灵根、公开技艺和自述；深层志向、可靠程度、潜力及不公开经历由相处、教学、调查和证据逐渐形成判断。
- 玩家作出门籍决定时可承担信息不全的选择；后续揭示不追溯改写生成结果。

## 3. 发现、求见与正式收录

1. 来源事件先建立一个真实人物及其当下位置、需求、行程和对山院的已知信息。
2. 求道者愿意来访且山门可达时发出求见消息；到场后玩家操控掌门走近，看到其可公开的情况与已有往来。
3. 掌门可交谈、了解条件、提供暂居或具体帮助，也可让对方等候或离开；这些决定各有时间、床位及物资成本。
4. 正式收录前核对本人同意、可用在籍名额、住居与基本生活条件、组织权限、归峰及门籍身份。
5. 一次正式决定写入外门、内门或亲传及归峰；亲传同时确定愿意收徒且有授业机会的具体师父。
6. 收录写入同一个 `personId` 的成员关系、承诺与事实凭据；人物的身体、私产、经历、原知识和社会关系继续存在。
7. 明确拒绝、暂缓和本人离去均保留相识事实；重新求见必须有新的时间与条件变化，不因按钮重试刷新结果。

- 开局由掌门主持求见；后期有收徒权限的峰可按 U-111 主持本峰收录，授权范围、剩余名额和师父同意在提交时再次核对。
- 多人争最后一席时按已提交的事务顺序原子结算；后一请求得到明确容量反馈，不能让两人同时占同一名额或床位。
- 亲传身份不等于立即学到师父所有法门；教学仍需可接触版本、双方时间、空间、理解和实际练习。
- 对方想入宗但不愿归某峰或拜某人为师时可继续商议外门/内门等合适条件，不能通过改按钮强迫其接受。
- 费用由接待、居住和生活的实际事务产生；不能点一次“招募”直接从公库扣费并凭空生出一位已经入籍的人。
- 界面显示当前在籍数、十五人上限、可用床位、已答应的暂居与待决求见；潜力与忠诚只显示掌门有依据知道的内容。

## 5. 十五人生活与组织承载

| 承载项 | 玩家可见的实际约束 | 扩容与不足时的恢复 |
| --- | --- | --- |
| 住居 | 一人一处有效休息位置，访客暂居也占实际床位时段 | 营造或升级、调整暂居期限、寻求外部住处；不隐形叠床 |
| 膳食与用水 | 人数、活动强度、库存位置和到货周期决定消耗 | 采集、交易、储备和搬运；短缺显示尚可支撑时间 |
| 休养 | 药物、床位、照护者和伤势占用时间 | 自我休养、药田与丹药、委托医者；伤员不同时参加生产 |
| 修行 | 典籍、教师、灵地实际供给、练位与时间 | 轮换、合适法门、外出求学；增加建筑容量不制造天然灵气 |
| 工作 | 工位、工具、材料、路线、愿意工作者及其日程 | 调整差事、培养技能、短期委托或掌门亲为 |
| 储运 | 公库、个人包裹、现场仓、搬运者与道路 | 增仓和路线、分批采购、改交货约定；在途不算已到货 |

- 作者试调容量阶梯建议为可支撑约 2、5、9、15 人的经营检查点；每次实际开放仍由床位、供给、阶段、道具及布局共同核定，数值经 SR-XF-031 试跑调整。
- 上述检查点是经营压力测试尺度，现有五、二十、五十等山域构图样例仍服务长期空间设计；第一篇章十五人上限不回写历史档容量。
- 每次扩招前以覆盖一个真实补给周期的世界步窗口观察饮食、药物、工位、教学、休息与物流；外出队伍回山后的需求也要计入。
- 生产可随人增加并行活动，但天然采集点、灵地、田地水土与贸易对手的实际流量有上限；增加人手不会让单块资源点超额产出。
- 床位已建而无食物、田已建而无种苗、工坊已建而无原料，都应显示实际缺口，不能按建筑等级发放抽象收入。
- 开工资源先预留，搬运后在合法位置使用；中断、满仓和读档恢复同一批次，不重复给付或重复消耗。
- 日常供给和岗位制度可以减少重复操作，但只提供机会、预算与公开承诺；一名门人同一时刻只能占一个身体活动和合法工位。
- 人多时可任命愿意承担职责的庶务、传功和护院，职责说明边界、时段与退出方式；一个人兼多责仍受个人时间限制。
- 掌门外出时山院仍按同一世界时钟运行；出发前可安排库存、可接替的人与安全撤退路线，不能在远方实时遥控每名门人。

## 6. 百艺、培养与人才短缺

- 百艺首批围绕药植、炼丹、制器、阵务、疗伤、营造、庶务与传授，分别保存知识来源、实际技能、练习经历及可执行配方。
- 药植：识别种苗、照料成熟、收获和分级入库分别发生；野生灵草与田中作物遵守真实供给周期。
- 炼丹与疗伤：药材来源、丹方、炉位、执行者、批次和成丹位置可查；诊治需实际到场和药物，不把技能等级直接兑换成痊愈。
- 制器与营造：图样、材料、工具、工位、匠人、品质与耗时分开；装备是唯一实例，维修与借用沿用原物品 ID。
- 阵务：需要可学的结构知识、布设材料、地点和持续维护；阵匠离开后既有节点与记录不消失，但维护会受人手影响。
- 庶务、护院和传功也消耗身体时间；好执事改善协调、预警或教学质量，不凭职位自动生产物资或全知情报。
- 学徒跟随有技能的门人、外部师傅或可接触的教材，在真实时段与工位练习；师父离开、教材不足或生产危险时进度如实暂停。
- 普通资质者在专业技艺和教学中可凭经验逐步承担关键职责；修为高者若未学具体手艺，不能越级制作或传授。
- 单一人才暂缺时允许掌门亲为、外部委托、购买成品、调整生产顺序和培训现有人手；各路线有时间、金钱、质量和信任差异。
- 稀有知识仍需可靠可取得的导师、遗卷、调查或交易来源；外部服务可以补一段生产，不代替掌门本人需要经历的学习与成长。
- 对某条路的拒绝可转向其他已定义机会，不能通过刷候选抽到“全能门人”才使复仇篇章可达。

## 7. 物品、订单和个人财产

- 公库、个人私产、掌门随身、现场仓与在途货物按位置及所有人分别记录；入宗不改写个人物品所有权。
- 每笔采集、生产、交易、委托、赠予、借用、归还、运输和损毁写入来源、数量、时间、参与人、位置与一次结算凭据。
- 界面同时显示可用、预留、在途和已知缺口；预留保留在原库存，运输改变位置，消耗才改变总量，不能三处重复扣料。
- 装备实例记录制作者、批次或来源、品质、维护状态、所有者、保管位置和借用约定；赠予需物主同意，公物借用需实际归还流程。
- 报酬和生活预算从有权支配的公库支出，个人工资归个人；公库不足先暂停新承诺并展示恢复途径。
- 门人离宗或身死后先停止其活动并释放预约；私物、借物、债务和未交接订单依各自事实处理，不凭释放名额没收或抹消。
- 商旅订单有报价、对方、数量、库存来源、到货方式和接受记录；补货遵守商路周期与库存，重复领取不额外造物。
- 物品上的旧案线索、师承和赠药关系仍引用同一来源事实；换仓、借出或卖出不改变曾经发生的历史。

### 7.1 经营差事与所得

| 差事 | 可靠接触和实际动作 | 可以得到的结果 |
| --- | --- | --- |
| 采药与育苗 | 已知采集点、田边照料与可交货的顾客 | 有批次的药草、种苗、报酬或栽培知识 |
| 修屋与通路 | 真实损坏、石桥驿或邻近住户的委托 | 建材、工钱、通路改善或匠人交往 |
| 护送与商路 | 买卖双方、可达路线和实际同行风险 | 已付款的货物、报酬、可靠到货消息 |
| 救治与寻人 | 目击线索、伤病地点与可携药物 | 关系、医术实践、实际答应的物资或新线索 |
| 教学与借阅 | 愿意授课的人、典籍版本及安全时段 | 已学习的技能、合法借阅权、后续师承机会 |
| 工艺与阵务 | 已接的制作单、材料、节点和交付地 | 唯一装备、阵图知识、委托款或设施能力 |

- 每项差事先标定委托人、来源货位、所需动作、期限与可核实结果；报酬来自对方实际库存、付款能力或已有作者事件，不从任务按钮凭空铸造。
- 同类差事可以轮换地点、人物和需求，但同一已定委托的报酬、证人和事实在读档后保持不变。
- 供给差事提供普通天赋门人可参与的实操成长；熟练度来源于所做工作，修为与法门知识仍按各自规则积累。
- 主线调查可借这些活动获得商路、旧账、阵痕或关系消息；可靠关键证据另有可达路径，不锁在随机差事的稀有结果里。
- 拒单、超时、失去工匠或运输失败时记录真实损失与修复机会；已交付与未交付数量分开，重试不重复领取。

## 8. 同行、留守和人员风险

- 掌门可邀请至多两名愿意同行的门人组成队伍；受邀者核对地点、伤势、任务风险、承诺、装备和本人目标，拒绝仍可维持关系。
- 同行者与掌门在同一旅程及战斗时钟中行动，各有实际携行物、位置和撤退能力；出门后不同时算作院中工位劳力。
- 留守安排可向门人提出护院、医疗、供给、教学和应急搬运机会，由各人自主接受；空缺要向玩家显示。
- 风险提示列出出行人数、留守床位和物资、正在运行而可能断人的批次、已知威胁与下一次补给预计时间。
- 山院来袭、伤病、物资中断或人员离去按观察、消息传递、到场、救援与恢复推进；远方掌门只能依据已知消息决定返程。
- 同行与留守的死亡、失踪或主动离宗均保存同一个人的结果；已登记任务改为等待、交接或失败，不让亡者继续产出。
- 主线可以由掌门加不满两人的队伍完成，但实际少人应承担更高行程、补给或战斗风险；十五人山院也不能无成本全体出征。
- 满员时掌门带两名门人出行，理论上还有十三名门人占在籍名额；实际留守人数再扣除另行出差、治疗、失踪或其他不在院者，以人物位置而非名册减法显示。
