| 施工 | 到场后200 tick，即20模拟秒 | T：用于验证到场、暂停、取消与存档；节奏未定稿 |
| 施工疲劳 | 每秒0.15精力；动工需至少15精力且无伤 | T：保证正常首建可完成 |
| 日长 | 1200 tick，即120模拟秒 | 沿用旧经营周期；不是真人游玩时长 |

`schemaMigration.clockOriginTime/clockOriginTick`是冻结的历史映射，兼容含小数时间的旧档；旧读取视图从唯一 worldTick 推导，原一秒结算节拍保持不变。这不是第二个可推进时钟。建造预约、存续记录和随机种子原样进入新根；原 `sim.seed` 同样只是 `rngState` 的适配入口。

## 3. 贯通路线与证据

`qa/ea-opening-v12-acceptance.mjs`只使用公开命令：疗伤 → 赠药 → 邀请/离开 → 药圃与伐木场 → 林长风自愿入院 → 藏经阁 → 春雨养脉法 → 门人自主生产 → 山谷到场、行动、回院。测试不注入资源、人物或主线进度。

- [命令报告](../../qa/acceptance-opening-v12/command-report.json)：两个种子/去留分支，各24次公开命令、6个存档检查点。
- [全仓测试记录](../../qa/acceptance-opening-v12/unit-tests.tap)：当前批次重新执行，不能沿用EA 1.4.2计数。
- [48个界面模板记录](../../qa/acceptance-opening-v12/ui-templates.json)：真实模板求值和只读检查；包括赠药后未入院、施工、暂停施工以及两条外出后的路线。
- [新增机制测试](../../tests/ea-opening-v12.test.mjs)：迁移、身份、转移、拒绝路径、命令幂等、到场研习、施工存续、未来版本保护。

自动路线模拟时长约4分钟，阅读、操作与观望未计入。这只证明可达性，不证明前30分钟真人节奏或趣味性。外出与回院仍复用旧旅行模型，本批未实现全世界统一旅队。

环境没有可执行的 Chromium；Playwright下载返回无效压缩包。没有本批浏览器截图、触控/命中/布局、可信FPS或真机测试，不将模板检查写成浏览器通过。
