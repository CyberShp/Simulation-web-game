# 09 · 人心、情报、谋局与机缘暗线

设计编号：DB-2026-10-05 v1.2。状态：目标规格，未实现。
本文件规定修仙世界如何产生可信而不全知的算计、如何让机缘有来历，以及玩家与NPC如何调查、利用或付出代价。依赖 [人物](01-CHARACTERS.md)、[装备与武学](02-EQUIPMENT-ARTS.md)、[世界与剧情](04-WORLD-STORY.md)、[运行时契约](05-RUNTIME-CONTRACTS.md)；持续危机、寻找与救援见 [10](10-CRISES-RESCUE-DEATH.md)，可选生成式AI边界见 [11](11-AI-CONTENT-CONTRACT.md)，作者交付规范见 [12](12-CONTENT-AUTHORING.md)。

用户确认的方向是：修仙社会存在利益冲突与欺骗，消息并非全真；人物不能按正、魔、鬼、妖直接分成好坏；稀世机缘需有设计过的暗线；玩家仅直接控制掌门，NPC可在持续危机中死亡。约40%的算计密度是用户给出的尺度方向，本文分母、预算、模板和“母子篇”具体规则均为设计建议，不声称逐项获批。

## 1. 世界基调：可疑、有秩序、仍值得交往

修仙社会的紧张来自有限灵地、传承、寿限、名分、修为与人情，并非所有人每天都在骗掌门。
真实交易、可靠师承、互助、旧债兑现和守信者必须长期存在；否则验证消息与经营关系失去价值。
人可以在不同对象和处境下表现不同：对门人负责、对敌人苛刻；真心救灾同时争取地盘；守约但不肯牺牲家人；救过掌门又隐瞒另一件恶行。动机能够解释行为，不能自动免除后果。

### 1.1 身份、法门、行为与舆论分别记录

U-79明确双方主流倡导的处世分野：正道重名分秩序与师承责任，魔道重个人意志与力量、较少受既定规矩束缚。这是理念背景，不是对每个人真实动机的判词；既可有践行者，也可有借名牟利者。社会联盟、个人理念、所学法门与实际行为继续分别记录，守约或作恶仍须依据具体事实判断。U-80允许少数散修达到极高境界，不能仅因无固定大势力归属就判定人物必然弱小或背后必有隐秘宗门。

| 维度 | 说明 | 不能推出什么 |
| --- | --- | --- |
| 组织归属 | 正道宗门、魔门、鬼道宗门、妖族群体、散修等社会身份 | 不自动推导仁心、可信度或必然敌对 |
| 修行道路 | 鬼术、血法、妖身、剑修等能力与禁忌 | 使用阴性法门不等于无差别杀戮 |
| 实际行为 | 救助、胁迫、违约、献祭、夺宝、设陷、遮掩等持久事实 | 不能因名门身份抹去犯罪，也不能因异类身份伪造罪行 |
| 公开定性 | 正统、异端、通缉、污名、受保护等地方制度判断 | 定性可能真实、夸大或伪造，需保留依据与知情范围 |
| 私人取舍 | 价值、欲望、恩怨、恐惧、承诺和当前压力 | 不能压成一个善恶分数或“野心高所以必背叛” |

“邪修人人得而诛之”提供可被公议接受的讨伐理由，不是所有NPC自动追杀的行为指令。是否调查、划界、悬赏、清理门户或暂不行动，按[U-40](13-WORLDVIEW-DISCUSSION.md)取决于具体门规、决策人所知、立场、利益、关系和行动条件；与邪修交易、借刀杀人或庇护所带来的风险，也由实际行为、被谁获知及相关规则决定。按U-39，邪修与其他作恶严格区分；主动为修炼目的屠城等重大暴行算邪修，真实失去理智/走火入魔等临时状态导致暴行另算。修炼目的、当时真实状态、诱因、损害、责任与公开说法分别记录；重大伤亡不能单独决定邪修身份，自称失控也不能自动免罪。完整禁忌与暂态责任细则仍待定。
已经确认的U-39真相边界保留；完整共同禁忌与门规的适用关系尚待讨论，不将用户处置例子推定为已选完整统一禁法表。正式确定的世界规则、组织门规、地区公约和具体权限分别以版本化定义登记，不能每名模型临时另造或为了既有剧情偷改事实。公开被称为邪修不等于权威事实已证明此人作恶，正道同样可能栽赃、隐匿或勾结。
讨伐中误伤无辜、伪造证据、占吞赃物分别结算。魔道、鬼道、妖道保有不滥杀者、守约交易者、救助者与不同制度；不能把“魔门”直接映射成可无后果杀戮的标签。

### 1.1.1 门规、清理门户与悬赏的处置链

以下是落实U-40的设计要求；具体门规、赏令分级与金额未定。用户举出的正派主动处置、中庸划界悬赏、魔道不挡路便不理会均是可能倾向，不能按阵营硬编码，也不能把道貌岸然者与正义者的真实目的混为一谈。

| 环节 | 作者与规则需要明确 | 实际后果 |
| --- | --- | --- |
| 判断与决定 | 决策人、所知证据、门规依据、真实动机、利益与资源 | 公开定性可与真实事实不同，也可与实际行动不同 |
| 内部处置 | 是否本门成员、处分权限、调查/保护/逐出/追捕等选择 | 清理门户针对内部关系；涉及拘禁或斗法须实际执行，不直接删除NPC |
| 公开划界 | 由谁宣告、断开什么联系、仍有哪些私下往来 | 消息沿传播渠道到达；宣告不自动抹除旧债、既有行为或暗约 |
| 外部悬赏 | 发行者、目标、指控、条件、报酬来源、有效范围与相关权限 | 可针对他派或散修；发布不证明指控为真，也不自动取得实时位置 |
| 接取与行动 | 谁获知、谁愿接、可获得的线索、距离、准备与成本 | 调查、出行、追捕和斗法使用实际行动及同一worldTick，目标可逃离、反制或求助 |
| 核实与兑现 | 完成条件、凭证、核实人所知证据、支付来源与一次性领取键 | 核实不读取后台全知真相；不因点击或换名字重复发奖；误捕、伪证、误杀与未兑现留下持久后果 |

“高级/紧急悬赏”仅作为用户例称保留，不把这两个词固定成完整等级树或倍率表。具体定义须另行设计。人物还可以不接悬赏、反对本门处置、揭露伪证或暗中庇护；这些选择引用实际能力、关系和代价，不能用标签自动完成。

### 1.2 隐藏议程与NPC的选择

议程从既有人物目标、所知消息、能力、资源、承诺、位置和机会生成；人格不能由一次随机抽取改写。
同一人物可同时有公开目标、未公开利益和道德底线；隐藏议程不必是谋害，可以是保住师弟、偿债或避免泄露本门弱点。
是否实施谋局还须比较收益、暴露风险、准备成本、可替代方案及对重要关系的损害。贫困、野心或阵营只能影响权重，不能强迫所有同类作恶。
执行失败后可认错、谈判、迁怒、撤回、转嫁或升级；新行动仍需条件和时间，不用剧情文本凭空补出无限后手。

### 1.3 天道誓言与宗门修真合约（U-78）

用户确认天道誓言有实际约束力，宗门可据此衍生约束力略低的修真合约。两者有真实超自然效果，依U-70按客观规律运行；是否成立及效果范围应来自既定机制，不能写成有意志的天道临时审判。普通说话、社会承诺与真正生效的誓言或合约分别记录。

作者须为具体内容定义成立条件、受约束对象、条款及适用范围、触发事实、后果、持续与解除规则。未在本轮确定反噬类型、固定代价、绝对可解/不可解或跨界适用性；宗门合约的约束力是略低，不等于没有法术效力。现有誓印、债印、认主契约等模板仍是作者设计，须说明其与这一机制的关系，不自动全部升级为天道誓言。

誓约造成的事实及各方能知道的消息分别处理，不能自动向掌门公开签约者全部隐私或幕后真相。NPC仍依据自己的知情、目标和已经成立的约束行动；誓约设定不直接新增玩家接管NPC的入口。具体规则按同一世界时间、身份与事件事实结算，不在本次文档更新中实现新系统。

## 2. “约40%”的计量与节奏

推荐基准为：在一段体验中**已经激活、可参与的重要独立机缘或事件链，约40%含蓄意操纵、实质欺瞒或隐藏施谋**。计数单位是根链ID；同一谋局的十封信、三次战斗和五条传闻只计一次。公开竞争、价格争议、已告知义务与可信合作另记冲突/职责，不自动算阴谋。

| 口径 | 推荐规则 |
| --- | --- |
| 分母 | 已激活且掌门有参与或调查机会的重要独立根链；排除普通浇田、吃饭、修屋及同一链后续节点 |
| 分子 | 有实际行动者、成本和后果，且`manipulationTag=true`；理由为`deliberate-manipulation / consequential-deception / covert-hostile-plan`至少一种 |
| 初次目标 | 在滚动20条合格根链中约8条；小样本按导演预算与内容审阅，不强凑精确比例 |
| 调节 | 40%为可调内容密度；新手阶段降低，熟悉后的地区提高，依据信任感、选择密度和压迫感复核 |
| 不代表 | 40%的句子撒谎、40%的NPC背叛、40%的装备诅咒或40%的出行死亡 |
| 分布 | 争利、隐瞒、骗局、诱导、暗中合作、敌对设局混合；不得用同一种假秘籍凑数量 |

比例由内容标签与事件导演的压力预算约束，不在打开传闻时掷骰子决定真假，也不为补满比例临时把已真实的旧事件改成阴谋。schemeId表示安排/议程，并不自动令manipulationTag为true；作者卡与导演统计使用同一标签和理由枚举。
推荐同时激活的严重危机有限，遭到重大损失后留出可预期恢复期。秘密计划可以继续有准备活动，但不能在恢复期无提示连发不可逆打击。
开局先用不致命的账目矛盾、议价和选择性隐瞒教会互证，再引入可能致命的机缘；关键基础法、治疗、正常资源与复仇证据仍有可靠路径。

## 3. 事实、消息、信念与掌门已知

消息是一个人向另一个人传达的主张，不是世界事实本身。

1. 权威世界保存实际发生的事实、作者已定秘密、实体归属和状态。
2. 人物通过在场观察、物证、他人告知或术法获得有限信息，形成自己的信念；诚实者也会判断错误。
3. 传信人按所知、目的和沟通条件发出`claim`，可省略、误述、伪造或转述。
4. 掌门获得这条消息，UI只展示来源、时间、转述链、已知证据与核实状态。
5. 调查增加观察与证据，使信念更新；真相与公开名声不必同步改变。

U-57已明确沈氏灭门是直接夺取灵脉与产业，不附加罪名或邪修栽赃；相关调查用于了解参与者、利益和经过，不设置洗罪翻案前提。世界一般的伪造指控与真假消息机制仍保留。[U-50](13-WORLDVIEW-DISCUSSION.md)中，仇家占领沈氏产业后，正道介入者的公开名义是维护正道道义，实际目的为争夺灵脉利益，结果没占到便宜；U-53已更正为既有沈氏修行灵脉，不新增矿产产业；公开说法、作者已定动机、各人物所知与掌门获知分别记录。玩家不能仅因听见道义宣言便自动获知真实利益，也不能由事后争夺灵脉倒推介入者预先共谋灭门。U-51已确认当地剑宗中层组织参与，U-52确认魔道上宗撑腰带来的冲突升级风险，与夺取已被控制产业的高昂代价，共同影响这批剑宗中层的取舍。具体人物/参与单位、支持方式与授权链/高层知情态度、实际交手/收场仍待定，不由传闻或临时反转补成真相；玩家所知仍需线索支持。U-54将此次争夺固定在主角正式落脚前，落脚后的调查揭示历史事实；初始知情程度待定，事件早于开局不等于主角自动知道真实目的。U-56明确韩厉川在主角落脚时对其生死不确定，只怀疑可能还有幸存者；作者真相中主角活着与韩厉川的判断分别存储，后续查探须凭线索更新，不能把不确定改写成已确认存活、死亡或已知别院。主角并不自动知道敌人的内心判断。

### 3.1 消息的五种常见形态

| 形态 | 作者必须明确的真实关系 | 玩家能够做什么 |
| --- | --- | --- |
| 如实告知 | 主张在已说明范围内成立，来源可能有限 | 追问范围、交叉验证、及时行动 |
| 真实但省略 | 说出的部分真实，省去条件、损失或另一参与者 | 核对时间、账目、地形或缺页，追问受益者 |
| 真实但诱导 | 地点/宝物存在，传信者希望掌门替其承担风险 | 另定进路、另谈分成、先观察、拒绝进入 |
| 误认与过时 | 消息原本诚实，但来源判断错或环境已变化 | 比较观测时间、复勘场所、澄清来源 |
| 蓄意伪造 | 内容、署名、证据或目击经过人为制造 | 检验制作痕迹、找独立见证、追查传播路线 |

UI不用一个隐藏“真假百分比”泄露答案。“商客转述，三日前”“阵纹与旧拓本相符”“此两名证人都引用同一书吏”比精确可信度条更有用。
同一谣言经三个商客转述仍是一个来源；传播数量不能自动变成三份独立证据。来源独立性由来源图和取证过程判断，而非仅看NPC姓名不同。
被证伪的消息保留历史，不删除已经依据它发生的行为、关系和成本。纠正可以传播，但不瞬间清空所有人的旧信念。

### 3.2 证据与可调查性

证据可来自物品来源、典籍文本差异、实际阵纹、药理反应、账目、路线足迹、尸伤、当事人证词和已知术法观测。
每份证据记录观察者、取得过程、时间、地点、引用对象、保全状态与可伪造方式；真实性只在权威层存在，玩家看到的是检验结果。
灾难性且不可逆的作者陷阱，在进入关键承诺前至少提供**两条独立发现路径**。可用“缺页反常+旧拓本”或“前代患者+仪式台残痕”，不能两条都依赖同一个未刷出的随机访客。
线索先于伤害存在，取证需时间和资源；后见结算文本不能冒充预兆。玩家不调查可以承担风险，但不能因唯一高级鉴定术未拥有而完全没有识别办法。
危险类别、准备不足与已知损失用直白提示表达；幕后身份、完整手段与最终答案仍通过调查取得。警示“此法突破篇缺失，无法核定风险”不泄露母篇持有者。

### 3.3 卜算作为一种受限调查

卜算输入必须有目标锚点，如近期书信、本人气息、随身物、地点痕迹或经核实的身份；没有锚点不能输入姓名全地图查人。
一次卜算是有准备、施法、解读阶段的活动，消耗合适材料、身体状态与模拟时间，可能留下被察觉的痕迹。活动阶段遵守05，不另造瞬间结算循环。
结果说明观测范围、时效和方法局限，例如“残息向谷北，雷雨遮断后续”“其气机与此玉简有共振”，不显示“隐藏叛徒=true”或必定死亡日期。
反卜算、替身、同源气息、天气与阵域可造成模糊或误导，但各有真实机制和取证痕迹；不得只因玩家用对工具就临时创造万能遮天术。
不同锚点与方法提供不同信息，同一个锚点短时重复施术不免费重抽；输入不变且世界未变化时返回既有观察范围，并可增加明确的重复施术成本。
卜算是可选途径。目击、信使、尾随、探路、关系求助、偶遇和物证也能定位或揭露；救援时是否赶得上由真实路程和危机阶段决定，见10。

## 4. 谋局不是剧情作者的无限权限

每个实际谋局必须具备：行动者、目的、目标、所知信息、可用能力、已投入资源、空间路径、准备时长、触发条件、暴露机会与撤退方案。

| 要素 | 规则 |
| --- | --- |
| 所知 | 谋局者不读取掌门私密库存、未知行程或尚未决定的选择；需侦查、泄露或已知习惯 |
| 资源 | 收买、埋伏、禁制、传信、替身、远程联系消耗登记资源或实际能力，不能无限复制 |
| 准备 | 人物到场、搭阵、运输与联络走同一时钟；计划是目标，不是已经完成的事实 |
| 触发 | 满足规则才能行动；掌门改路线、毁锚、拒绝仪式、组织见证可使触发失败 |
| 曝光 | 存在目击、物资缺口、术法残留、文书矛盾等与具体手段有关的证据 |
| 失败 | 收买对象可以拒绝；反噬、丢失材料、暴露、欠债、被反制等代价按事实发生 |
| 自保 | 撤回需要能力和时间，已发生的伤害/证据不会因计划取消而消失 |

同一谋局的初始阶段、关键参与者、机制与身份在根链激活时固定并存档；后续选择改变进展和结果，不改变先前真相。若母篇被真实抢夺、持有者死亡或执行者更换，须通过可追溯的新事实改变后续执行条件，不能把新持有者改写成“从来都是幕后人”。
作者可设计分支，不能在玩家破解后再凭空增加一位真正幕后人。阶段升级必须引用原有准备或已经发生的新行动。
本人死亡、失踪、设施被毁、失去传讯条件会影响执行；不能死亡NPC继续无条件操纵他人。
NPC与掌门使用同一行动权限、物品、道路、调查和危机规则。外地模拟可聚合耗时与行动，但不能因为不在镜头中就免除准备、战斗时长与证据。

## 5. 稀世机缘的作者规范

绝世功法、绝世装备、上古洞天及被定义为稀世的重大机缘，每一项至少一条设计过的暗线，可有互相交叉但能解释的多条。
按U-68，世界修行文明总体不断发展；古代遗留的价值须由实际能力、独特知识、材料或历史用途支撑，不能仅凭“上古”二字保证更强。古代个别高峰和失传技艺仍可存在，当代创新也可成为稀世机缘来源，均遵守同一作者真相卡与暗线规则；不将全部机缘改成古代全盛文明遗产。
**暗线不等于恶意陷阱**：合法继承条件、需要偿付的恩债、封印守护、失散同门、历史错案、有限污染或第三方争夺，都可以使机缘具有重量。暗线的存在率与40%的算计率分别统计。
普通药草、入门功法、常用武器和日常建设不强配幕后阴谋，保留可依赖的生活基础。
稀世内容先建作者卡，再做宝物名称、数值、掉落或宣传文本。未具备完整暗线卡不得进入正式内容池。

### 5.1 每条暗线的最低作者卡

| 字段组 | 必须填写 |
| --- | --- |
| 来历 | 定义ID、版本、创造者/遗留者、真实用途、为何现在可被发现 |
| 隐藏机制 | 生效对象、触发条件、边界、弱点、成本、时距、停止条件 |
| 参与利益 | 受益者、受害者、争夺者、知情者；各自所知及不能做的事 |
| 传播 | 谁最初放出消息、为何相信、转述如何变形、哪些部分真实 |
| 调查 | 至少两条独立路径、线索出现时点、可替代调查工具、误导的来源 |
| 选择 | 获取、拒绝、改造、交易、揭露、夺用或毁弃等实际可行分支 |
| 后果 | 收益、伤势、损失、时间窗、死亡条件、地方和人物反应、恢复/收束 |
| 可玩范围 | 当前可执行阶段、后置境界与伏笔；不能用锁死按钮冒充远期系统 |
| 持久化 | 根链ID、固定种子、引用事实、参与者ID、物品/典籍实例、结算键 |
| 验收 | 正常获取、独立发现、破局、迟到、拒绝、NPC经历、保存/恢复情景 |

“此宝物其实邪恶”不构成作者卡；需要解释可观察的机制及其利益链。

## 6. 示例深化：母子篇收割与一线生机

用户举出的“无敌子篇在大境界被母篇持有者抽取”用于验证长期暗线设计能力；本文推荐把它做成有真实收益、固定代价、可调查且可反制的罕见链，而非所有奇遇的默认真相。
以下名称与数值未锁定；金丹、元婴完整玩法仍依L-01后置。首轮不能突然用远期敌人吸干炼气角色，也不能借此将韩厉川降格为无限幕后人的棋子。

### 6.1 子篇真的有用，关键是被隐藏的依赖

子篇改进灵力循环与某类术法，收益与局限真实；“天下无敌”是传播者的宣传主张，不是物品定义承诺。
母篇与子篇共享特定气机签名。子篇缺少独立闭合的大境界结算段，其修炼者可能在突破时开放一条本来用于师徒调息的通路。盗改者将这条通路用于掠夺。
正规同源法可以有完整结算段与合法授受关系；危险必须绑定具体版本/复制来源/禁制，而非整个法门名称。复制危险版本仍复制其结构，不因换书名变安全；净化/校勘后生成新版本和改写事实。
母篇持有者身份、持有关系、意图、通路和布置在根链激活时固定。UI可长期不知道，作者不得在突破失败后临时选一个更强的人当收割者。

### 6.2 收割成立必须同时满足条件

| 条件 | 解释与反制 |
| --- | --- |
| 危险版本仍在功体中 | 若已完成安全转修/补全闭合段，无法按原方式收割；知道危险但只换纸本不够 |
| 进入作者定义的突破阶段 | 日常运功不会任意触发全额收割；触发阶段和共振预兆在机制卡固定 |
| 有可用锚点与通路 | 血印、誓印、玉简禁制或维持联系的法阵至少一种；销毁、隔绝或改写要实际处理已内化部分 |
| 母篇持有者可行动 | 需活着/可施术、相应能力与已登记资源；受伤、失联、被困或锚点破坏会降低或停止效果 |
| 能跨越距离与阻隔 | 远程通过既有阵域/中继，耗时与维持成本随阻隔增加；没有“跨全地图无成本瞬杀” |
| 执行未被打断 | 抽取是持续活动与危机，不是一条突破结算消息；双方动作、外来救援和通路变化共同决定结果 |

收割者需要准备、维持、传导与吸收时间；正面维持术法会占用其主活动和可用精力。吞纳超出自身能力会反噬或丢失，不能零成本叠成无限世界最强。
目标法宝/地点作为锚点时其归属、位置、损坏、隔断与破阵均走装备和空间事实。离线、剧情阅读或战术暂停不继续抽取。

激活键为`schemeId + targetPersonId + internalizedSignatureId + breakthroughAttemptId`；同次突破只能创建或恢复同一抽取危机。`internalizedSignatureId`引用人物已内化联系，`breakthroughAttemptId`引用这次真实突破活动。阶段往返、母篇易主、回调重送或读档均不能重建危机、刷新累计抽取上限；实际易主可改变后续施术者，不改变旧结算。

各段扣取使用`activationKey + transferSequence`的幂等账本，保存累计已损、已吸收、逸散与反噬。中止/净化/断链保留账本与终态；真正重新发起突破是新活动，但能否再次触发须由未解除联系和内容规则决定，不把旧同次突破包装成新实例重复扣取。

### 6.3 不自动全吸：哪些东西能损失

可抽取的范围在内容定义固定：同源灵力积累、特定修行资质的灵性成分，以及被定义为可转移的道体/法印特质。
学过的药理、对人的恩怨、姓名、人格、长期记忆与全部工艺经验不作为同一个“吸光属性”包转移；需要独立神魂机制的内容不能偷偷顺带生效。
境界、资质、特质分别有上限、进度和后果。抽取不会因为动画未播放完就瞬间把全部数值归零；损失、吸收、逸散和反噬分别记录，不能凭空复制正收益。
部分抽取可造成修为减少、跌境、经络伤、某项资质损伤或特质暂失；恢复条件与不可恢复部分在规则中明确。风险警示先说明可能损伤类别，不必须提前揭露完整敌人身份。
抽取先创建/更新10的持续危机，不由谋局表直接写死亡。危机阶段使用`forming / exposed / engaged / escalating / critical / resolved`，记录`stageStartedTick / durationTicks / stageProgressTicks`；不是另一个人物活动时钟。
完成抽取也不必立即死亡。若生命/神魂损伤达到10定义的不可逆条件，危机结算才可能将`person.lifeStatus`从`alive`改为`dead`。`bodyState`依据健康/伤势派生为`fit / impaired / incapacitated / dying`；已经死亡不以晚到的普通治疗或刷新自动复活。

### 6.4 至少三条相互独立的生机

| 生机 | 前置与过程 | 必须承担的代价 |
| --- | --- | --- |
| 事前校勘转修 | 从独立旧拓本或合法师承识别缺段；在突破前用真实研习、调息和药材改闭合循环 | 放弃部分增长优势、延迟突破、花费材料；保留已掌握普通知识 |
| 当场自行断流 | 在共振/牵引阶段识别异常，以已知的基础断息或紧急散功动作关闭通路；不依赖唯一稀世装备 | 失去当前突破投入和部分修为、伤势、功体需要修复；不保证无伤逃过 |
| 外部破锚救援 | 掌门/盟友通过线索定位，赶到锚点、解除阵域或打断施术者；也可护送目标离开影响范围 | 真实路程、战斗、资源和留守代价；每次迟到可能增加损失 |
| 反向谈判或追索 | 已掌握母篇身份、证据或关键中继，交换停止、夺回物资、迫使撤法或后续追回可追索的凝炼物 | 债务、让利、风险关系；收割者可能拒绝，但不能抹去已存在的其他生机 |

这些路径各用独立条件，至少事前路径与当场路径不得同时依赖同一稀有随机材料。外援能否到达不提供绝对承诺，由当下距离与危机窗口判断。
生机是有代价的可能，不是人人自带复活保险。无人识别、拒绝停止、持续困锁或所有救援迟到，仍可产生严重损失与NPC死亡。
玩家发现后可揭露、毁掉危险复制品、建立校勘课程、保护潜在受害者或反用通路设局。传播证据要经过可见信使/见证与信任，不瞬间让天下所有人相信。

### 6.5 首轮范围如何实际验证

首轮用炼气至筑基可玩链验证相同结构：一卷来历不明的快速调息诀含借气禁制；收益真实，但某次小关口/同源仪式会抽走部分灵力并造成可治疗经络伤。正常基础法与可靠筑基知识不被替换。
链中包含两个独立线索、一条安全校勘、一条紧急断流、一处可破坏锚点、NPC经历及有时距的救援。没有金丹/元婴突破按钮，也没有远期无敌敌人当场运行。
高境界母子篇作者卡作为后置内容保存版本与伏笔，不在当前存档实例中预置必死倒计时。将来开启需增加完整境界、危机、恢复、存档和验收规则。

## 7. 长期链的反馈与收束

长链按“接触—受益—发现矛盾—付出调查成本—作出承诺—危机或解决—善后”给出可理解阶段，但不是每条都强迫危机发生。
每一阶段至少带来实际变化：招式可用、地方关系变化、物品来历补全、账目异常、人物求助或明确的可调查地点。不能数十小时只留一句“以后有大事”。
个人收益与风险可同时增长；玩家向门人传授危险版本也形成责任和关系后果。导师“不知道”与“已知还隐瞒”用知情事实区分，不能事后自动把好意传授判作恶意。
破局后保存结果：危险版本已封存、阵域已毁、受害者仍有伤、施谋者失去信誉、继承义务开始或债务重订。解决过的同一阴谋不重开；复制传播后的新实例要引用旧事实和新的执行条件。
复仇篇章的旧案有自己的固定清算终点。旁支暗线可以留下世界余波，不能把每个解决结果都改成更高境界幕后人的下一层试验。

## 8. 玩家也可以作恶，但必须亲自形成因果

掌门可以隐瞒、设诱饵、盗取、布置陷阱、借第三方、选择不救或针对洞天危险做局，前提是拥有实际情报、能力、位置与材料。
“令某NPC死在洞天”不是命令目标直接写`alive=false`。应当由掌门调查路线、制作/携带材料、到场布置、留下或消除痕迹，再通过消息/契约/实际情境影响对方自主选择；对方仍可能识破、改道、拒绝、逃生或被他人救出。
玩家不在当地无法在地图上远程生成陷阱；若委托第三方，则有同意、报酬、信使、履约及背叛风险，不接管第三方身体。
陷阱只按定义作用于进入范围者，可能误伤其他人、被拆除或反用；掌门不可因是玩家免疫实际阵法/空间规则。
无人知情时不立刻广播恶名，实际事实与潜在证据仍保存。被发现后，各方依据亲疏、利益、证据和制度分别反应；销毁一份证据不能撤销目击、账目或幸存者记忆。
选择不救、知情诱杀、主动献祭、救人后索偿分别记录行为与动机依据，不用同一扣分替代。善后、赔偿、认罪或长期守信可以改变部分关系，但不能用送礼删除死人和旧案。

## 9. 目标数据与接口边界

本节只提出字段职责，最终必填/枚举/引用以05共享schema为准；不是可直接导入的完整存档。

40%分母包含机缘和重要非机缘事件链，统一通过以下根链的`playerActivationTick`首次非空记录计一次；再传信、进入子战斗或读档不重复激活。暗中发生且掌门尚无参与/调查入口的NPC链不会因世界在模拟就计入玩家体验窗口。

| 主表/字段 | 保存职责 | 与已有数据的边界 |
| --- | --- | --- |
| `schemesById` | 隐藏议程实例：执行者、目标、利益、所需信息、已投成本、机制、阶段、暴露/中止条件 | 不复制人物性格、物品位置或事件结果；引用personId/eventId/factId |
| `claimsById` | 原始主张、发出者、接收者、时点、主题、引用证据、转述来源与传播记录 | 不把消息文本当事实；真实性/意图在权威侧，已知核实状态由投影派生 |
| `opportunitiesById` | 统一重要独立根链：`rootKind=opportunity / event-chain`、来源定义、参与者、暗线卡、当前节点、内容版本、首次可参与激活时刻、实例物/典籍引用 | 子事件以`rootChainId`引用；宝物仍在items，典籍仍在editions，危机/结果仍在events/facts；不另造事件链统计根表 |
| `investigationsById` | 调查目标、问题、活动引用、来源图、证据引用、已作推论及其依据 | 观察结果存facts，个人相信什么存人物知情/信念；不另藏第二份真相 |
| `divinationsById` | 卜算请求的锚点、规则版本、活动ID、观测时刻/范围、阻隔、结果事实与成本事务 | 与普通调查共享结果模型；不持有独立时钟或免费重抽的私有随机流 |
| 人物知情扩展 | `beliefs`按主题引用claims/observations及修订原因；公开和私知分开 | 不是世界真值；人物详情只读掌门合法知情投影 |
| 典籍/物品扩展 | 版本来源、复制关系、同源签名、已内化联系与改写事实的引用 | 不在每个物品上复制整条阴谋；隐藏机制通过定义与机缘引用关联 |

`schemesById`可用`schemeStage`表达`planned / preparing / active / compromised / settling / resolved`；此字段是谋局进展，不冒充人物活动的`phase`。每个实际传信、布阵、调查、卜算、施术、救援仍使用05活动阶段和唯一`worldTick`，每tick为100ms模拟时间。
事件维持04的阶段，不再为机缘复制一套事件结算；危险持续过程引用10的危机实例。同一损失、发奖、改版、泄露或暗线收束只产生一个幂等事务。
消息、暗线、参与身份、种子、已调查线索和既定结果保存到存档。恢复同一存档不能更换真假、重抽幕后身份、把该档已损失资质复原或让已断通路恢复。允许恢复较早的有效存档重新行动时，较早时点已确定的身份与机制不重抽；改变未来结果只能通过不同的实际选择与因果过程，不能靠重载洗出更有利的秘密。
可用命令包括：提出调查、按现有证据询问、请求卜算、披露/隐瞒掌门已知消息、准备/执行实际陷阱、停止自己的仪式、请求破局帮助。命令需检查权限与可达；请求NPC行动只创建邀请/机会。
生成式AI只可根据合法投影润色传信、对话或叙述；不能私自新增指控、改变消息真假、抽取修为、发出致死事实或编造第二幕后人，具体见11。

## 10. 内容与实现验收

| ID | 可观察的验收 |
| --- | --- |
| INTRIGUE-01 | 同一人物身份与修行道路不决定善恶；至少一名正道谋利者、一名异类守信者与有证据的邪修分别产生符合行为的后果 |
| INTRIGUE-02 | 能审计重要根链分母、标签与激活记录；同一链多条传闻不多算，稀世暗线率与算计率分开报告，40%不变成致死率 |
| INTRIGUE-03 | 三名转述同一来源者不算三份独立证据；诚实误认、真实省略、诱导与伪造分别能调查，核实不泄露后台真值 |
| INTRIGUE-04 | 每个稀世定义有完整作者卡，至少两条独立发现路径；正常基础法/资源和拒绝机缘不封死复仇可靠路径 |
| INTRIGUE-05 | 施谋者必须用已知信息、实际资源与准备时间；其锚点/能力/位置变更会影响进展，被破解后不临时新增万能后手 |
| INTRIGUE-06 | 线索在承诺/伤害之前存在，获得需要实际取证；明显风险提示不提前泄幕后身份，晚到结算文本不能补造预兆 |
| INTRIGUE-07 | 卜算需要锚点与真实施法活动，返回范围/时效有限的观察；非卜算路线可独立定位，重复查看/施术不能洗出更好命运 |
| INTRIGUE-08 | 玩家与NPC可经历同一危险版本、骗局与破局规则；NPC可能自主拒绝、识破、求助、逃离或失败，不因玩家注视才运行 |
| INTRIGUE-09 | 实际布陷有到场、材料、时间、触发与证据；没有远程直接处死人按钮，NPC改道、拒绝或获救会改变结果 |
| INTRIGUE-10 | 读档/刷新保留参与身份、真假、来源、已调查结果、物品、损失与解局；重复选择/结算不重复扣费、发奖或抽取 |
| INTRIGUE-11 | 谣言与纠正沿实际传播关系发生，秘密事实不瞬间广播；各势力和个人根据自身所知形成不同评价 |
| INTRIGUE-12 | 完成暗线有可见善后并持久收束；第一篇章仍可终结，不新增无限幕后层；AI关闭时同样可调查与完成 |
| INTRIGUE-13 | 主动为修炼屠城、其他重大罪行、真实暂态失控与伪称失控分别以既定真相/证据处理；不只凭伤亡判邪，不凭自称失控免罪，损害与受害者后果保存，未定责任规则不临场补造 |
| INTRIGUE-14 | 相同邪修事实下，不同门规、决策人所知、利益和资源可产生不同调查/清理门户/划界/悬赏/不行动；正魔标签与用户示例不构成固定策略，内部与外部处置分别留记录 |
| INTRIGUE-15 | 悬赏发布后仍经传播、获知、自愿接取、追查、实际行动和核实兑现；不即时定位/伤害/删NPC，真假指控可调查，报酬有来源且兑现幂等，受害与违约后果持久保存 |
| FATE-01 | 缩尺子篇链有真实收益、两个独立预兆、事前校勘与当场断流两条独立生机；拒绝仍能走可靠成长路线 |
