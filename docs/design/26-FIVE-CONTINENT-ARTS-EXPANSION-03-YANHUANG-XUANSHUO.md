# 五洲修行谱 · 炎荒与玄朔四十项

2026-10-11 作者评看稿。承接[五洲修行谱](19-FIVE-CONTINENT-ARTS.md)、[修行体系评看](21-CULTIVATION-SYSTEM-REVIEW.md)、[五洲修炼地](22-WORLD-CULTIVATION-SITES-REVIEW.md)与[第一批扩写](24-FIVE-CONTINENT-ARTS-EXPANSION-01.md)。本稿写 `Y-148–187` 四十项独立可学内容；品相、地点、人物与机制须经后续评看和同境样例校准。`炼／筑／丹／婴／化／合／渡` 分别指炼气、筑基、金丹、元婴、化神、合体、渡劫。范围指传承存在相应篇章，取得一卷不等于已获全文；续篇、器物、蛊群与设施沿原项目或实体记账，不另占目录号。

普通项目有师傅、可信卷本或同行工坊等可取得途径。心法在表中逐项注明实际供给、可用练位和成长取舍；无优选灵地时的基本练习与需专门条件的突破分开。魔道、鬼道和妖道是法门来源与修行传统，人物行为及责任另按事实判断。复合技只按一次动作结算，其材料、起手和异常积累不能叠领两门技法的完整收益。
