# 双岸递护与地契停遁 · 完整动作样例

2026-10-11 作者评看稿。本文展开 [Y-201《双岸递护阵图》](27-FIVE-CONTINENT-ARTS-EXPANSION-04-ZHONGTIAN-CANGLIU.md) 与 [Y-144《地契停遁》](25-FIVE-CONTINENT-ARTS-EXPANSION-02-QINGHENG.md) 两个已有目录号；各自仍只计一项可独立学习内容。取得目录记录不等于人物已经学会，本文也不是运行配置、游戏实现或验收通过记录。下列新增时长、精力、护持和结算数值均标为**设计试算**，用于核对动作与反制，尚不调整 [19](19-FIVE-CONTINENT-ARTS.md) 的目录预算、[20](20-ARTS-GROWTH-COMBAT.md) 的正式数值状态或 [21](21-CULTIVATION-SYSTEM-REVIEW.md) 的评看状态。

共用演算口径：世界坐标单位为米，每 `worldTick` 为 0.1 秒；以下 `t=0` 是一次会话内任取的整数世界步。命令先登记意图，人物仍须自主接受、到达、完成起势；暂停、后台、关闭不推进时间。每步按 [05 §4](05-RUNTIME-CONTRACTS.md) 的校验、移动／动作、已完成效果、逐人伤势／死亡、保存顺序处理。所有例子使用固定人物、场景、物件和战斗会话 ID；精力、神意、伤势及既成死亡只在同一权威状态里写一次，不由卷册或特效结算。

## Y-201 · 双岸递护阵图（二品百艺／多人结阵／兵家／筑基）

### 取得、站位与作用

中天河防教场持有筑基教案；甲、乙各自获得授课许可，理解同一 `Y-201` 阵图、练过左右桥头的交接，再分别同意参加这次河防。卷册归属、人物各自的理解／熟练、同意和撤回记录分开保存；一个人会图、另一人只看过图时不能起阵。至少两名**自愿**修士同时在实际场景中占据可达站位：甲守桥西岸入口，乙守桥东岸入口，二人可经未断的桥身互见交接信号，撤离者沿真实桥面通行。桥梁的通行、宽度、损坏和人员脚点照常受地图与碰撞约束。结阵知识不生成桥、阵旗、阵盘或独立护罩，也不占用修炼地的虚构容量；教场训练占真实导师与练场时间，战场起势占本人活动时间。

**设计试算：**两人都到位且完成 `10 tick` 共同起势，各扣 `2` 点精力；维持时每人每 `tick` 扣 `0.1` 点精力（最小计量单位为十分之一点，满十步合一整点）。只有双方仍自愿、清醒、能行动、守住各自桥头且桥面可达，阵才持续。撤回同意、倒下、离位、桥断、失联或任一人精力不足时，当步停止后续协同，已经发生的个人动作和伤势不回滚。退出无需额外等待；离位者按真实移动耗时撤离，其余人可独立格挡或另找同意者重新起势。重新加入须重验理解、站位和起势，不能沿用旧阵的进度。

阵效只作用在**两岸换防交接中的一次合法护撤动作**：轮值者有实际面向、射线和可护住的撤离者时，将该次动作原本可挡的量提高 **6%（设计试算，处于同境 5%–8% 协同检查带内）**。例如对同境来袭的一次攻击，按人物原有兵器、物抗／法抗、位置和护持先算出该动作原本可挡 `50` 点，则本阵在合法交接窗内可挡 `53` 点；这 `3` 点是该动作的一次协同收益，不让两人各领 `6%`，也不同时增加伤害、速度和治疗。两名阵员各自只能执行自身可做的护撤；没有可达受护者、视线被遮、未发生换防或有人离位时，收益为零。相同护持组只取最强有效项，普通总减伤仍受 [20 §一、§三](20-ARTS-GROWTH-COMBAT.md) 的预算与 80% 上限约束。第三人加入可轮值，不复制加成；人数和修为不相加为高境护罩。对高一大境界敌人的攻击仍按原有境界差和伤害通道结算，二品阵可争撤离时间，不能稳定抹平越境承伤。

实际命中造成的甲、乙及撤离者伤势各写在本人；甲挡击而倒下，不把其伤平均分给乙，也不让乙代替甲通过死亡检查。命中、稳伤和死亡由同一个世界步汇集后逐人裁定，符合 [10](10-CRISES-RESCUE-DEATH.md) 的永久死亡与救援时窗。掌门只可控制自己并提出同行战术，不能把乙的同意、站位或格挡写成强制命令。

### 可复演分支

以下操作是未来实机验收的**设计脚本**，不是现有命令名。起点固定为完好的桥、两岸可走、甲乙同为筑基且各有 `10` 点精力（设计试算）、双方已理解阵图且同意；撤离者丙与同境来袭者有稳定 ID、固定位置与同一战斗会话。记录每步人物坐标、活动阶段、精力、阵实例阶段、攻击来源与各人伤势。

| 分支 | 输入与世界步 | 应得事实 |
| --- | --- | --- |
| 正常 | `t=0` 邀请甲乙护撤，二人自主确认；各走到相应桥头后同在 `t=20` 开始起势，`t=30` 完成。`t=31–40` 丙过桥，甲乙交接；`t=35` 同境敌的一次攻击从西岸命中交接处。 | `t<30` 无阵效；`t=30` 各扣起势精力一次；`t=35` 只有合法轮值者的一次护撤获得上例 `50→53` 的试算收益，攻击余量仍给真正命中的人物。`t=31–40` 各按实际维持步扣精力；丙走到真实落脚点，战斗／撤离记录不复制。 |
| 拒绝／倒下／破位 | 复制起点，乙在起势前拒绝，则甲可自行守桥，阵实例不能进入生效；不扣乙的起势费。另从正常分支 `t=35` 前复制，令敌击倒乙或使乙被迫离开东岸站位，或桥在 `t=35` 结算断开。 | 拒绝显示本人意愿原因；倒下、离位或断桥在其实际完成边界停止后续阵效，`t=36` 的护撤按个人动作计算，不能沿用 `53`。乙伤势／死亡独立入账，甲已付费用不退、未发生的维持费用不扣；不会因阵散自动传送丙或清除路障。 |
| 暂停与存读 | `t=25` 起势中暂停并保存，反复打开阵图页、取消再排计划；读取后恢复到 `t=25`，继续至 `t=30`。另在 `t=35` 攻击结算后保存并重载一次。 | 暂停和读页不增加起势进度、精力消耗或阵效；取消若尚未完成，仅释放未来动作预约，已真实发生的成本保留。恢复时甲乙仍在原位置、各有各自活动和已完成起势进度；阵效只在完成边界成立。`t=35` 已结算的攻击、伤势和费用不重放。快进与逐步演算同结果。 |

## Y-144 · 地契停遁（四品神通／土·行动权／金丹—元婴）

### 学成、锚石与唯一改写

青衡古战场旧阵石的地脉道痕只提供可考证的观想契机。人物须先学土脉辨位、真实经历破阵，再由本人参悟修成 `Y-144`；导师与石痕不能直接授出可发动按钮。`Y-144` 独立记学成状态、来源与适用篇章，持有道痕拓本或锚石不等于学成。锚石是另有归属、位置、耐久的**实物**，需在可达地面由本人提前安放；这与 [22 §三](22-WORLD-CULTIVATION-SITES-REVIEW.md) 的道痕取得边界一致。

这是一条**行动权**规则改写：生效后 `30 tick`（3 秒），以锚石的实际平面坐标为圆心，距离 `≤5` 米且双足着地的人物，**不能开始新的身法／遁法动作**。边界 `5` 米算区内，超过 `5` 米才算离区；敌我、施者本人及友方一视同仁。普通步行、格挡、攻击、既有动作的合法收势及已结算位移仍走原规则；在起效前已经开始的合法腾空／遁法不被倒退或强制落地，空中人物也不满足“双足着地”。场景真实坐标、碰撞、路径、伤势及死亡均不改变。期限届满、锚石被毁或施者起效前被打断时按对应边界结束；锚石在一次完整发动后裂损，未预置实物不得远程点地代替。

**设计试算：**预置锚石占本人 `20 tick` 的到场布设动作；布设中断留下按实际进度可检查的实物状态，未完成者不能作有效锚点。起势前须本人有 `100/100` 神意、本战斗尚有可用发动次数、锚石仍完整、本人能行动且在允许作用距离内。开始起势时即扣 `100` 神意并占本会话一次发动额（被打断也不返还，避免零成本反复试探）；可见地面震纹持续 `10 tick`（1 秒，供同境反制的设计试算）。届满仍合法才生效 `30 tick`；成功期满锚石裂损。神意和会话次数沿 [21 §三](21-CULTIVATION-SYSTEM-REVIEW.md) 的共用战斗槽建议记在原人物／原会话，切镜头、读档或暂退不重置。锚石布设时长、破坏耐久和神意积累率须经实机再定。

**结算层解释：**停遁不制造命中、伤害或六组异常积累，故准入检查本身不触发束缚异常抗性，也不经过物抗／法抗减伤公式；它不是把“减速异常”换一个神通名。已经命中的普通攻击仍依物／法份额和异常抗性独立结算。反制在行动和空间层进行：见到震纹后可完成真实的打断或毁锚动作、先行腾空、步行离开半径；生效后可步行出界、破锚、由同伴干预。毁锚的攻击若有物／法伤害，仍按锚石自己的实体耐久与合法命中处理，不因此忽略人物抗性。对同境者，1 秒征兆应允许至少一条已学且可执行的反制路径；是否真的来得及取决于距离、站位、动作起手和伤势。对高一大境界者，地面准入条件仍按实际位置判断，但其原有速度、法门、破锚能力和境界差照常生效；停遁不给低境施者额外伤害或越境击杀保证。境界压制是否另设“破域”动作及所需成本留待实战评看，不能暗中让本条变成永久封移动。

### 世界步时序与可复演分支

以下固定金丹施者丁、同境目标戊、友方己、锚石和战斗会话 ID，起点锚石已在 `t=-1` 以前由真实布设完成，丁双足着地且距锚石 `2` 米（设计试算），神意 `100/100`，各人物坐标与朝向已知。以下 `t` 是相对 `worldTick`，不是现实秒表。**设计试算的确定时序**：`t=0` 的动作开始阶段校验锚石和神意，扣 `100` 并记一次发动，震纹可观察；`t=0–9` 共十步征兆，反制必须在合法动作完成边界发生；`t=10` 步开始时复核锚石／丁状态后启用，生效步为 `t=10–39`，`t=40` 开始前到期。若毁锚或打断动作恰在 `t=10` 的效果阶段完成，`t=10` 已开始的动作按该步起始合法性判断，随后在此步完成边界解除；不会把此步已结算的行动或死亡倒改。这个同一步优先层属于本例试算，正式动作配置须与 [05 §4](05-RUNTIME-CONTRACTS.md) 的统一结算层对齐。

| 分支 | 输入与世界步 | 应得事实 |
| --- | --- | --- |
| 正常 | `t=0` 丁起势；`t=9` 戊仍双足着地、距锚石 `4` 米，己距 `3` 米。戊与己在暂停时各排一个新遁法计划，恢复后均于 `t=10` 请求开始；丁完成起势后于 `t=11` 尝试新身法。戊改为普通步行，走出至 `>5` 米后再申请身法。 | `t<10` 无停遁效力；`t=10` 戊与己的新遁法、`t=11` 丁的新身法都被同一行动权条件拒绝并保留可理解原因，不扣被拒动作的执行消耗，不把排队当已施展。戊普通步行可持续，越界后的新申请按原动作条件执行；`t=40` 后区内人物也恢复普通准入。三秒不刷新任何人的伤势或既定死亡。 |
| 前置失败 | 从起点复制，换成未布设完成或已毁的锚石，或把丁神意设为 `99/100`（测试输入）；`t=0` 仍尝试发动。 | 校验拒绝且说明锚石／神意的实际缺口，不显示震纹、不扣神意或发动额、`t=10` 不产生领域；戊原本合法的新身法仍可开始。失败不得生成可用锚石或免费补足神意。 |
| 征兆反制 | 从 `t=0` 复制，戊已在合法路线，于 `t=8` 完成腾空，或友方在 `t=9` 完成毁锚／打断丁。另一次复制中戊只在 `t=10` 才开始腾空。 | `t=8` 已起的腾空继续，不被 `t=10` 倒改；`t=9` 毁锚或打断使 `t=10` 无领域，丁已扣的神意与发动额仍保存。若戊到 `t=10` 才从地面申请新腾空身法，则该新动作被拒；普通步行和可执行的格挡仍可用。锚石被毁有物件归属及损坏记录。 |
| 生效后反制／越境 | 从正常分支 `t=10` 复制；戊在 `t=15` 步行离区，或同伴在 `t=20` 击毁锚石。另以高一大境界目标重复同站位场景。 | 离区后下一合法动作可起；毁锚于完成边界解除领域，此后不再拒绝新动作。高境人物若仍着地且在区内，仍先受同一三秒准入检查，但可依自身已学飞行、步行或真实破锚动作脱离；任何伤害、抗性及死亡判定继续按原境界和动作，施者不取得越境伤害倍率。 |
| 暂停与存读 | 在 `t=5` 震纹期、`t=20` 生效期、`t=40` 到期后分别保存并读取；每处重复点施展与打开卷册，另将保存失败模拟为持久化失败。 | `t=5` 仍余五步征兆、已扣神意与一次发动额；`t=20` 余二十步有效期、锚石耐久与人物位置原样；`t=40` 领域已结束且锚石裂损，不因重载重开三秒。暂停与只读操作不动步数，重复命令不重复扣神意或重造领域。保存失败按 [05 §5](05-RUNTIME-CONTRACTS.md) 暂停并提示内存变化尚未落盘，允许导出；不得把已发生效果误报为已回滚。逐步与批量推进结果一致。 |

丁、戊、己如果在上述任何分支受到真实攻击，命中与有效治疗先在该世界步合并，之后逐人检查致死条件，原子记录死亡及遗物位置；停遁不能撤销死亡记录，也不能因读档重判一次。若丁在 `t=10` 以前死亡，起势被中断；若丁在领域已经生效后死亡，死亡与锚石状态按本例的持久事实继续结算，领域是否立即解除需在正式动作规则中固定，现阶段试算取**施者失去行动能力即解除**，并在同一步的完成边界执行，避免死者继续维持主动神通。

神意只来自同一战斗中的有效行动。土修按 [21 §三](21-CULTIVATION-SYSTEM-REVIEW.md) 的五行建议，在确有相应环境、目标和实际完成的土行攻守／破阵动作后按有上限的事件收益入账；自伤、与同伴互刷、原地等候、空放土术、反复毁造廉价锚石、暂停重试或重复死亡记录均为零收益。一次环境事件只按稳定事件 ID 计一次；NPC同规。具体每次收益、环境上限与会话结束规则仍是待决参数，不能用本样例反推出神意已经可刷或 100 点可随时补满。

## 评看结论与待定参数

两例共同检验 [19 §一、§二](19-FIVE-CONTINENT-ARTS.md) 的独立学习号和真实授业，[20 §一、§三、§五](20-ARTS-GROWTH-COMBAT.md) 的同境预算、抗性与目标完成比较，[21 §三、§四、§六](21-CULTIVATION-SYSTEM-REVIEW.md) 的神通／多人阵边界，[22 §三](22-WORLD-CULTIVATION-SITES-REVIEW.md) 的道痕获取，[25](25-FIVE-CONTINENT-ARTS-EXPANSION-02-QINGHENG.md) 与 [27](27-FIVE-CONTINENT-ARTS-EXPANSION-04-ZHONGTIAN-CANGLIU.md) 的目录原项，以及 [28](28-FIVE-CONTINENT-ARTS-LEDGER.md) 的计数状态。对照 [SR-XF-013](../requirements/items/SR-XF-013.md) 的动作时序、同行战术、暂停及倒地后果和 [SR-XF-014](../requirements/items/SR-XF-014.md) 的理解／熟练／授业分离；两项 D01、AC 与运行实现状态均维持原台账。

正式落配置前需用同境守桥和破域实战校准：护撤交接窗、`6%` 相对收益是否足以被玩家感知、阵员精力单价、锚石布设和耐久、神意有效行动的单次收益／环境上限、征兆的实际可读性、同一步毁锚优先层及施者死亡后的解除边界。检查目标是撤离人数、完成时间、各人承伤和资源消耗，不把试算数值当成已通过平衡验收。后续若采用，应分别更新动作配置、地图／物件／人物学习状态、存档兼容与对应 SR/AC，并在真实浏览器与同源旧档上验证；本稿本身不推进这些状态。
