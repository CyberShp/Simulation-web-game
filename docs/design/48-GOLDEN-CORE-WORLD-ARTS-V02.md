# 金丹复仇篇世界修行库 v0.2

2026-10-15。U-146 修订范围，R-46 作者内容方案。面向炼气六层开局至金丹初中期、有限复仇主线收束期间的玩家、门人及地方 NPC。当前是内容设计，具体人物、教学渠道、动作数值与特效仍须接入游戏。

## 1. 本次修订

上一版169项适合呈现主角成长路线，但不足以支撑地方世界的修行差异。本版保留全部169项并新增551项，形成720项可独立学习的内容草案；新增部分由72条小型谱系和47种独立散法组成。720是本次已写目录的规模，不是本篇永远不再扩充的上限，也不代表玩家单人应学会全部内容。

“完整”首先按用途检验：主要路线须有主修、攻击、防御、机动，并有侦察、调养、生产或特殊战术作为支撑；具体法门分别修炼。专门防雷、隔音或器具保护不能冒充普遍战斗防护，存在这种短板的分支须给出明确的兼修、防具与撤退来源。新增72条谱系各用7项刻画一个可检验的教学样例，7不是世界规则，也不表示每个持有人都学全或每条谱系都只有7项。成熟传承后续可有更多招式，零散传承也可以残缺，人物须实际寻找补足渠道。

本版重点补符箓与蛊道，两者均作为能独立立足的修行道路。兵器、五行、鬼心音幻、毒煞血咒、卜算、御兽、傀儡、阵法、丹医和灵植同时扩写。纯2D高清像素、人物自主、实际供给与同一世界时钟继续成立。

## 3. 玩家和NPC使用同一套内容

新增谱系中的NPC是具体持有者、实践者和授课者的作者配置。谱系下的七项配装是这个人物在相应境界、资源和准备均成立时可以采用的教学上限；初遇实际已学项、携带实例与熟练度须在人物配置里分别登记。不会因编入谱系就自动精通，也不会因为是NPC就凭空获得符箓、蛊群或阵材。

| 人物来源 | 核心传承如何重复 | 实际形成的差异 |
| --- | --- | --- |
| 正式宗门弟子 | 同一主修与基础课程广泛共用 | 修习篇章、师承支系、兵器、职责、熟练和兼修不同 |
| 小世家成员 | 共用有限家学与少量补课 | 财力、继承次序、外出经历与本人志向不同 |
| 游方师徒 | 一师少徒，可有同门 | 学到哪一段、是否得到私授、转修和个人改法不同 |
| 公开散本修士 | 纳息、护体、基础步法允许常见重合 | 主修残本、购入战技、生活工艺和实战经历形成组合 |
| 遗迹残传或重构者 | 同一残传可以被多人获得 | 缺页位置、校勘来源、兼容补法与真实代价不同 |
| 自创或改法者 | 少数人有可追溯的独立教法 | 新法须产生独立取舍；仅改招名不增加项目 |

散修的多样性来自真实传播与经历。世界生成先建立持有者、书本、师承和商路，再据人物的资质、收入、意愿与经历形成已学清单；不从720项中无条件均匀抽签。允许同门、同家或同一本散书重合；应检查一个地方的无关散修是否大面积碰巧同主修、同攻防、同身法，出现时补来源分布与学习差异。

人物不会永远保持预制配装。缺符、蛊群折损、兵器损坏、灵力不足、护卫对象离位或同伴退出，会改变其选择。NPC按自身目标和风险偏好决定继续、换法、求援或撤退，玩家只能直接控制掌门；授业、入门和取用私藏均保留同意与权限。

已学动作共用实际身体、手位、蛊群和器材。侦察蛊尚在外面，就不能同时充当身前护蛊；攻击蛊改作助行须实际返回并重新部署。双手结印、持盾、取药与操偶分别占用动作，不能把“同时学会”解释成“同时免费执行”。资源不够时先结束原动作；仅条目明确允许的动作可以缩配，要求固定四蛊或固定阵员数的动作缺员就不能发动。按真实位置与回收时间调配，回收失败则选择剩余手段。

72条谱系分散在已有地方生活圈、驿路来客及迁居者身上，不新增72家宗门，不把开局两家金丹宗门变成数十家金丹势力，也不要求每位金丹教习同时常驻青溪。各NPC在实体化时记录常住地、旅程与在场条件；同一教习不能同时出现在多个地方。替代渠道也是一份真实存在的教材或另一个持有者，若双方均消失就保留失传风险，不能凭刷新补货复活死者。

## 5. 符修与蛊修的完整玩法

符修以符性、蓄注和书写控制塑造功体。攻击可依实际媒介穿送、贴附、牵引或分区触发；防御可截流、改向、遮蔽或保护退路，均有方向、耐久和供给限制。备用符与现场书符互有取舍：预制占库存和准备时间，临书暴露起手且受打断。掌握制法不等于所有施符技术已会，采购成符的战斗符师也有成立的路线。

蛊修通过真实活体与本人功体建立有上限的饲养、感知或御使关系。甲蛊可护、丝蛊可束、鸣蛊可震、医蛊可清创，土水等分支改变可用地形；毒只是其中一种手段。蛊群有来源、数量、喂养、伤亡、活动半径和回收过程，补群需要培育或交易。本人、虫体与容器的承伤分别记录；控制距离、声味干扰、断供、蛊道隔离和正确清除提供不同反制。

两路都要能回答：主修怎么练，缺耗材如何保命，什么时候抢攻，什么攻击能防，什么攻击必须躲，战后怎样恢复。补给断裂时可用普通兵器和通用逃生技；跨路兼修依学习与兼容条件开放，不能用职业按钮禁止。

## 6. 来历、暗线与公开信息

谱系来历、持有人和原理为相关条目的共同来源，各条另写具体取得步骤。独立散法自带来源。暗线卡固定作者真相、实际触发、两种独立来源的线索、接受与拒绝的后果；没有暗线的明确记无。新暗线服务于当地师承、技术归属、资源和人物利益，不新增沈氏旧案幕后责任人。

玩家的典籍界面初次只显示公开来历和已知使用条件；作者卡、隐藏持有人目的及尚未发现的线索不提前泄漏。发现证据更新的是人物所知，不能在玩家作出选择后改写真相。主线的五脉可靠续篇、提前合法清算、旧完成档和有限责任链按47稿保持。

## 7. 施法、工艺与规则边界

特效逐项描述起手、作用形态和消散，使用纯2D高清像素。基础火星、水线、符笔、虫群、刀光与阵线可以复用绘制组件，但危险形状、方向、实际作用范围和可反制征兆必须准确。同类攻击要能通过轨迹或作用方式区别，不能单靠换颜色。

主修特效只出现在实际运功和周天变化；战斗护罩由已学防御动作产生。百艺的烟气、火候、碎屑和阵线对应实际工作步骤。符纸燃尽、蛊体死亡、节点断供及傀儡损坏后立即停止对应效果，视觉不继续冒充有效伤害或防护。

神通仍按21/47稿的局部规则改写与神意边界。本版扩写不把普通控场、伤害、视线遮蔽或临时增益改叫神通来填配额。炼气移动遵守真实路径，遁法逐项限制媒介与阻挡；金丹仍无无条件穿墙、全伤免疫、无限分身或回滚死亡。

## 8. 接入要求与验收边界

内容稿到运行配置还需要：创建实际人物和教材版本；建立章节及前置；把每项作用映射为具体动作、范围、时间、灵力、冷却和库存结算；配置自主学习、采购、施术和撤退；制作并核验对应特效。优先用符修与蛊修各一条完整样例验证获取—修炼—供给—攻防—撤退—战后恢复，再按相同契约接入其余内容。

逐项验收覆盖正常使用、缺资源、被反制、对手与NPC同规则、动作中断、存读恢复和战利知识取得。当前检查只证明目录数量、字段、引用、配装和来源描述的一致性，不证明720项实机玩法已经完成或同境平衡已经通过。原SR/AC实现与验收状态保持，设计证据新增。
