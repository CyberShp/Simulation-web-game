# 世界、江湖关系与第一篇章

基线：DB-2026-10-05 v1.1。本文是后续开发的目标规范，不表示这些内容已经全部实现。
优先级、变更流程及已确认设定见 [00-BASELINE.md](00-BASELINE.md)；字段权威与存档契约见 [05-RUNTIME-CONTRACTS.md](05-RUNTIME-CONTRACTS.md)。
新增具体人物、物品、地点名称是内容样例，可在保持规则与因果链的前提下替换；不得借改名改变固定主线。

## 1. 必须保持的调子

- 单机、无联机；关闭网页、浏览器后台冻结和离线期间不推进世界，不产生离线袭击或剧情损失。
- 玩家只直接操控掌门；弟子自主生活、接受差事和决定同行。人物选择与自主边界见 [01-CHARACTERS.md](01-CHARACTERS.md)。
- 掌门天资卓绝，出身修行世家，开局炼气六层；天才弟子仍可能超过掌门。
- 父母以生命掩护逃亡，主角携部分传承来到母亲旧日采药别院；逃亡伤势不永久降低资质。
- 第一大篇章是复仇与立足相互推进，结尾真正清算直接责任人，不追加无穷幕后黑手。
- 世界给玩家可理解的机会、代价和后果；不靠随机丢失唯一线索、不可预警倒计时制造难度。
- 人物在山院、世界、室内、战斗中保持同一身份，加入门派不会重新生成一个替代人物。
- 主线提供可信的前进路径，经营允许停留、养伤与准备；小而精的山院也是有效路线。

## 2. 参考设计与边界

| 参考方向 | 采用的关系 | 不直接照搬的内容 |
| --- | --- | --- |
| 经典单机《天龙八部》 | 选择改变名声、势力、个人关系，进而影响机缘与传承 | 把所有善恶压成一条全局分数；复刻原作人物与剧情 |
| RimWorld | 事件结合现状产生，并有预警、压力与恢复节奏；出行带来留守代价 | 每个周期必须灾难；随机事件封死主线 |
| 《了不起的修仙模拟器》 | 具名外部修士、门派态度、凡间据点与传承互相影响 | 同时模拟所有远方居民的逐步走路与全世界战争 |
| 《模拟人生》及生活模拟 | 世界人物有日程、私人目标、社会关系与可见行为 | 让掌门逐个控制外部 NPC 的生活细节 |

本表规定我们采用的设计方向；具体效果以下文为准，不以任何参考游戏的未核实行为补写规则。

## 3. 三个空间尺度与同一世界

| 尺度 | 负责展示 | 状态来源 |
| --- | --- | --- |
| 大世界 | 区域、聚落、门派、路线、已知事件、队伍位置 | 区域与地点记录、行程实例、已公开情报 |
| 宗门／峰域总览 | 实际建筑分布、主持者、资源与事务摘要 | 同一宗门及场景实例，不额外复制建筑 |
| 可操作局部 | 真实地形、建筑内外、人物、交互目标与战斗 | 对应 `localSceneId` 的持久场景实例 |

大世界标记允许简化为符号；进入局部后必须呈现实际空间，不能把标记当作可操作建筑。
总览和局部的尺度切换、营造占地、屋顶淡出与人物命中规则见 [03-SPATIAL-ART.md](03-SPATIAL-ART.md)。
每个可进入地点具有稳定的场景实例；离开再回来保留已拆路障、救出的居民、设施损坏与建设变化。
场景可以按首次进入生成地形细节，生成种子立即写入存档；再次进入不能重新抽取地形、宝物或 NPC。
战场属于所在地点的局部空间，复用通行与遮挡数据，不另造一个无关联的漂亮背景。
世界视图只显示玩家已知信息；管理员式全知数据只允许存在于开发诊断界面。

## 4. 区域、地点和路线

| 对象 | 稳定字段 | 规则 |
| --- | --- | --- |
| Region | `id, name, bounds, locationIds, factionIds` | 区域是地理容器，不直接作为全部交互的替身 |
| Location | `id, regionId, localSceneId, type, ownerFactionId` | 山院、村镇、遗址、驿站、门派据点具有独立状态；局部位置沿用 1 世界单位＝1 逻辑米 |
| Route | `id, fromId, toId, terrain, costModelId, conditions` | 路线有方向、耗时、天气与通行条件 |
| Discovery | `subjectId, discoveredAtTick, sourceFactId, knowledgeLevel` | 传闻、确认、到访互不混同 |
| Travel | `id, partyPersonIds, routeId, progress, durationTicks, supplies, status` | 队伍成员只引用人物 ID，不复制人物对象 |

地点需要分别表达 `discovered`（听闻／地图发现）、`known`（掌握可用位置）与 `accessible`（目前可到达）。
这三个字段可由发现记录与访问条件投影生成，禁止维护互相矛盾的三份事实。
传闻只告诉玩家大致位置与线索；确认后显示路线，通行受地理、天气、关系与补给约束。
章节决定相关证据何时出现；地理决定怎样抵达；关系决定是否接见；成本决定是否值得现在出发。
人口、宗门等级不能单独锁死整个世界；组织里程碑只开放主持与管理能力。
没有达到推荐境界的危险地点仍应区分“可前往但危险”和“实际无法通行”，不能混写成同一锁。
已知但不可达的地点显示原因与可执行解除方式，例如“渡桥损坏：可修复／绕行”。
安全归程始终可查看；故事强制封路必须先预警并提供可完成的替代出口。

## 6. 第一大篇章《余烬立山》

现有暂名为栖霞沈氏、云岫山、赤嶂门与韩厉川；角色姓氏可调整家族称谓。
父亲是筑基中期阵师，母亲是筑基初期丹师；家族依靠支脉灵地、灵植、丹药和护脉阵术生活。
韩厉川为筑基后期，灵地衰败使其觊觎家族灵脉；交易借贷渗透、收买外聘阵匠、破阵夺脉与伪造邪修罪证共同构成旧案。
父亲逆转残阵挡追兵，母亲发动遁行符送走主角；双亲身亡为固定起因，不能后续反转成无代价团聚。
带出完整基础炼气法、残缺筑基篇、药理丹方笔记、护脉阵手札、旧玉简和少量物资。
藏有典籍、知道名称、理解内容、练成与能够传授是不同状态，见 [02-EQUIPMENT-ARTS.md](02-EQUIPMENT-ARTS.md)。

| 五段 | 必须产生的进展 | 可变的方式与后果 |
| --- | --- | --- |
| 雨夜余烬 | 到达别院、理解逃亡、恢复伤势与基础操作 | 观察顺序、掌门起居与第一次行动 |
| 隐姓山居 | 山院能维持生活、结识首批人物、恢复生产 | 救助方式、招募意愿、工作与学习选择 |
| 旧账新证 | 获取交叉证据与可靠筑基知识 | 坊市账册、阵匠证词、遗址阵纹三选二 |
| 削羽断援 | 完成至少两种削弱途径，准备归乡 | 救人、断粮、拆阵、公开证据四选二 |
| 重返栖霞 | 解除外阵、战胜韩厉川、取回遗物、选择传承归处 | 经营准备改变战斗条件；故地重建或回云岫 |

该表是叙事五段；实现可以拆为多个可靠任务节点，不得把现有 11 步误称为另一个主线。
“证据三选二、准备四选二”是沿用现有内容的首轮配置，不是用户确认的永久阈值；修改配置仍须保证多条可靠途径。
核心证据有多条可靠途径，不由随机访客是否刷出决定；知识缺口不能只靠稀有掉落补全。
NPC 可能拒绝参战、留守或离开；复仇不要求指定随机资质弟子必须加入。
削弱准备明确改变兵力、补给、阵势或地方态度，必须在场景和战斗规则里兑现。
韩厉川被清算且伪证昭雪以后，篇章设置永久完成标记；重复到访不能重新生成旧仇奖励。
结局“重建栖霞”保留云岫根基并增加实际可经营据点；“归云岫”保留故地纪念与访问价值。
完成后继续经营、修行、传授和分峰；不强制重新开局，不无限追加更大的幕后操控者。

## 7. 侠义、势力与个人关系

| 层次 | 表达 | 可影响内容 |
| --- | --- | --- |
| 江湖名声画像 | 公开范围内的守信、仁义、威望与恶名事迹 | 来客、陌生人初始判断、公开委托与传播 |
| 各势力立场 | 每个势力的信任、利益、威胁感及具体旧账 | 通行、交易、授业、结盟、警戒与敌对 |
| 各人物关系 | 人物间的信任、情感、恩债、承诺与已知经历 | 同行、投奔、告知秘密、托付或拒绝 |

三层独立存储因果记录；不是一条全局善恶数值，也不允许靠捐款将所有敌对记忆清零。
仁义和恶名可以同时存在：玩家救助村民却背弃商约，不同知情者会作不同判断。
复仇目标、手段、证据与附带伤害共同影响评价；清算凶手不自动等于作恶，殃及无辜也不能用复仇抵消。
每次变动引用实际事件、知情者和传播范围；秘密行动不立即向所有势力公开。
传闻可以失真，发现证据可以澄清；真相记录与人物当前相信的信息必须区分。
声望只影响机会和判断，不直接增加伤害，也不能取代适性、境界、师承及材料条件。
界面显示具体事迹及主要立场原因，避免迫使玩家猜隐藏的全局善恶公式。

## 8. 外部人物、门派和凡间据点

外部 NPC 使用统一人物模型，拥有身份、外观、境界、目标、日程、关系、装备、所知事实和记忆。
首次生成后保留人物 ID；散修来访、出山相遇、受伤留住和入门不能分别创建四个人。
具名 NPC 有私人诉求，不会因为掌门拥有足够声望就自动交出全部功法与宝物。
NPC 可以隐瞒、误解或欺骗；可查证的矛盾通过证据、其他证人和实际场景表达。
NPC 未公开私事只存在于权威状态，人物卡不能提前显示“此人其实是叛徒”。
远方人物采用规则定义的日程阶段与区域摘要；掌门/旅队实际到达后可转换为局部模拟，保留既有位置约束、伤势、活动、关系和持有物。仅切镜头、定位人物或打开地图不改变模拟层级、进度与产出；山院留守仍执行真实工作、工位和物流规则。
门派持久记录资源状况、主要人物、立场、据点与已发生的冲突；变化有来源、幅度和历史记录。
不模拟每个远方修士的每秒行动；先实现与当前地区有关的有限势力及事件链。
凡间据点提供药材、商路、劳作或情报，同时有供给和保护责任，不能每天凭空产出无限资源。
据点发展为区域摘要加可进入局部场景；玩家到访时应看见之前修路、救灾或安置的结果。

## 9. 出行、留守与战斗

出行准备显示预计耗时、路线、补给、风险、同行意愿和留守缺口；数值由运行时模型计算。
人物自行接受同行邀请，拒绝时给出已公开的原因；玩家不能把反对复仇的人直接拖进队伍。
同一人物在旅队中不能同时工作、睡在院内或参加另一次差事。
出行真实消耗口粮、药品、精力与时间；物资不足允许补给、改道或返回，不凭空扣成负数。
出山期间山院继续按同一游戏时钟经营；留守医者缺失、工位空缺和学习暂停是可见的机会成本。
唯一持久时钟为整数 `worldTick`，1 tick＝100ms 模拟时间；期限用 `*Tick`，时长用 `durationTicks`，禁用现实日期倒计时。
`ticksPerDay` 可配置；首轮以现有 120 秒／游戏日为兼容基点（1200 ticks），不作为最终节奏的永久平衡承诺。
旅途等待不能变成强迫玩家离开网页的现实时间门槛；可安全加速的条件见运行时契约。
行程用“准备、在途、到达、探索、战斗、返程、结束”表达；保存任何阶段都能可靠恢复。
局部战斗采用基线规定的可暂停即时形式：掌门直接操作，同行者依能力和意愿自主行动。
保留当前移动、攻击、术法、格挡、闪避、落点预警、障碍视线与可撤退基础，不默认为回合制。
暂停规则、技能装备与战斗资源由 [00-BASELINE.md](00-BASELINE.md) 与 [02-EQUIPMENT-ARTS.md](02-EQUIPMENT-ARTS.md) 统一定义。
失败保留伤势、损耗和已取得证据，给予疗伤再来的路径；不能同时重复扣装备和旅途成本。
掌门默认战败可脱险养伤或进入明确失败/读档；NPC在真实危险中可濒危直至永久死亡，自救/求救与玩家干预按[10](10-CRISES-RESCUE-DEATH.md)。不按道途、外出次数或随机日结算判定必死。
致死危险有过程和可获取预兆；斗法耗世界时间，进入战斗不冻结山院或其他危机。掌门永久死亡/继承仍后置，不篡改原存档。
核心证人因其他事件无法接见时，档案、第二证人或阵纹提供可靠替代，不自动复活也不永久堵主线。

## 10. 事件生命周期与导演

| 阶段 | 进入条件与提交内容 |
| --- | --- |
| `trigger` | 检查章节、事实、地点、时钟、人物与候选条件；不扣费、不发奖励 |
| `eligible` | 条件满足且冲突、风险预算允许；记录可用事件，不承诺玩家已经参与 |
| `reserved` | 确定实例、参与人、种子、目标与保留窗口；抽签结果先写档 |
| `active` | 事件显现在场景／消息，接受动作与选择；维护成本和进行中状态 |
| `resolved` | 选择、成本、关系、物品、事实、场景变化作为一次事务提交 |
| `cooldown` | 可重复模板进入冷却，唯一事件永久保留 outcome；禁止重新领取 |

触发条件不是每帧重抽骰子；事件实例拥有稳定 ID 与 `resolutionTransactionId`。
唯一事件的种子、结果、唯一物品实例和领取记录随存档持久化；刷新、返回、重复点击不能重抽或复领。
已激活事件的期限使用模拟时钟；后台暂停后不追算现实经过时间。
关键主线锚点不得因唯一证人死亡/失踪永久锁死；人物危险在未暂停时仍真实推进，备选证据负责恢复可靠路径。打开阅读/暂停停止全世界时钟，普通经营不是对远方NPC的无敌保护；不可逆关键选择清楚确认。
可选事件可有期限，但提前显示窗口与后果；失败允许世界留下不同结果，不承诺所有支线都能全拿。
导演参考食物、伤病、近期冲突、生产容量和事件负载选择压力；高压力后安排可预测的恢复窗。
到达预警阶段后显示发生来源和准备方式；敌袭不能从背景里无声产生，也不固定频率追杀新手。
同一时间不可激活争用唯一 NPC 或唯一场所的互斥事件；主线锚点优先保障可靠路径。
天气、访客、委托和主线使用独立随机流或明确的抽取序列，调整表现不能改变命运序列。
动态反应必须通过受控事实与事件规则发生，不使用生成文本直接修改资源或剧情状态。

## 11. 证据与知识

事实 `Fact` 记录真实世界变化；情报 `Knowledge` 记录某人听到、相信或确认的内容。
证据 `Evidence` 引用可观察的物品、证人或场景痕迹，记录来源、真实性与验证状态。
玩家的任务日志仅展示掌门已知内容；尚未验证的指控标注“传闻／待核实”。
按首轮三选二配置验证至少两项相关证据；互相印证条件由事实规则计算，不能只计不相干物品数量。
发布证据只传播已经掌握的内容；公开失实指控产生可解释的关系后果与纠正途径。
日志提供下一步可调查对象与地点，不揭露未被发现的幕后身份或 NPC 内心秘密。

声明/口信使用09的claimsById。每次传播记录原始主张、观察时刻、发送/接收时刻和转述来源；三名转述同一来源者不是三项独立证据。天气预报、失联口信、洞天地图和秘籍宣传均可真实但陈旧、误认、省略或诱导，人物相信不等于世界确认。

暗线需要真相卡、利益、独立线索和可解释破局，不要求全部机缘恶意；约40%按09明确操纵标签统计。真实竞争与公开职责另记。NPC危机、消息传递和斗法按同一时钟持续推进，发生死亡后保留遗物/记录/第二证人的可靠取证路径，不能重生一个证人抹平损失。

## 12. 开局前 15 分钟的目标体验

以下时间为设计目标，尚未实测；不限制玩家停留和观察。

| 目标时间 | 可见体验 | 系统引入 |
| --- | --- | --- |
| 0—3 分钟 | 雨夜片段、父母牺牲与旧院落脚；能认出掌门并移动、看伤势 | 身份、主线动机、移动与选择 |
| 3—6 分钟 | 实际进入小屋调息、保管遗物，来客在门外等待 | 室内外、疗伤、物品与人物交互 |
| 6—10 分钟 | 为求药者找药、交谈；留院意愿有缘由，药田开始恢复 | NPC 目标、关系、第一项营造与生产 |
| 10—15 分钟 | 完成首次营造并看懂人物到工位；后续15—30分钟完成首次产出、研习与山谷线索 | 空间与行为先成立，再引入传承、世界与留守代价 |

新玩家应知道自己是谁、为何在此、眼前谁需要帮助、下一件事怎样做；不同时开放所有系统。
来客具有可见身体、姓名、目的和等待位置；任务不靠浮空边框替代人物，操作验收见 [06-OPENING-ACCEPTANCE.md](06-OPENING-ACCEPTANCE.md)。

## 13. 贯穿系统的代表事件链

样例“雨后伤匠”：受胁迫的炼器师在药径负伤，掌门选择救助、索价相助或暂时拒绝。
救助后他进入山院真实床位疗伤；门人照料、药材和时间产生实际消耗与关系记忆。
恢复后他愿意暂住并提出修复旧法器；玩家营造匠坊，他实际使用工位研究图谱。
图谱注明部件在驿站与遗址，掌门邀请同行、准备补给；留守生产因带走的人手而变化。
部件、法器与相关技艺按装备和武学规则入库、练习，不能直接给全门派永久套装加成。
匠人提供关于外聘阵匠的线索；可信证据增加后，韩厉川察觉调查并改变当地警戒。
村民感谢救助、赤嶂门认为其受庇护、匠人保留个人恩债，这三层反应可以同时存在。
拒绝救助产生可见后果和另一条取证途径；不能因未救此人而彻底无法筑基或复仇。
上述是内容样例，不等同现有陆知微主线；新事件不得悄然重写她既有的赠药救家人经历。

## 16. 必须通过的验收

- WORLD-01：听闻、确认、可通行分别显示；未达人口门槛仍能进入已具条件的山谷或坊市。
- WORLD-02：局部修路、救人、移动设施后离开、刷新、读档，返回保持同一地点和变化。
- WORLD-03：同一人物外出、战斗、负伤归山保持 ID、外观、装备与记忆，无分身同时生产。
- WORLD-04：出行成本和留守缺口可观察；暂停／离线期间行程、伤势、事件期限全部停止。
- WORLD-05：救助同一人可以同时改善个人关系、提高地方信誉、恶化敌对门派态度，原因可查。
- WORLD-06：唯一事件刷新不重抽，重复选择不二次扣费或发奖励；互斥事件不争用同一人。
- STORY-01：不出现唯一随机筑基材料或随机证人堵主线；当前三选二配置下始终存在可靠路径。
- STORY-02：四种准备分别兑现不同后果；拒绝某次支线或某名弟子拒绝同行不封死复仇。
- STORY-03：韩厉川战败、旧案清算、遗物取回和结局选择永久保存，故地与云岫可以继续经营。
- STORY-04：掌门战败能恢复/失败读档且保留已获证据；NPC危机死亡有过程及替代取证，无硬核删档或无穷幕后黑手。
- STORY-05：不知道的秘密不显示成确定事实；欺骗与传闻可通过调查验证和更正。
- STORY-06：开局仅凭场景与清楚引导能完成第一个交互、营造、生产与世界发现；时间目标以实测校准。
