# 五洲功法谱 · 目录规划与云岫首批

设计增补：2026-10-11。关联 [U-112](DECISIONS.md)、[功法规格](02-EQUIPMENT-ARTS.md) 与 [SR-XF-014](../requirements/items/SR-XF-014.md)。本稿是内容设计，不表示典籍、动作、人物授业或高境界玩法已经进入游戏。

## 一、七百部的计数口径

五洲主世界以**约七百部独立传承**规划具名目录。七百是长期内容规模的设计目标，不是世界中所有人写过的功法总数，也不要求开局一次呈现。已学传承、书册实物、抄本版本、师父口授与招式动作保持各自身份。

- 一门有独立修炼原理、传授谱系、使用条件和实际用途的传承计一部。它可以同时含心法、招式或技艺，但按主导用途只占目录一个位置。
- 同门炼气篇、筑基篇及以后续篇、残卷、批注本、译本和口传版本仍属同一部。分支只有形成独立功体或独立可传的技法，才另立一部。
- 独立流传、可单独学习的术法、身法、丹方体系、阵图或工艺可各计一部；单个动作、单张普通药方和装备技能不自动计数。
- 一部传承可以在多洲传播，只以发源／主要成形地或“跨洲共通”归一处。不同族群和道途都可在各洲发展，不按洲锁定职业。
- 七百目录中的一部至少要有可追溯来源、篇章范围、修习门槛、实际效果、使用代价、可教授范围及与其他功体的关系。稀世或牵涉重大事件者再按 [12](12-CONTENT-AUTHORING.md)补作者真相卡、线索和后果。

### 分阶段写作

1. **云岫首批四十部**：本稿给出名称、主类、来源、可见作用和关键限制。它们构成地方社会与第一篇玩家会遇到的功法谱，不等于四十部都能由玩家取得。
2. **青衡洲其余一百四十部**：先按六大宗门、王朝、世家、地方组织、散修与公共传授分别写传承谱系；未定的五家大宗名称保持待定。归元道宗的五行主脉、剑与阵按已确认方向展开。
3. **其余四洲和跨洲共通五百二十部**：随地理、人物、组织与修行道路逐区写入。敕封神道王朝所在洲尚未确定，相关功法暂不强行归洲。
4. 每部进入可玩内容前，再补章节、学习与授业条件、数值、动作范围、来源事件、知情投影及存读验收。首篇实际游戏仍只覆盖炼气至筑基。

## 二、功法怎样进入游戏

一人有一门当前主修，可以选择相容的辅修、独立术法、身法和生产技艺。相容由具体功体、身体状况、材料与练习时间判断；不同五行本身不等于互斥。转修保存旧知识，却要付出休整与重建功体的实际时间。门人依据志向、适性、师承与风险自主择学；掌门负责开放典籍、安排导师和提供资源。

功法从**听闻 → 得到可读版本或口授 → 理解篇章 → 实践练熟 → 有资格教授**逐层推进。残卷不能补出缺页，名师也只能教自己理解的部分。普通入门法门较普及；越往上，完整篇章、可靠导师和突破资源越难取得。功法的价值由用途、适配、完整度及代价决定，不凭年代或稀有颜色排序。

战斗传承至少改变距离、区域、起手、持续、移动、护持或消耗中的一项；技艺传承必须进入实际工位、材料和产出。效果有真实位置、动作时间、资源与冷却，暂停和只读卷册不推进练习。宗门、各峰及个人可有不同典籍所有权和授业许可；一人入门不等于其私藏传承自动归宗门。所有人的理解、熟练、来源、篇章和导师关系写在同一持久世界里。

## 四、后续逐部设计的准入表

每一部进入正式内容表时按以下顺序核对：

1. `artId`、主要成形地、传承谱系、主类和版本关系；篇章续写不另占目录名额。
2. 炼气至高境各可用篇章的真实范围；第一篇只实施炼气／筑基，并记录不可用章节的来源。
3. 获取人物与地点、书册或口授版本、许可和替代来源；无主线必需内容仅靠一次随机掉落。
4. 学习前置、理解与熟练收益、师授条件、可中断活动、材料／精力成本、转修与冲突。
5. 具体动作或生产流程的距离、时间、空间、资源与失败结果；至少一个区别于近邻传承的可观察用途。
6. 稀世传承的固定真相卡、可追查线索、持有人利益及拒绝／失去后的持续后果。
7. 玩家知情、NPC已知、作者真相分层；典籍、人物、地点与时间在保存、读取和迁移后保持同一事实。
