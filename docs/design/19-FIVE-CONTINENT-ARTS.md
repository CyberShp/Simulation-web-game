# 五洲修行谱 · 分类、万法分支与云岫首批

设计增补：2026-10-11。关联 [U-114](DECISIONS.md)、[修行成长与斗法数值](20-ARTS-GROWTH-COMBAT.md)、[功法规格](02-EQUIPMENT-ARTS.md) 与 [SR-XF-014](../requirements/items/SR-XF-014.md)。本稿是内容设计，典籍、动作、人物授业和抗性尚待游戏接入。

## 一、四千九百种的计数口径

五洲主世界以**约四千九百种可独立学习的修行项目**规划长期目录。传承是一套师承和典籍的组织关系；“功法”可作为玩家对修行内容的总称，系统内部则分清心法、武学、术法、身法、神通和百艺。一本传承里若有一门心法、三式能分别学习的剑招、两道术法与一种神通，目录计七种；书册、传授关系和人物熟练度另记。

- **一项一号**：能单独研习、掌握、授业并在战斗或经营中产生可辨结果，才占一个目录号。同一项的炼气、筑基及后续篇章、残卷、抄本和口授版本共用项目号；动画段、伤害数值和重复药方不另编号。
- **传承成套**：一本经卷可引用多个项目号，宗门也可把不同来源的项目编成课程。人物得到经卷只获得对应篇章的接触机会，尚须分别学习。
- **分支成立**：变体若有独立教法、前置与实际战术／生产取舍，可以单列；只换五行特效、改名称或提高伤害的版本沿用原项目。
- **传播归一**：跨洲流传的同一项目只计一次；来源、持有人和各地版本可以有很多。独立异界待对应世界的修行与法则设计明确后另建目录。
- **逐项规格**：每种必须有类型、大道标签、来源、篇章、前置、作用、成本、失效边界及师授条件。重要稀世内容另按 [12](12-CONTENT-AUTHORING.md)补真相卡和线索。

### 项目类型

以下是学习与使用方式的分类，人物可跨类修习；一个项目只选一种主类型，同时可拥有多个大道标签。

| 类型 | 学会以后具体得到什么 | 规划数 |
| --- | --- | ---: |
| 心法 | 修炼灵力、功体和突破准备，分主修与相容辅修；心法自身可附带教学，但具体攻击另列可学项目 | 700 |
| 武学 | 剑、刀、枪、棍、拳掌、弓戟等兵器或身体技法，给出实际攻击、格挡和战斗站位 | 1400 |
| 术法 | 五行、符、鬼、毒、心念、军阵等主动施术，按距离、范围、引导和耗用生效 | 1450 |
| 身法与遁法 | 步法、御物、追击、脱离、隐匿和跨地形移动，服从相应境界与空间条件 | 550 |
| 神通 | 修为、身体或道意深入结合后可经修炼形成的独立能力，有明确条件和代价 | 400 |
| 百艺 | 制符、炼丹、炼器、布阵、制偶、养蛊、卜算、医植等可执行工艺与研究法 | 400 |

心法与武学可以同属一套剑宗传承，却各有学习状态。神通以形成和使用机制区分于普通术法，不按威力大小自动升级名目；无法学习的纯先天特性记在人物身上，不占目录号。符箓的制法归百艺，使用符箓的独立施术诀窍可归术法，符纸实物不占目录号。

### 大道覆盖与交融

大道标签说明修行原理、材料和战术领域，不把人物锁成固定职业。剑、刀、枪、棍及其他兵器可分别有近战、御物、阵列与炼体分支；金木水火土各有心法、术法、神通和生产用法；傀儡、符箓、鬼道、魔道、妖道、毒道、兵家、心灵、蛊、卜算同样可与五行和兵器相交。正、魔、鬼、妖是传统和组织语境，不直接标善恶；毒性是实际作用机制，须写暴露、积累与解毒条件。合欢法作为心念、双修等道途中的小支，跨全目录规划最多二十四种，计入相应主归档，不另加数量。

## 二、学习与传承关系

一人有一门当前主修心法，可以选择相容的辅修心法、武学、术法、身法、神通和百艺。心法提供灵力运行与功体条件，**攻击、防御和移动由各自已学项目提供**；一套传承可以把它们作为课程组合，但不能因为学会心法便自动会其中所有招式。相容由具体功体、身体状况、材料与练习时间判断；不同五行本身不等于互斥。转修保存旧知识，却要付出休整与重建功体的实际时间。门人依据志向、适性、师承与风险自主择学；掌门负责开放典籍、安排导师和提供资源。

功法从**听闻 → 得到可读版本或口授 → 理解篇章 → 实践练熟 → 有资格教授**逐层推进。残卷不能补出缺页，名师也只能教自己理解的部分。普通入门法门较普及；越往上，完整篇章、可靠导师和突破资源越难取得。功法的价值由用途、适配、完整度及代价决定，不凭年代或稀有颜色排序。

战斗传承至少改变距离、区域、起手、持续、移动、护持或消耗中的一项；技艺传承必须进入实际工位、材料和产出。效果有真实位置、动作时间、资源与冷却，暂停和只读卷册不推进练习。宗门、各峰及个人可有不同典籍所有权和授业许可；一人入门不等于其私藏传承自动归宗门。所有人的理解、熟练、来源、篇章和导师关系写在同一持久世界里。

游戏内修行谱按**已知传承 → 其中可见项目 → 当前人物可学条件**阅读；人物页先显示本人已学的心法与可用攻防，再展开武学、术法、身法、神通和百艺。大量内容通过类型、大道、境界、来源及所在峰藏书筛选，默认只展示人物实际知道的项目；传闻可显示名称和来源线索，不能直接揭示秘本全文或作者真相。四千九百种是世界目录规模，不形成玩家首屏的一张长名单。

### 青岚传承的完整关系

沈氏“青岚”是一套传承，不是一种包办所有行为的技能。`Y-001`负责主修心法，`Y-041`提供开局已经会用的中距攻伐，`Y-042`是可进一步练成的贴身武学，`Y-043`是主动护持，`Y-014`负责短步，`Y-054`负责有锚点的卜算。各项有自己的篇章、理解、熟练和授业资格；学会 `Y-001`不会自动练成其余项目。普通持械攻击、守御和闪避仍是人物基础动作。

现行战斗的“青岚术”是一项固定动作，而运行中的 `qingyuan` 定义只提供修行增益。正式接入时将这项已可使用的战斗行为映射到 `Y-041`，并在旧档保留掌门原有使用资格、资源与学习结果；`Y-042–043`及其他新稿须按实际来源取得。此处只确定设计关系，没有修改战斗代码或存档。

### 接触范围与第一篇路线

`Y-001–020`以家传、散修、坊市或普通匠师为主，部分基础内容有可靠取得途径；具体交易、师父意愿、所有权仍按世界事实结算。`Y-021–036`主要使地方势力拥有辨得出的修行与生产能力，人物已知其名不等于掌门可以索取秘本。`Y-037–055`补足攻防、兵器、心灵、蛊、卜算与交融，`Y-056–067`加入魔道、妖道、毒和复合攻防；属于不同组织的内容各守其来源。

三条路线都以已学的 `Y-001 + Y-041`为共同根基。剑术机动再修 `Y-012 + Y-014`，以后寻 `Y-009`；药理养脉从 `Y-002 + Y-016`起步，循 `Y-008`深化；阵护守势从 `Y-013 + Y-007`起步。三路共同保留基本攻击、防御、撤离与可靠筑基途径，选择支路不截断复仇篇。掌门取得典籍只获得相应项目和篇章的接触机会，其他人物需各自学习和实际授业。

## 四、后续逐部设计的准入表

每一部进入正式内容表时按以下顺序核对：

1. `artId`、主要成形地、传承谱系、主类和版本关系；篇章续写不另占目录名额。
2. 炼气至高境各可用篇章的真实范围；第一篇只实施炼气／筑基，并记录不可用章节的来源。
3. 获取人物与地点、书册或口授版本、许可和替代来源；无主线必需内容仅靠一次随机掉落。
4. 学习前置、理解与熟练收益、师授条件、可中断活动、材料／精力成本、转修与冲突。
5. 具体动作或生产流程的距离、时间、空间、资源与失败结果；至少一个区别于近邻传承的可观察用途。
6. 稀世传承的固定真相卡、可追查线索、持有人利益及拒绝／失去后的持续后果。
7. 玩家知情、NPC已知、作者真相分层；典籍、人物、地点与时间在保存、读取和迁移后保持同一事实。

本批确定四千九百种的计数、类型与大道覆盖预算，云岫六十七种已有来源和机制初稿。其余四千八百三十三种尚待逐项写作；云岫新稿也需进一步补章节卡、具体获取事件和实机动作验收。首轮数值与抗性方案见[修行成长与斗法数值](20-ARTS-GROWTH-COMBAT.md)。SR-XF-014 的 D/I/V/R 状态按需求台账保持，不由目录数量推进。
