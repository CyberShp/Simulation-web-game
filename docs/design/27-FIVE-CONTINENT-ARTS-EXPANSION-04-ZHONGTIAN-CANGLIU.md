# 五洲修行谱 · 扩写第四批：中天与沧流

2026-10-11 作者评看稿。承接[五洲修行谱](19-FIVE-CONTINENT-ARTS.md)、[多轴品级与阵法](21-CULTIVATION-SYSTEM-REVIEW.md)、[五洲修炼地](22-WORLD-CULTIVATION-SITES-REVIEW.md)及[首批扩写](24-FIVE-CONTINENT-ARTS-EXPANSION-01.md)。本批只提出 `Y-188–227` 四十项可独立学习内容；地点、人物、品相与机制待评看，尚未进入正式地图、游戏或 SR 状态。

`炼／筑／丹／婴／化`分别为炼气、筑基、金丹、元婴、化神。境界范围指有相应可靠篇章的设计范围；取得某卷不等于得到整套篇章。品相评估适用境界内的用途与结构，和境界跨度、流传稀度分别看。心法写明供给与实际练位；主修只建立功体，攻防仍须各自学习。两术融合须在一次动作中产生单术做不到的路径或取舍，按一个动作预算结算。下表的阵图各占一个学习号，旗、盘、傀儡、岗位、成员和续篇都不另计。

## Y-220 · 留堤一息的固定真相卡草案

- **身份与原事**：`art:Y-220` 的旧海闸真本由护潮者郁怀沙（`person:cangliu:yu-huaisha:001`，拟定元婴）保管。她从一次旧潮灾中归纳出短暂延后堤垣垮塌的法门，公开用于疏散。海闸旧址、阵锚、失修段和历年伤亡在内容激活前固定；法门正常效果真实，不依赖她在场暗中加成。
- **公开委托与隐藏目的**：拟定港务账房江载衡（`person:cangliu:jiang-zaiheng:001`，金丹）公开资助修闸，私下希望下一次逆潮时有人在旧闸发动此神通，使堤下库房暂不淹没，供他带人取出可证明旧航税权益的原始账匣。他知道库房位置，却没有修士能力和安全进入路线；他必须到场、备船与潜水人手，并承担真正的潮灾风险。郁怀沙知道闸下有库房但不知道他的取匣计划，不能因此自动替他负责。
- **两条独立查证路**：港务旧测绘簿记录库房与闸基相连，保存在治水院；不受江载衡管理的潜水工可从实地见到新装的取匣导索及下水痕。两者分别说明结构和近期行动，单独一条不足以判定取匣人的目的。江载衡的船料采购账可作第三路校验。
- **触发与时间**：只有逆潮进入预先登记的闸段、堤垣受一次足以垮塌的实际冲击，且修士已到场并在起效前完成参悟、起势与神意积累，延迟才成立。江载衡须在这段短窗内派人到库房；不在场、船路被堵或闸段先垮时取匣计划失败。潮位、工程状态、每人位置与伤损按同一世界时钟推进，读档不重抽账匣或换幕后人。
- **选择与持续后果**：掌门可先核图与工匠谈条件，要求救人优先并公开取匣；可只护堤疏散，不协助取匣；可在实际到场后拆导索或另开泄槽；也可拒绝赴闸。江载衡可自行求别人，但仍受同一时间和资源约束。成功救人、取得或失去账匣、堤垣损毁、受伤与身死分别持久记录；若错过时窗，库房淹没但港务争议仍有其他账目与证人可查。这条港务利益线独立于沈氏旧案。
