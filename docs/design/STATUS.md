纯 2D 高清像素桌面山院位于 `apps/courtyard/`，读取 `src/simulation/` 共用规则。Windows 为主力平台，macOS 是已开展前期验证的平台。当前具备原山院、人物与建筑查看、院务/修行/物资操作、实际供苗与劳动、收成搬回、存档恢复及东台首处扩建。
