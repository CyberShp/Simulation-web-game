## 动作怎样读得清楚

人物动作按四个可辨阶段设计：**起势让人看懂意图，发力交代作用方向，落点对应真实事件，收势回到能接下一招的姿态**。持续护持、操偶、引导施法和劳动在发力后进入可循环的维持段，再通过对应收势结束。

1. **先看身体，再看光效。** 关掉光效后，至少能区分攻击、防御、施术、布置、操控和劳动。手臂与躯干留出空隙，握点不能藏在整团袖子里。招式差异优先放在肩、肘、重心、兵器轨迹和节奏上。
2. **双手逐项记账。** 每段标明左手、右手与器材去向。双掌维持护阵前先完成收剑；单手施法可以保留另一手持剑；操弓、长枪和重兵器有自己的双手握法。法器御空要显示实物离手与返回，同一实例只有一个可见位置。
3. **身份固定。** 脸型、发髻、长发分束、衣装配色及佩饰位置沿用母稿。头发、袖口、裙摆随动作有延迟，收势逐渐停稳；动作规模不改变人物体型。
4. **足底与作用点固定。** 站立、蓄力、守御有清楚支撑脚；移动攻击的位移对应实际路径。表中的踏步、退步与腾空是姿势设计意图，接入时必须匹配该法门许可的空间与位移；条件不成立时按其规则受阻，不能由动画穿越障碍。
5. **手与道具分层。** 手掌覆盖握柄，柄身保持刚性；袍下大腿、小腿、靴子和被遮住的手臂补出完整图层。单张站立图的遮挡区不足以支撑深屈膝、扭身、跨步和双臂高举，制作这些动作前先补对应姿势素材。
6. **对象各有实体。** 人体、兵器、法器、符纸、蛊群、傀儡、阵旗、地面阵纹与命中特效分别制作；用同一次动作的真实事件对齐。大型光阵以实际保护范围决定形状，人物始终能看清。

### 方向和镜头

建议成品采用八向：正前、前侧、侧面、后侧等离散朝向，镜头保持原固定俯角。第一轮仍只制作现有前侧方向，验证握持与轮廓后再补背侧和其余方向。镜头固定与人物朝向分开处理。

持剑手、盾手、单侧披挂和佩饰具有身份，左右方向需分别校正。镜像可作绘制参考，不能把用剑手换边。身体可在动作中先转肩再转髋，但背侧需要独立素材；转向时按脚步相位衔接，避免整张人物瞬间翻转。

### 样片节奏 T-17

下表是离线美术试做初值。正式播放时长、命中时刻、耗用、冷却和打断窗口由对应法门或工序规则决定，制作时对齐事件，不能靠加帧增加收益或削减行动代价。

| 动作性质 | 初始观察时长 | 关键姿势与导出建议 |
| --- | --- | --- |
| 轻攻、短施法、闪身 | 约0.6–1.0秒 | 5个关键姿势，8–12张变化帧；发力快，起势和收势可见 |
| 重击、双手施法、部署 | 约1.2–1.8秒 | 6个关键姿势，14–22张变化帧；蓄势与回收重量清楚 |

## 共用身体动作

| 编号 | 动作组 | 起势 → 执行 → 收势 | 需要看清的事实 |
| --- | --- | --- | --- |
| B01 | 日常站立 | 重心落稳 → 胸肩轻呼吸、发尾回落 → 向目标转头 | 手中实物保持，同一只支撑脚稳定 |
| B02 | 戒备 | 转肩对敌 → 降低重心，兵器护住身前 → 缓收回日常姿态 | 与站立有肩线和持械高度差 |
| B03 | 行走 | 前倾起步 → 左右交替、摆臂受持物约束 → 支撑脚落稳 | 复用已做步态作为候选，裤腿遮挡仍须修整 |
| B04 | 奔跑 | 压低身体、蹬地 → 髋先行，短腾空，衣摆拖后 → 连续两步减速 | 持刃侧收，双手负重时另有动作 |
| B05 | 转身与急停 | 头肩预转 → 支撑脚换位、髋跟进 → 衣发随后停稳 | 朝向、惯性与实际路线一致 |
| B06 | 闪避与撤步 | 下沉侧身 → 短跨步或后撤 → 面向威胁重新立架 | 身体让开攻击线；位移和无敌资格由法门决定 |
| B07 | 取用与收纳 | 目光落到佩位 → 触物、握稳、移交工作手 → 空手回位 | 剑、符匣、蛊罐、工具各有来处与归处 |
| B08 | 搬运 | 贴近物件、屈膝 → 抱持或肩担行走 → 屈膝放下并松手 | 货物持续可见；占用双手时保持负重姿势 |
| B09 | 轻重受击 | 受力点先响应 → 肩髋带动偏转或踉跄 → 重新找支撑 | 四个受力方向可区分；硬直幅度依据实际结果 |
| B10 | 破守 | 持物或护手被压偏 → 重心后移、胸前空隙出现 → 收回失稳手臂 | 与普通格挡成功有不同结果姿势 |
| B11 | 倒地与起身 | 支撑丢失 → 侧倒并保护持械手 → 撑地、半跪、站起 | 仅可恢复状态使用起身；伤势限制按事实表现 |
| B12 | 身死停止 | 最终失衡 → 倒地、手部松弛 → 停留真实结果 | 尸身、遗物去向由既定状态决定，停止循环呼吸 |
| B13 | 服用与照料 | 收妥持物、取药 → 托瓶服用或在可达处照料 → 收瓶与回架 | 消耗、治疗结果与动作阶段对应 |
| B14 | 调息与研习 | 收械就位 → 坐定呼吸或翻阅、演练 → 合卷、起身 | 心法修炼重在安定气息，练招保留完整收势 |
| B15 | 御物移动 | 放出已装备御物、踏稳 → 屈膝平衡、随转弯侧倾 → 减速落地收物 | 影子与高度、登物和落物连续；按既有境界/能力开放 |
| B16 | 工位进入与退出 | 到达本人合法工位 → 放材料、拿工具、进入专用动作 → 归工具、放余料、离位 | 等位时站定看工位；缺料时停止执行循环 |

轻伤、疲劳和熟练度可改变呼吸、幅度与收势稳定程度；关键预兆和作用点仍保持可读。NPC 与主角共用动作语义，具体行为由各自能力、意愿、工具和真实活动决定。

## 施法

施法首先区分出手方式，再叠加具体法门的媒介和效果。下表动作可以单手或双手编排的，必须在制作单中明确选择，不能在动作途中增加可用手位。

| 编号 | 动作组 | 起势 → 执行／维持 → 收势 | 轮廓、持物与受阻表现 |
| --- | --- | --- | --- |
| S01 | 引诀点发 | 侧身定步，施法手收胸前 → 肘先开、前臂直送，指向落点 → 屈肘收掌 | 单臂直线，肩不耸；另一手可按真实装备持剑。未释放时收诀；已释放物沿实际轨迹继续 |
| S02 | 扫臂散发 | 身体微扭，前掌向侧后收 → 腰肩带动扇面横送 → 手沿弧线落回身侧 | 宽横弧与S01直送有区别；物效从实际出手点扩散，空发保留收势 |
| S03 | 持续导引 | 双掌错位拢在身前 → 后掌稳源、前掌调整流束 → 后手压息，前手收回 | 不对称双臂框形；源断则流束从源头中断，身体随后卸力 |
| S04 | 掐诀护身 | 胸前掐诀 → 护盾自脚边升起并合拢包住周身 → 持诀护身 → 收诀、盾光消散 | 手诀与成盾有先后；头顶、身体两侧及脚边均处于护盾内，剑已收妥。受击先在实际盾面作用点出现涟漪，破盾后按真实结果接受击 |
| S05 | 落地成域 | 抬臂认准地面 → 沉身下按，地表沿真实落点展开 → 双手回胸、起身 | “抬高—下压”纵向轮廓；没有合法地面时止势，已形成区域按其真实状态收尾 |
| S06 | 引风牵流 | 前后脚错开、掌心朝侧 → 肩臂绕身引出横流，再转掌定向 → 顺势收圈 | 绕身弧线、袖尾偏向流向；持续改向有身体转肩，不由特效独自旋转 |
| S07 | 内敛护体 | 吐息沉肩，双臂护住肋腹 → 肘外开少许、稳住身体 → 护纹回收，手归戒备 | 护体光沿身体收束，形状与外推护障不同；失效先显局部暗裂及呼吸紊乱 |
| S08 | 近身救治 | 到伤者侧面蹲下，一手扶稳 → 另一手悬按或沿患处缓引 → 撤手观察、再起身 | 低姿态与双人关系明确；治疗未完成时只撤手收物，成功反应取真实结果 |
| S09 | 扰法与解术 | 凝视实际施术线或附着处 → 一手探定，另一手做短切、旋解或拂除 → 收手确认 | 三种手路按法门分别画；命中节点才有断光、脱附等对应变化，失败后回守 |

下表把 [32 开局传承](32-OPENING-INHERITANCE.md)的攻守定位落实到身体。它是具体法门对动作组的选用建议。

| 路线 | 攻击姿势 | 防御姿势 | 主要辨识 |

| 青岚 Y-041／043 | S06引风后沿斜前方送出 | S03以偏转掌势引开来力；S04掐诀形成周身风盾 | 身体侧向舒展，袖发随横向风路偏摆 |

## 布阵和结阵

个人布阵、多人结阵和护山工程按 [21 第四节](21-CULTIVATION-SYSTEM-REVIEW.md)的作者方案分开呈现。阵法实物与工程取 [48 百艺阵法分卷](arts-v02/crafts.md)；组内具体动作以已学阵图和实际节点为准。

| 编号 | 动作组 | 起势 → 执行／维持 → 收势 | 识别点与中断 |
| --- | --- | --- | --- |
| A01 | 勘位 | 展图、持罗盘观察 → 实走到节点俯察、比对 → 合图指认操阵位 | 看图—走位—俯察的节奏；不可达节点停止前往，保留已知勘测结果 |
| A02 | 部署节点 | 从携具取阵旗／筹／线 → 俯身插稳、铺线或压实 → 松手、检视 | 物件逐个落在真实位置；搬运大件用B08。被打断时已放物留地，未放物仍在手 |
| A03 | 点阵 | 一手托盘，另一手逐点指认 → 节点依规则依次导通 → 回到操阵姿势 | 低位地面点位与手势呼应；断点只在实际故障处闪灭 |
| A04 | 维持与收阵 | 沉脚进入持阵位 → 单手调盘或双手撑势 → 按阵图泄流，再实际回收 | 维持手数由阵法决定；双手版本先收武器。阵纹、阵旗和人体同时显示受压、裂纹与卸力 |
| A05 | 多人合势 | 发起者举臂示意、成员各自回应 → 实际入位后共同沉身起势 → 分别解势离位 | 人物同拍但姿势按岗位有差别；缺员没有连接，破位从对应节点退散 |
| A06 | 阵中换位 | 发起者侧向示意 → 留位者保持，换位者沿真实路径移动 → 新位站稳再合势 | 一人动、其余稳；受阻者停步示意。阵效依据实际成员和阵型条件变化 |
| A07 | 护山启枢 | 到实建阵枢核验 → 双手触枢、沉肩注入 → 转入值守或按规则离枢 | 人靠固定设施操作，响应沿实建阵基展开；未通段保持断开 |
| A08 | 巡检补阵 | 沿阵基巡查 → 验纹、卸能、更换阵材、逐段试通 → 归工具确认 | 工具接触真实损坏点；反冲时撤手护面，未修段保留失效状态 |

多人动作按共同活动事件对齐，先到者等待。合作由人物意愿与实际条件成立；画面呈现其回应和到场，不以整齐同步替代尚未加入的人。撑阵受压依次为稳撑、肘屈、腿承重、裂纹扩大、真实破裂后失衡，保护范围与实际阵面对应。

## 蛊道

蛊道动作同时呈现**人、容器、活蛊及目标**。育蛊工序见百艺分册，下面是御使、攻守和解除。基础来源见 [蛊道分卷](arts-v02/gu.md)与48的手位、回收及知情约束。

| 编号 | 动作组 | 起势 → 执行／维持 → 收势 | 识别点与中断 |
| --- | --- | --- | --- |
| G01 | 开匣放群 | 一臂护匣贴腰，另一手启盖 → 前臂低送，引蛊沿实际路径离匣 → 合盖、留控蛊手势 | 内收护匣臂与低送臂不对称；失控则止放封匣，已放蛊体保留真实位置 |
| G02 | 近身附蛊 | 侧身靠近，肘贴身 → 手背或袖口短送，实际接触 → 快速收腕回守 | 动作短而贴近目标；未接触收回，遭截按真实结果掉落或退回 |
| G03 | 分群驱使 | 看向已在场蛊群 → 腕掌向两侧分送、交替点令 → 并掌收控 | 指令动作与两路虫群关系明确；人不同时凭空多出攻击蛊和护身蛊 |
| G04 | 蛊群护身 | 双臂围出低窄面 → 微调腕角，蛊体形成甲片、丝网或挡面 → 解除护势 | 以实体蛊片、丝网形状区分术法护罩；损失位置出现缺口，受冲由身体承力 |
| G05 | 回匣与清点 | 打开原匣，手掌内招 → 蛊沿原有可行路线返回 → 清点后关匣 | 往返轨迹和匣口相连；未归蛊有失联或在途事实，不能直接画回匣中 |
| G06 | 感应与搜引 | 收敛重心，一手近匣／媒介 → 头肩朝已感方向缓转，另一手示路 → 记录或收手 | 静听姿态与低位指引；可观察信息按法门和知情投影表达，不显示隐藏目标真位置 |
| G07 | 解蛊与隔护 | 到患处近旁，放好隔护器物 → 一手稳定、另一手引离或封隔 → 收容实物、检查患处 | 与放蛊方向相反：由目标回到容器；失败保留实际附着与伤势，不能以收罐姿势宣告治愈 |

隐蔽施蛊时，以上是供制作的完整动作。玩家画面只展示观察条件允许的动作、虫迹和后果；未被察觉的行为不能附带醒目的“下蛊”标签或自动显示受害者连线。

## 傀儡

操作者与傀儡分别行动、分别受击。操控姿势强调腕部指令与稳定重心，打击动作发生在偶体。来源为 [百艺分卷的桑弦小偶等](arts-v02/crafts.md)；造偶和维修见百艺分册。

| 编号 | 动作组 | 起势 → 执行／维持 → 收势 | 识别点与中断 |
| --- | --- | --- | --- |
| P01 | 置偶 | 搬运或引导真实偶体到位 → 蹲身安稳支点、连接控制件 → 人退至操控位 | 大偶按搬运、部署资格出现；取出、落地、手离开三个节点明确 |
| P02 | 启机试动 | 近身开检修处、按芯或接线 → 逐关节试动 → 关盖，偶转待命 | 操作者低姿态、偶从静止到响应；卡节留在故障角度，已有损坏可见 |
| P03 | 控偶进攻 | 身体侧后定步，双腕朝偶 → 一腕送一腕牵，偶沿真路径攻出 → 回腕令其回防 | 人控、偶攻的双实体关系清楚；断控侧腕突然松，偶依其规则停止或转态 |
| P04 | 调偶护主 | 一手内勾、另一手横划 → 偶实际移动到来袭侧架臂／转盾 → 收令解除 | 偶在前沉身承压，人留出位置；折臂、碎甲与击退出现在同一偶体 |
| P05 | 多偶分向 | 两臂朝各可控方向打开 → 左右指令交替，有明确转头与重心调整 → 逐侧收控 | 使用同一控制容量和实际偶数；一侧失效仅该侧表现改变，余偶按合法指令继续 |
| P06 | 停机与收回 | 给出停止指令 → 偶收工具、卸力待命或沿路返回 → 到场停机、收好控制件 | 收回有路程，折损偶按搬运条件处理；中途停在真实位置，不瞬间缩回物品栏 |

偶体另配待命、移动、搬举、工具使用、攻击、承击、失衡、故障停机和被修复后的试动片段。其形制决定关节和步态，木偶、轮式偶与兽形偶分别适配；操偶者动作组可以复用，偶体轨迹、握点及重量需分别制作。

详见[百艺工序动作分册](character-actions/CRAFTS.md)与[逐项覆盖索引](character-actions/craft-coverage.json)。C01–C23 将现有工艺按身体工序组织：备料、切磨、火候、锻打、雕刻、书绘、缝织、种采、调制、医护、育蛊、驯养、机关与设施维护等；每项引用相应的准备、劳动循环、交付和中断。

## 动作之间怎样衔接

### 持物与双手

| 当前状态 | 接续动作 | 必须出现的过渡 |
| --- | --- | --- |
| 单手持剑 | 单手引诀 | 握剑手保持，空手施术；袖、剑不穿过身体 |
| 单手持剑 | 双手护阵、书符、持弓、操偶 | 先完成合法收剑或安置，再腾出双手；结束时按当前实物位置重新取剑 |
| 双手重兵器 | 取符、取药 | 先合法收妥或放置重兵器；不能凭一帧切图跳过占用阶段 |
| 御剑已离手 | 近身持剑动作 | 真剑先返回并被握稳；剑被挡、损坏或失去时按实际可用动作接续 |
| 同一蛊群或傀儡正在攻击 | 转为护身 | 先停止或改变原指令，实体实际回防；不同位置不能复用同一份实物 |
| 工位劳动 | 移动、战斗或离开 | 释放对应工序姿势，工具及未完件有实际去向；紧急中断采用相应结果 |

### 结束和失败

每组至少声明下列适用分支。某招没有某种分支时，应在制作单上标明原因；不能用成功动画替代所有结果。

| 事实 | 身体与物效 | 后续接续 |
| --- | --- | --- |
| 起势前条件不足 | 留在当前姿势或短暂检查器物 | 显示可知的缺料、占手、距离或工位原因 |
| 起势中主动取消 | 沿最短合理路径收手、卸力、收物 | 已发生费用与器物状态按原规则处理 |
| 起势或维持被打断 | 先表现真实受力／故障，再进入失稳或自护 | 持续效果按自身中断规则结束；自治物或已释放物按其状态继续 |
| 挥空或目标移走 | 完成剩余惯性、制动与收势 | 没有命中反弹和成功命中特效；不瞬间朝新目标扭曲武器 |
| 被接住或格开 | 接触点短反馈，兵器与肩肘共同受力 | 接住、偏架、反震、破守分别读取真实结果 |
| 兵器、符、偶、阵材失效 | 相应实物先出现断裂、熄灭、停机等变化 | 使用失效后的真实握持、控制和移动状态 |
| 多人协同失去条件 | 对应节点先断开，成员按其活动各自卸势 | 剩余阵效、撤离及伤害按具体阵图处理 |
| 劳动缺料或暂停供能 | 停止当前可停段、放稳工具或保留受控姿势 | 等待原因与工作单一致；继续时回到实际阶段 |

**存读与暂停：** 动画从同一活动的阶段、已过时长、对象与已发生事件恢复。中途读档不会重新播一次“投出”而复制道具，也不会因跳到收势而补发产物。世界暂停时，身体动作、实体移动和持续效果一起停在对应时刻；界面的阅读和切换不补算动作时间。

### 三个关键姿势样例

**S04 掐诀护身：** 收剑完成、凝神 → 施术手抬至胸前结诀，另一手自然护于腹前 → 脚边起光、盾膜沿周身上升并在头顶合拢 → 持诀维持 → 受击点出现盾面涟漪 → 收诀、盾光消散、双手落回。盾形与范围由该法术实际防护作用决定；护盾包覆身体并保留前后层次。破裂分支在实际破盾事件后接B10或B09对应结果。

**G01 开匣放蛊：** 右手确认匣盖、左臂托罐 → 右手启盖 → 右前臂低送、掌指示路 → 蛊体从匣口沿真实路径离开 → 右手合盖、左臂仍稳持 → 转入G03操控或G05召回。若角色的器材配置使用另一侧，另做该侧握持版本并保持连续。

**W01 单剑点刺：** 剑尖对敌、空手守住上身侧面 → 后脚蓄重、剑肘略收 → 髋肩送出，握点与剑保持刚性 → 到真实接触／挥空位置 → 屈肘撤剑、前膝缓冲 → 剑尖回到可接守法的位置。被格开时增加剑路侧偏和肩肘卸力，不把直刺帧倒放当受阻。

## 建议制作顺序

第一步补齐原形象的袍下腿、袖内手臂、持物手与空手图层，处理现有行走小样的伸腿拉伸。下列顺序供本轮方案确认后采用，先以当前前侧方向做姿势板与短段动作。

| 批次 | 代表样例 | 要先证明什么 |
| --- | --- | --- |
| 第一批 | S01引诀、S04护持、A02落旗、A04撑阵、G01放蛊、F01掷符、P03控偶 | 七种身体轮廓和双手占用能辨认，原脸与衣装稳定 |
| 第二批 | W01剑攻守、W05枪刺、W09盾斧、W15拳掌肘；C07锻打、C22书符、C23育蛊 | 握点、兵器承力、工具接触与劳动循环各自成立 |
| 第三批 | A05多人合势、P04偶护主、D03山河借位、D08留堤一息 | 多人／多实体的同步、真实位置、预兆和失败收势可读 |
| 后续扩展 | 其余动作组及背侧、侧面、正面等朝向 | 逐组沿用已验证制作方法，检查方向变化与人物身份 |

样例通过后再决定更多方向和换装复用的产量。同一个动作组的循环、攻守、失败与方向变体分别登记文件，不能用“100组设计”推算已经完成的动画数量。
