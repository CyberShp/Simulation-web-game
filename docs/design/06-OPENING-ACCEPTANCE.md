## 1. 玩家首先需要理解什么

开局需要建立五件事：我是谁、怎样亲自行动、谁愿与我共同生活、建筑为何存在、恢复传承怎样通往复仇。先经历可见的行动与关系，再逐步开放管理信息。

保留既有“雨夜余烬→落脚疗伤→赠药结缘→恢复生产→整理遗卷”顺序。掌门默认沈砚（可改名），炼气六层；姓名改变不改变 `person:master`。剧情背景与段落采用 [04-WORLD-STORY.md](04-WORLD-STORY.md) 的唯一版本。

按U-54，剑宗中层事后争夺沈氏灵脉在主角正式落脚前已发生，属于既有背景，后续由调查揭示经过。U-55确认雨夜逃生至正式抵达别院经历数月隐匿流亡，这段背景跨度容纳该事后事件；14按R-26将间隔默认定为四个月，途中细节由作者补齐，不将故事挤在同一夜，也不将历史争夺改成落脚后的实时事件。开局疗伤表现应与数月流亡及实际伤势恢复阶段自洽，具体伤情仍待设计；这段背景时间不要求玩家等待或通过离线推进。初始呈现只使用主角当时可知的信息，未确认的真实动机不直接塞入首屏。

U-57确认沈氏灭门是直接夺产，无罪名或邪修栽赃。开局动机及主线验收按复仇、成长和立足组织，取消沈氏洗罪/昭雪要求；调查可揭示参与者、敌方布置和利益关系，公议或交涉不能成为批准复仇的必要环节。

首屏只有必要的时间/暂停、掌门状态、当前目标、人物定位与当前可用操作。远期区域、空装备槽的大量弹窗、分峰、全量势力账本、无用途排行榜不在第一次行动前铺满屏幕。可看已知信息，但不能用未解锁按钮冒充玩法。

v1.1的活世界先从生活建立可信关系，再教学有限情报和危险。陆知微的赠药结缘不因“世界有阴谋”改写成强制骗局；第一次明确危险出行前，玩家应理解NPC自主、行程耗时、消息会过期及可能永久身死。通过已知路线、近期目击和一次可完成的救援演示学习；不在首屏讲完卜算、道途、禁忌与母子篇。首次教学危机至少有一条普通准备即可走通的路线，此后不保证每次求救都能及时赶到。

v1.2前期清单、固定责任链与三路成长见[14](14-EARLY-GAME-DETAILED-DESIGN.md)，新增EARLY系列是对本文件验收的补充，未获得实现证据前均为未通过。远洲神道王朝设定留空不应使开局验收阻塞。

## 2. 推荐体验顺序

时间是首次玩家学习目标，不能用加速模拟的秒数汇报达标。玩家可以自由查看、暂停与慢读；正常操作允许更快/更慢。

| 学习段落 | 玩家实际行动 | 画面与系统反馈 | 下一阶段条件 |
| --- | --- | --- | --- |
| 约0–3分钟：落脚 | 识别并选择掌门，移动到旧别院可达入口，理解伤势与逃生处境 | 同一人物肖像与场景外观；移动路径与门口清楚；管理页说明真实床位及活动 | 玩家完成一次明确移动/交互；读剧情不自动消费物资 |
| 约3–6分钟：疗伤 | 选择休养/使用本人已有恢复机会，查看家传残卷来源 | 身体状态有变化，休养在真实位置发生；家传不是随机抽取奖励 | 伤势允许基本行动；保留自由探索和补救，不以唯一按钮强卡 |
| 约6–10分钟：结缘 | 遇见具名采药人陆知微，了解求助，决定赠药/暂缓及接纳约定 | 草药扣除明确；她有身份、动机、稳定外观与回应；受助不等于强制永久入宗 | 明确选择事务结算一次；选择暂缓仍能回访/补给，不自动“善良选项” |
| 约10–15分钟：营造 | 选择已开放的药田建造点、查看缺料与通路、确认施工，掌门或愿意帮忙的人完成工作 | 临时预览→工地→同尺度设施；占地与入口来自同一预设点和预制件；不同实际工位和动作 | 建造点资格、合法地形、材料与路径；无人接受时掌门可亲自做 |
| 约15–30分钟：传承与江湖 | 看到药田活动/一次有效产出，研习遗卷或参加首次授业，获得可靠外界线索 | 行为标签、动画、库存、学习进度相符；外界地点与当地人物引用同一身份 | 首轮供给、一次成长和下一明确目标成立；不等全部远期系统开启 |

既有开局赠药费用和初始资源以实际配置核对，设计阶段不另写一套相矛盾的数值。实施需验证初始可用量足够且有余地，明确已预留物资不能支付；失败/暂缓的恢复途径必须可用。调整费用需登记平衡理由，不靠控制台加钱验收正常开局。

## 3. 引导交互与可读反馈

- 同一输入先命中人物/可交互实体，再根据当前模式决定地面移动或营造；点击门人不能先让掌门跑过去而丢失选择。
- 选择掌门与门人使用一致反馈；重叠人物可展开列表，列表含稳定肖像、姓名与活动，不用“4号小人”作为身份。
- 活动描述使用事实：前往、等候、准备、照料、研读、休养；当前不能执行时给出材料、道路、工位或意愿原因。
- 常态不铺满姓名与进度条。悬停/选中/异常时呈现重点；人物栏提供持续定位，缩远后仍能找回某人。
- 建筑从预览到完成保持同一视角、尺度和地形关系。封闭建筑显示完整外观，人物/建筑管理可查看内部真实活动与工位；露天作业人物在实际脚点可见、可点选。
- 选择、已读与执行分离。打开剧情/材料说明不扣费，不替玩家接受委托、赠予、入宗或出发。
- 每次引导只解释眼前一次必要操作；允许关闭和重新查看帮助，不因跳过文字永久丢线索。
- 重要拒绝有合理反馈；引导也不能覆盖NPC意愿。首名同伴的可靠出场是作者内容，接受条件由真实处境支持。

## 4. 必须先证明的一条完整事件链

推荐工程切片为“雨后伤匠”。以下是本游戏新设计情景，不声称直接复刻任一参考游戏。

1. 具名伤匠到访，掌门可调查其处境、暂缓或提供治疗。事件ID与人物ID稳定，伤匠不是陆知微改名。
2. 治疗使用实际药物与休养位置，NPC自主响应照料机会；产出、扣费、关系和记忆在同一事务结算。
3. 伤匠提供可靠线索或合作机会，目标地点关联真实局部场景。玩家准备物资并邀请同意的同行者；可单独前往。
4. 出行使用时间、消耗和持久人物。当地选择改变不同个人/势力评价，不能一条全局好感覆盖所有关系。
5. 获得有来源的配方/部件，返程制作唯一装备实例。它归属明确，可自用、赠予或借出，读档不复制。
6. 该装备与一门可实际学会的法门形成用途变化；在护院、救助或遭遇中看得见区别，不能只有伤害数字提高。
7. 剧情/供给/关系后果回到山院。前述选择已完成，不反复弹出同一事件发奖；后续可靠主线仍可推进。

这条链证明人物、空间、经济、事件、装备、武学和存档共用事实。并非新增一条强制主线；拒绝治疗、缺材料、没人愿同行或战败应产生恢复/替代路径。初始完整切片未通过前，不并行扩几十套装备和随机事件。

第二条切片采用[12的“暴雨与失联采药人”](12-CONTENT-AUTHORING.md)：天气改变生产与道路，商人和药师按自身利益行动，消息中有真假混合，掌门调查或卜算取得有限定位，再付实际行程与施救成本到场。需分别证明NPC自救、掌门救出、迟到死亡、玩家预置陷阱被识破等结果及宗门后果。它用于验证活世界，不替换开局可靠赠药事件，也不将独立世界阴谋追加为复仇的无限幕后黑手。

母子篇抽取作为之后的稀世暗线切片，先在炼气/筑基范围做可玩的缩尺机制，验收预兆、校勘、持续抽取、断流、外援及损失；完整金丹/元婴仍按L-01后置。所有切片在AI关闭时完整成立。作者真相、线索和时间预算必须满足12，不能到死亡时临时宣布隐藏规则。

## 8. 证据与完成状态

每条验收在实现记录中保存：设计版本、规则/ID、代码提交、存档来源、操作步骤、预期与结果、截图/日志/测量、未覆盖范围。自动测试只覆盖其实际断言；视觉比例、人物认知、真人等待、设备触控需相应证据。

状态使用 `not-started / designed / partial / implemented / verified / blocked`：有规格仅为designed；代码能运行不等于verified；某设备待测不能借另一设备盖章。旧EA验收保留历史价值，不覆盖本版新标准。

新设计交付本身只检查文件引用、JSON、决策状态、跨系统规则和入口完整，不因本轮设计改动重跑整个游戏并宣称这些新体验已通过。实际差距见 [STATUS.md](STATUS.md)。
