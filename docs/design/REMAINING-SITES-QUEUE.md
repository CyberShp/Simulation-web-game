# 剩余14处预设建位的接入队列

2026-10-19。派生工作清单，依据 U-167／R-54 批准的 [58 总图](58-GOLDEN-CORE-PRESET-BUILDINGS.md)、[63 正常成长路径](63-NORMAL-GROWTH-FACILITY-PATH.md) 与当前运行目录（17 处接入、14 处规划）。它只把“已批准的用途”拆成可排期的工单，不新增设计决定、不改动任何费用或境界门槛；带“待 T”的数值仍须按 U-63 登记后才能进入实现。

## 1. 共同前提

31 处建位都按同一套产物接入，缺一项就不算完成：

| 产物 | 内容 | 核对方式 |
| --- | --- | --- |
| 固定建位 | 锚点、占地（一级／三级上限）、入口与门扇、接入道路 | 同一坐标事实被空间、渲染、导航共用；未开区拒绝 |
| 阶段外观 | 未建地貌、清场／基础、施工木架、完工；二三级升级层 | 同机位对照、111px 成人／140px 门扇同缩放 |
| 实际工位 | 床位、工作位、特异位（炉、案、栏、池）按真实位置登记 | 独占、容量、寻路可达 |
| 正式操作 | 面板与地面操作走公开命令；失败路径有明确拒绝 | 缺人／缺料／未到场时正确停工 |
| 持久 | 携料途中、半建、完工、生产中存读一次结算 | 重开后身份、投入、时间、随机状态不变 |
| 验收 | 同一来源档的正常链 + 失败分支 + 桌面可见结果 | 不注资、不改境界、不瞬移 |

## 4. 现状与边界

- 14 处全部没有运行几何：`ea-golden-core-sites` 只登记用途与规划编号，锚点、占地、入口、槽位和阶段图都待各批制作。
- 10 处没有经营定义，其中 9 处需要先冻结设施定义（GC-04、05、06、15、27、28、29、30、31），GC-07 另行冻结地标与接待规则，不按经营建筑计价。GC-08、21、22、23 可复用 `watchtower`／`farm`／`well`，但 15、21、22 仍需槽位变体，不能直接照搬现有类型。
- GC-14 医庐已接入、正常解锁与疗程仍待验；它不在本表 14 处内，但排在 GC-04 之前。
- “17 处接入”不等于“17 处完整验收”：二三级外观与升级、正常经营链、Windows 与安装包仍分别待验，见 [STATUS](STATUS.md)。
- 本清单不改变 58 的批准布局和分期；新增数值一律按 U-63 以 T 参数登记，并同步 58 与需求台账。
