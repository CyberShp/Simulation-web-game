# 兵器、徒手与神通动作分册

2026-10-17。隶属[人物动作库主稿](../55-CHARACTER-ACTION-LIBRARY.md)，作者提案 **R-51**。沿用 U-157 的固定视角、近景立绘和蓝白衣装长发像素形象，以常规 111 像素显示高度检查身体、持物与动作方向。

本册包含 **W01–W16 共16个兵器／身体动作家族**和 **D01–D09 共9项本篇神通表演**。一个家族可含多个独立攻击、守御、控制、收回与受阻片段；家族数、修行项目数和动画文件数分别计算。

新增姿势、握持拆分、轮廓要求与复用方法属于作者制作建议。功法效果、使用资格、范围、消耗和时限仍取各自来源规格；动作节奏服从真实规则。主稿 T-17 仅作离线样片观察初值，命中、释放、维持结束与中断均按实际事件对齐。

## 共同制作约定

- **攻守分别制作。** 每行同时给出攻与守的素材槽位。没有对应已学攻守动作的角色不能因素材存在而取得新能力；仅有守御或控制条目的器械，其攻击槽是待具体动作映射的作者建议。
- **身体与手位连续。** 标出左、右手持物及交接时刻。双手动作开始前须完成原持物的合法收纳或转交；离手兵器、实箭、暗器、锚石和鼓均保持真实实例与位置。
- **分段显示结果。** 起手、接触／释放、最大延展、收势分别可辨；持续守御与神通另有维持段。接住、被拨开、挥空、受击中断、器物失效分别接对应分支，动画读取实际结果。
- **脚点对应空间。** 表中的前踏、侧步、后撤与换位仅在该动作许可且路径成立时执行。守势承压、兵器受墙限制和地面支点滑动都从真实空间事实投影。
- **原像素外观保真。** 握柄处露出手与武器的连接，长发、衣摆与袖口随身体延后回落；深屈膝、扭身和双臂动作先补齐原图遮住的肢体图层。111像素先检查无特效轮廓，再看完整效果，150／222像素用于细部复看。

## 复用与制作核对

1. **可复用的身体基底：**站稳、转肩、沉胯、承冲、收息及基础收纳。每种兵器仍保留自己的握点、轨迹、接触段与回收段；武学元素效果附着在实际运动及接触位置。
2. **必须分别绘制的变体：**长枪滑握、棍杖横扫、戟钩回拉；双剑与双匕；双环旋腕与双叉绞杆；单锤与双锤；拳、掌、肘。柔鞭、链锤、弓弦分别保留各自运动顺序。
3. **神通分别表达被改写的事实：**D01连接人与桥，D02连接人与实壳，D03对应两个脚点，D04对应地锚与边界，D05对应实岩缘，D06对应实际格挡弧，D07对应共视来源，D08对应堤体裂纹，D09对应鼓线与实箭。身体轮廓与这些对象一起承担识别。
4. **关键姿势先行：**每片段先核对预备、最大蓄势、接触／释放、最大延展与收回；持续动作增加可循环维持段，按真实时限退出。所需姿势数与导出帧数以片段实际内容决定。
5. **制作后逐项检查：**111像素下辨认攻守、发力手、器械方向与支撑脚；逐帧核对握点和持物去向；分别检查正常、挥空、被挡、中断及器物失效；正式接入时再核对暂停、恢复与存读后的相同阶段。

本册当前提供动作设计与来源映射。像素帧、连续播放、正式运行和目标设备表现按主稿后续制作与验收安排分别记录。
