# 百艺工序动作分册

2026-10-17。承接[人物动作主稿](../55-CHARACTER-ACTION-LIBRARY.md)的 **R-51 作者动作提案**；观察节奏与帧数采用主稿 T-17 的可调样片参数。当前状态为 **design-only（设计映射）**。本分册用于确认动作内容与制作顺序；动画制作、运行接入及实机验收分别登记。

[48 世界修行库](../48-GOLDEN-CORE-WORLD-ARTS-V02.md)的同源目录有172项百艺。本分册以C01–C23组织148项生产、生活和调查工艺，另24项阵法引用主稿A01–A08。逐项ID、名称、动作组、原始效用与工序特效见[覆盖索引](craft-coverage.json)。一组可包含数段专用动作，同一项目也可引用多组；这些数量均不是动画片段或已制成素材数量。

## 身体、工位与结果

- 到达本人合法工位后，使用主稿B16进入专用工序；前往、等位、缺料和实际劳动分别呈现。人物、工具、工件、原料和工位读取同一活动事实。
- 表中的循环只表达当前工序。锤击、运笔和翻料的重复次数不直接产生物资；收获、成丹、成符、装成机关及交付在正式结果成立后播放一次。检查失败时保留废品或待返工状态。
- 主动停工按允许中断的小步骤收好器物；受击、器具损坏、断供与失控按实际事件进入对应分支。炉火、储能、虫体和吊物的去向由规则决定，不能在收势时无条件清空危险。中断分支是拟议表现，不新设安全保证或资源返还规则。
- 111像素先检查身体轮廓、持物轮廓与运动方向；150／222像素用于复看握点和接触细节。当前识别点为制作目标，须由样片核验。手指细节和细粒光效不能独自承担工艺识别。
- 表中转身、伸手和移步以真实空间允许为前提。多人抬运、阵员合势与动物响应分别占用实际对象；同一人物的手位、工时和身体活动保持唯一。

## 组内专用工序

C01的采药、浇灌、嫁接和授粉，C02的斧伐、锯切和刨削，C06的研磨、过滤和控炉，C08的磨刃、校矢和改甲，C11的装榫、换轴和校晶等，应分别制作核心劳动轨迹。可以复用人体与衣装图层、取放和收纳衔接；手臂轨迹、重心、握点与工件接触按工序细化。

### C11 制偶与御偶

制作和维修在停机架上完成，保留同一偶体、构件与损伤；校准必须逐轴试动。御偶引用主稿P01–P06，操作者与偶体分别显示。操偶法、可通信距离、能源、控制容量与武具状态齐备后才显示相应偶体动作；工坊产物不自动获得所有战技。
