- [编号建位图](../art/golden-core-domain-20261018/site-plan.svg)负责覆盖清单与相邻关系；图中位置为构图坐标，实际米制占地、入口和工位随分区母稿逐批校准。
- [整体场景概念与来源](../art/golden-core-domain-20261018/README.md)负责环境、道路、建筑群和尺度关系。两者的整体构图及分区关系按U-167批准；分区像素表现与实际经营随各批次制作、验证。
- 本篇玩家上限为金丹初期、在籍至多15名门人另加掌门；具体营建由人手、知识、材料和服务能力决定。七区长期规划与四座分峰仍保留，分峰建设是可选成长路线。[37](37-FIRST-CAMPAIGN-PLAN.md)、[39](39-FIRST-CAMPAIGN-DISCIPLES-ECONOMY.md)、[成长章程](../SECT-GROWTH-PLAN.md)

## 4. 分期与供给顺序

1. **开山起步：**保留原院、药圃、东台已有建位；先接通西桥至16的真实采伐路线，具备17/18/24后形成木、石、粮、货的基本供给。所需物资也可通过既有有限交易取得。
2. **炼气经营：**按实际人数启用09–12，完善13/14；建02/03与26，25提供常用加工维修。各项仍以正式阶段、图纸、材料和人员为条件。
3. **筑基发展：**完善05/04、23供水接引及27–31专项设施；31的养蛊与封毒分区各按实际技艺独立建设，30由御兽路线决定。独立院落须有维护和补给能力。
4. **凝丹准备至金丹初期：**升级04稳定练位、护持及恢复安排；升级实际使用的丹房、工坊、库房和传承设施。06按风险和阵图选择建设。旧田及旧工位在新供给稳定送达后再转换用途。

这些是制作与服务的顺序建议，设施的建造日期不被境界标签强行锁定。道路、台阶、院间空地和最大升级范围一次规划，工程按游戏进度显现。

## 5. 山域、比例与画面阶段

七区沿用Z-01主峰、Z-02东住居、Z-03西生产谷及四座分峰。金丹篇详细图集中前三者；四峰保留山体、主路连接口和远期生活圈位置，具体立峰按07、U-105/U-111条件推进。

主殿仍是中心锚点，原药圃与古松保持识别关系。东西区域经石桥、山路和台阶相连。建筑外观统一蓝灰瓦、木梁、暖灰石；人物与道路、门扇、工棚共用尺度。当前80母稿像素人物校准仅是动作小样依据，接入时还需按同机位实际米制复核。

每处建位交付同机位的未建地貌、清场／基础、施工、完工、升级及必要损坏层。未建状态显示真实山地、林缘或田地；已交付材料才出现在堆场。封闭建筑完工后保持完整外观（U-101），露天工位可见真实作业者。
