# 逃亡包裹与五条入门传承

2026-10-11 · U-115 已确认开局选择；具体名称、数值、来源位置为作者校准稿。对应 SR-XF-002-AC-01/02、SR-XF-013、SR-XF-014 和 SR-XF-030 的局部实现与验证，整项验收仍按台账。

## 开局事实与操作

母亲逃亡时塞来的包裹里只有**一卷传承**。主角初到云岫仍带伤，第一次成功用六份灵草开始疗伤时解开包裹，世界时钟暂停。游戏在这一刻提供青岚、赤阳、寒泉、厚土、金锋五种开局选择；画面始终只呈现一卷遗物，玩家逐项预览并确定它是哪一条传承。确定后获得该线的炼气入门心法、独立攻击法、独立护持法各一项，三项分别记理解与熟练。选择提交后返回当前山院，继续未完成的疗伤活动。草药只在开始疗伤时扣一次；打开、保存、重载与择法均不另扣草药或推进时间。

其余四条没有放在包裹里，也没有通过这卷遗物给出线索。它们的原本有固定的市场或低级遗址来源，日后主角须亲自到达、靠近物件；市场还须携足交易灵石。寻得原本只取得典籍接触权，不能直接变成已学。旧档不重新选择，原来已学的青岚与旧战斗动作保留。五条是开局道路，不是永久职业。

五条已获得的入门段各给出**一个可操作攻击和一个可操作防御**。普通闪避、持械平砍仍为通用动作。当前运行里的同境试算只改变射程、灵力消耗、基础攻击量和护持时长：青岚 6／16／25／2.2，赤阳 5.4／20／29／1.8，寒泉 6.5／17／23／2.6，厚土 3.8／14／27／2.8，金锋 2.2／12／30／2.3；攻击量另叠同一境界加值。此为首轮战斗参数，须经同境敌人和真实装备复核；火、水、土、金的异常与环境加成尚未接入，不在 UI 暗示已有效。金锋使用开局已有的实体铁剑，失剑检验仍须补到正式战斗动作。

## 筑基与后续校准门槛

现行可靠筑基线仍把《青岚筑基篇》作为唯一前置，无法直接承接其他四种心法。后续必须为赤阳、寒泉、厚土、金锋分别写清同一心法的筑基续篇来源、可靠校验及替代路线；同一心法的续篇沿用原 Y 号。完成之前，五条开局路线仅确认**炼气开局可操作**，不能声称五条从炼气到筑基已完全打通。正式入口与 Godot 预览共用选择规则；旧档保留原已学内容。雨夜包裹画面绘制新山院背景与单卷遗物；可行走山院仍须另行接续。
