# 08 · 活世界、生态、天气与多面社会

设计编号：DB-2026-10-05；版本：v1.1；编制日期：2026-10-05（北京时间）。

## 1. 活起来的含义

世界的生命感来自同一批人和地点在时间中延续。人物有自己想做的事，场景留下事情发生过的痕迹，天气改变可行的安排，社会对行为产生有范围、有时延的反应。

| 层次 | 玩家可观察的变化 | 权威事实 |
| --- | --- | --- |
| 生活 | 吃饭、避雨、授业、访友、争执、照顾伤者 | 身体需要、活动、约定、关系与记忆 |
| 生计 | 原料告急、匠人赴市、田地轮作、商队改道 | 库存、工序、订单、路线与生态承载 |
| 修行 | 研读、练法、闭关准备、寻找适性环境 | 典籍、理解、熟练、修为与已知机会 |
| 地点 | 灵草长成、路面潮湿、工地推进、伤痕修复 | 场景生态、天气影响、设施与事件事实 |
| 社会 | 口碑变化、私下结盟、证言冲突、拒绝接见 | 人物知情、传播、真实利益与公开立场 |

单纯让小人随机走动、给背景加粒子、定时弹出消息，不构成活世界。每项会影响玩法的变化都须回答：谁或什么造成、何时开始、影响什么、留下什么、谁能知道、怎样保存。

宁静也须有因果：同伴吃过饭相约练剑；医者给伤者换药；老匠守约归还借用法器；雨停后人们走出屋檐。玩家应有能力建立可信的生活秩序，不应因“世界复杂”而被迫把所有善意都视为陷阱。

## 2. 不变的控制、时间与知情边界

- 玩家只直接操控掌门。远方 NPC 的生活、修行、斗法和危机不产生接管按钮。
- NPC 自主形成目标和接受约定，掌门通过条件、制度、沟通、亲自行动与已获知的机会影响世界。
- 唯一时钟为整数 `worldTick`，1 tick = 100ms 模拟时间；期限为 `*Tick`，时长为 `durationTicks`。
- 暂停、后台、关闭、剧情阅读及规定暂停的界面不推进世界。重新回来不补算死亡、天气、商队或生产。
- 打开地图、看人物卡、切镜头、重绘、刷新天气图标，都不推进或重抽任何事实。
- 世界正在发生的事和掌门知道的事分离。远方发生争斗，不等于任务栏立即显示双方真名、坐标与胜负。
- 地图定位未知人物只能显示最后可靠消息或推断范围；镜头不能成为无成本占卜器。
- 正常战斗与危险过程消耗同一世界时间。NPC 的永久死亡、救治窗口和玩家干预遵循 10，不沿用 v1.0 中“NPC 永久死亡后置”的旧建议。

## 3. 有限但持续的世界范围

首轮建议围绕云岫、青溪、石桥及与旧案有关的有限区域建立持续生活。已有故事骨架、可靠证据和复仇收束继续成立，不能以新增动态系统重新让主线依赖唯一随机访客。

范围起点为：一个宗门生活场景、一个坊市场景、两类山野场景、数条持久路线、数个有明确生计的外部势力。精确数量在内容制作和性能测试后调整；每个新增地点应增加生活或策略差异，而非重复兑换菜单。

首轮生态只追踪能改变决策的有限状态：地表湿润、可采资源恢复、灵植阶段、道路状况、局部灵气压力。完整食物网、全球气候、大规模人口迁徙、全大陆政治逐帧推演后置。

人物总表只保存已生成且与地区、关系、事件或组织有关的持久人物。路边群众可由已登记的群体摘要表达；进入具体关系、交易、证言、战斗或财物归属后，才登记具名人物并保存身份。不能把同一个证人每次生成成陌生人，也不必为每片树叶生成实体。

## 4. NPC 的长期目标与生活计划

人物仍使用 01 的 `aspirations / commitments / preferences / activityId`。建议增加内嵌 `lifePlan`，不建立第二套可独立推进的人物主表。

| 时间尺度 | 内容 | 例子 | 改变条件 |
| --- | --- | --- | --- |
| 长期志向 | 想成为怎样的人、保全什么 | 拜师成丹、追索旧债、抚养亲属、建立安息之所 | 重大经历、目标完成、价值冲突 |
| 阶段计划 | 近期要补齐的条件与步骤 | 存够药钱、学会护脉术、赴市请匠 | 条件变化、可靠消息、承诺与风险 |
| 日常安排 | 起居、职责、研习、社交 | 清晨照料药田，午后授课，晚间调息 | 天气、需要、可达性、身体与约定 |
| 当前活动 | 实际占用身体的行为 | 到医庐换药、携材料前往工坊 | 统一活动生命周期与中断规则 |

阶段计划保存 `id / goalId / createdAtTick / currentStepId / dependencyIds / commitmentIds / reviewAtTick / status`。依赖引用本人已知的机会、已有物资和关系，不读掌门也不知道的幕后全知信息来“精准避坑”。

效用判断顺序：硬条件过滤 → 身体和安全 → 已同意的责任 → 目标收益与个人偏好 → 风险及机会成本 → 转换成本。权重可调，不能用“仁心高必救人”“魔道必掠夺”“匠人永不骗人”当生成规则。

NPC 可以认错、犹豫、受骗、拒绝不合理牺牲，也可以因经验积累改变判断。改变须关联可解释经历，不靠每次查看人物随机改性格。

### 4.1 从目标到实际出行

1. 人物发现与目标相关的机会，保存自己的知情来源。
2. 检查补给、物资所有权、现有职责、路线和风险。
3. 形成准备活动；对已同意的职责提出代班或告假请求。
4. 自己取得合法补给、约同行者，按本人接受的条件出发。
5. 成为 `travelsById` 中的参与者，停止院内工作并保留原身份。
6. 完成、失约、负伤、失踪、被俘或死亡按事实产生后续，更新有资格获知的人。

宗门公约可要求报备、公器借用和职责交接；能否遵守取决于本人选择和实际条件。玩家可劝阻、拒绝借出自己的物品、安排替代机会或亲自同行，不能取消 NPC 的身体自主权。违约和违规不能自动即时暴露，追责需要证据与合法处置流程。

### 4.2 可见解释与隐藏动机

玩家能看见“收拾行囊”“向执事告假”“前往山门”，不必知道此人每个私人理由。人物愿意披露时才显示“赴青溪购药”；秘密交易保留真实位置与活动状态，投影只显示已知去向和合理可观察行为。

公开理由、内心真实目标与本人相信的信息可能不同；活动仍由实际移动、工位和资源驱动。不能为了保密在画面中伪造人物仍在药田生产。

神色、语气、可疑动作也须有本人当前行为和可观察处境的来源。不能因为权威侧存在 `schemeId` 或秘密合作标记，就让 renderer 自动播放奸笑、红眼、阴影或“心虚”提示；真正留下线索的是绕路、藏物、错漏证词、目击交易等实际行为。

## 5. 生计、供给与日常相互依赖

人物生活须和 07 的物资、权限、岗位及运输一致。收入、产物、学习和消耗都有来源；天气或外出不构成额外发放资源的独立系统。

| 日常关系 | 世界如何反应 | 玩家可干预的条件 |
| --- | --- | --- |
| 医者缺药 | 延后非急治疗、采购、求助、试用已懂替代方 | 种植、拨预算、交易、亲自采药 |
| 匠人缺材 | 改做维修、寻找合法材料、推迟承诺 | 商路、回收、公器权限、交付期限 |
| 门人欲突破 | 寻找知识、准备药物、请教导师、选闭关环境 | 典籍、授业机会、灵气条件、护法 |
| 商队遇阻 | 驻驿、改道、请求护送、调整可交货数量 | 修桥、清障、公开通行协议 |
| 外出久未归 | 已知联系逐渐陈旧，原岗位空缺，近人提出查访 | 口信、调查、卜算、实地搜寻；见 09、10 |

地价、物价、工资等复杂市场不要求一次完成。首轮价格变化只由明确的供给、路线、信誉、关系或订单条件驱动，保留上下限和原因。不能每次开商店重抽报价，也不能让“物价上涨”同时凭空增加库存。

山院晚膳、师徒讲法、洗晒药材、修补衣物、共同祭扫等有可见场所与实际时长。可用少量活动类型表达，不要求每件生活细节都变成需点确认的任务。

## 6. 关系、记忆与可信生活

共同经历延续 01 的有向关系和重要记忆。增加的是经历的生活来源，不是另一条“友好度”。

- 守约归还、准时赴课、照料病人、分享可靠消息、承担公平份额，能形成可追溯的信任。
- 严重背叛、隐瞒风险、拖累同行、夺取私产不会被重复赠礼抹去；不同人物理解可以不同。
- 人物可能为亲友隐瞒行踪，也可能因旧恩向敌方求情；这不自动等于加入敌对阵营。
- 同一好事不重复结算；日常细节可以摘要，救命、师承、重大失约和生死结果必须持久保存。
- 一个可靠朋友可以明确拒绝危险邀请；拒绝本身不作为背叛事实。
- 有真实能力与代价的长期善意须兑现。内容作者不能把所有忠诚关系都在最后反转成骗局。

生活导演维护近期开销、伤病、争端和未解决危机的压力预算。压力较高时优先给可恢复机会、日常相处和可靠帮助；它调节新事件的启动，不撤销已经发生的天气、死亡或冲突，也不操纵每场结果保证玩家获胜。

## 7. 场景生态与连续变化

建议新增根表 `ecologiesBySceneId`，每条以 `sceneId` 为键，只保存需要持久的环境状态。建筑、人物、物品不复制进生态表。

| 状态 | 事实来源 | 持续变化与玩法 |
| --- | --- | --- |
| 地表湿润 | 降水、排水、地形、暴露条件 | 雨后逐渐消退，影响未铺路速度与适用灵植 |
| 资源斑块 | 内容定义、采集与恢复游标 | 有有限存量和恢复条件；过采降低后续可用量 |
| 灵植阶段 | 种植批次、照料、供给和环境 | 由播种到成熟、收获、休耕；不随镜头改变 |
| 地方灵气压力 | 地点基底、聚灵设施、使用和恢复 | 稳定适性与短期供需分开，闭关占用有代价 |
| 道路状况 | 既有路线、雨季损伤、修复事件 | 泥泞、局部落石、修复痕迹影响合法通行 |
| 事件痕迹 | 实际斗法、救灾、营造或调查事实 | 倒木、裂地、封条、祭扫物等引用事件和期限 |

资源恢复规则使用模拟时间和现存条件。切地图不能获得一次完整刷新；旧林的采集不会同时在库存和资源斑块各扣两次。

局部灵气不得作为无限“道韵货币”。07 中 `insight` 是既有抽象知识资源，场景 `ambientQi` 是环境条件；两者不能无说明互换。

首轮不计算全场水流或完整土壤化学。可按稳定地形区块保存湿润和资源斑块，必要导航变化只更新影响区块。季节外观也不能凭空改变场景碰撞或遮挡。

施工、清障、救治、开市、熄炉、成熟、损伤和修复都要有匹配的实际画面阶段。火光、烟、血迹和斗法残痕来自定义过的事件；纯表现粒子不能触发伤害或产物。

## 8. 历法、天气与预报

建议新增根表 `weatherByRegionId`。天气是区域内持续演变的环境事实，局部场景按地形、室内遮蔽和灵气条件派生实际暴露。远处山峰可有不同微环境，但不能仅因玩家切入场景随机换天气。

### 8.1 历法与持久天气过程

- 游戏日由 `worldTick / ticksPerDay` 派生，季节由版本化历法配置派生，不建立第二个季节计时器。
- 四季可作首轮内容方向；每季长度是可调参数，不能未经试玩把每季固定成现实数日的等待门槛。
- 普通天气候选建议包含晴、阴、雨、雾、寒、暑；雷暴等显著危险过程单独纳入压力与风险预算。
- 天气过程保存开始、阶段边界、结束、强度、局部种子与已提交转移，不能每帧重抽。
- 后续天气由此前过程、季节、地区特征和已保存随机流生成。计划天气序列属于真相，不代表掌门已知精确预报。
- 延续的湿润、道路状况与天气当前图标分开。雨停不意味着泥泞立刻消失。
- 改日长或季节长度必须迁移日相位、天气阶段、增长进度及结算游标，不能换配置后同一天收两次庄稼。

灵潮、瘴雾、异常冷雨等修仙现象是天气/生态与事件的受控联动。其来源可以自然、洞天周期或人为法术；权威事实引用真实来源，玩家投影先显示可观察异常，再通过调查确认原因，不能看颜色就自动判断“魔修所为”。

人为改天候使用已经定义的术法/阵法动作、范围、准备、消耗、持续、维持和失效条件。效果保存为该区域天气的 `modifiers`，引用实际活动、设施或事实，不重抽底层自然过程；同一时刻多种效果的优先、叠加与相消按版本化规则确定。查看、施法失败或模型生成文案不能临时改变范围和结果；停止维持后的剩余变化按既定恢复规则推进。首轮只开放少量可验收局部效应，不预设掌门可以无成本操控全地区雷雨。

### 8.2 每种天气至少改变两项可读决策

| 环境 | 日常与生产 | 行程与斗法 | 必须有的提示与对策 |
| --- | --- | --- | --- |
| 晴燥 | 可晾晒材料；露天灵植需适量供水 | 通常能见度好，开阔处暴露清楚 | 水源与遮阴条件、可见日照 |
| 持续降雨 | 停止不适用晾晒，照料与施工按配方调整 | 土路成本上升；已定义的水/雷法条件变化 | 屋檐、改道、穿戴或准备；不默认所有火法失效 |
| 山雾 | 户外观察和采集范围受限 | 远距离识别变差，埋伏和误认风险改变 | 视线变化、识路工具、停留或结伴 |
| 寒潮 | 特定灵植生长受限；露天活动精力代价变化 | 冰滑区域需实际地形条件，持续暴露影响状态 | 保暖、温室/炉火机会、暂缓行程 |
| 暑热 | 易损物品仅按明确保存规则变化；需更多休息 | 长时奔走精力成本提高 | 阴凉、补给与合理调整活动 |
| 雷暴 | 露天施工或采集者重新评估风险 | 高处和已定义导雷区域有预警；法术不能无规则免疫 | 渐进征兆、安全路径、避雷/护阵方法 |
| 灵潮/异常瘴雾 | 特定闭关或采集机会，同时有明确负担 | 阵法、感知或路线条件按内容定义变化 | 来源待查、已知禁忌、可行规避 |

每项数值修改由能力/配方/地形定义指定，不能另写“雨天全产出 ×0.5”覆盖所有流程。初版优先让少量差异实际可用，复杂组合后置。

天气不能对无准备的新手触发无征兆即死。自然危险的征兆、升级过程和致死可能性归 10 校验。天气可以让消息延迟、痕迹消退或道路中断；可靠主线证据须有另一种保留方式，不能一场随机雨把复仇永久封死。

### 8.3 预报属于信息

掌门可直接观察当前天气；远方天气来源于传信、路人、气象设施、经验或卜算。来源、时间、覆盖范围与可信程度按 09 保存。

预报可错在时刻、强度或地理范围，也可能有人借消息设局；普通村民凭经验的善意判断失误不自动生成恶意。观测设施提高可验证信息，不获得读取所有秘密天气/事件的权限。

界面使用“山口可能起雾”“此信为昨日午后所见”等自然语言，不向玩家展示未获知的准确未来随机序列。玩家调查后可以明确确认或纠正；长期可靠来源应积累声誉，而不是永远同一模糊概率。

## 9. 修行道途、利益与行为底线

正道、魔道、鬼道、妖道描述传承方法、社会身份或自我认同，不构成人物善恶结论。道途定义可以影响法术条件、制度禁忌与社会偏见；人格和具体行为仍由本人、利益、关系、机会及底线决定。

| 分离的轴 | 记录内容 | 不允许的替代 |
| --- | --- | --- |
| 修行方法/身份 | 法门来源、功体、组织归属、自称 | 正道 = 好人，鬼道 = 杀人者 |
| 个人价值与底线 | 守约、亲友责任、欲望、可接受手段 | 一个性格标签永久决定每次选择 |
| 真实利益 | 灵脉、供给、传承、保护、权力、债务 | 势力仅有对玩家好感数字 |
| 实际行为 | 有对象、手段、时间与后果的事实 | 名称“邪”自动证明犯禁 |
| 公众认知 | 已知证据、传闻、指控、公议与地区立场 | 隐藏事实自动全世界传播 |

同一正道门派可以有护民者、保守执事、逐利商脉和借名声攫利的掌权人；同一魔道组织可以重契约、护家人，也可以接受残酷手段。不能把某个职业、人格、阵营标签当作绝对善恶生成器。

鬼道修士可超度、护送亡魂、经营安息之所；拘禁无辜之魂是另一种具体行为。妖修有自己的生态、生计、社会关系与保护对象；妖道不等于野兽敌人。凡间与妖族争地可涉及农田、族地、狩猎和历史约定，不必须通过其中一方“其实邪恶”解决。

### 9.1 邪修、真实犯禁与诬指

用户提出邪修是公认异端、可被公议讨伐。世界观问答[U-39](13-WORLDVIEW-DISCUSSION.md)确认邪修与其他作恶严格区分：触犯公认修炼禁忌才认定为邪修；主动为达到修炼目的而屠城等重大暴行，属于邪修行为。正魔双方都可能出现邪修，不能只凭门类或重大伤亡自动定性。

真实失去理智、走火入魔等临时状态导致重大暴行，按U-39另行认定。实际修炼目的、行为时控制状态、状态诱因、损害事实、责任认定与公开指控分开；“自称失控”是可调查的说法，不直接成为权威事实。损害与受害者后果仍保存，具体追责、明知冒险和人为诱发失控的边界待讨论，不能自动免罪或自动归邪。

完整禁忌内容与具体适用边界尚待世界观问答；以下仍是设计候选，不是逐项获批名单：强行血祭有知觉的无辜者、拘魂炼制并阻断其脱身、以未同意的他人作为夺取修为/资质的耗材。确定后由版本化定义登记行为、对象与适用条件，并结合U-39判定；知情不足时只能是嫌疑或指控。

必须分开：`真实禁忌行为事实`、`掌门/公众掌握的证据`、`社会给予的邪修指控或公议裁断`。赤嶂门伪造栖霞沈氏邪修罪证的旧案因而继续成立，不能把被诬者改为真正犯禁来方便新系统。

公议、通缉和制裁是有权限、证据和传播的社会事件。它们可以被干预、隐瞒或滥用，但证明无辜、纠正错误与追究伪证要有可行途径。

正道人物暗通犯禁者可以出于谋利、把柄、亲属、恐惧或战略判断。私下合作须有接触、实际交换和风险，不能每天随机给一位正道人物添加“勾结邪修”标签。公然声讨与暗中交易能并存，利益与行为被发现后各方再响应。

同样，公开反对邪修的正道义士可以是真正可信的盟友。反转只能来自内容结构与既有事实，不能因为玩家已相信就强制改成伪君子。

## 10. 势力是持续经营的组织

扩展现有 `factionsById`，不新增独立“善恶势力”表。势力有资源、据点、关键人物、对外宣示、内部决策与已同意的承诺。

| 字段组 | 目标字段 | 权威边界 |
| --- | --- | --- |
| 身份与方法 | `id, organizationId, traditionIds, doctrine` | 宣示与修法分别记录，不决定成员人格 |
| 生计与利益 | `interests, resources, holdings, dependencies` | 引用真实设施、订单、商路或债务 |
| 公共立场 | `publicPositions, publicCommitments` | 对外已表达的态度与可知承诺 |
| 内部计划 | `plans, decisionPersonIds, privateAgreements` | 隐藏事实，只按获知权限投影 |
| 双边关系 | `relationsByFactionId, knownGrievances` | 利益、威胁、信任、契约和具体旧账 |
| 内部分歧 | `stakeholderInterests` | 引用已有关键人物/职位及其诉求 |

首轮不模拟无穷内部派系投票。选取少量关键人物代表确实影响当期事件的分歧，以可追溯决策产生行动。例如掌门寻求断供制裁、坊市执事担心药材断流、护民修士要求先转移村民；三方不是同一好感值的不同皮肤。

势力间可交换资源、缔结通行约定、争夺护持权、庇护某人、背弃承诺。每个结果必须创建实际事务和事实；新闻里说“商路封闭”，路线就应出现有来源的条件，不能只改一句文本。

公开立场不必等于真实动机。玩家通过账册、目击、可信口信、合同和实地变化逐渐了解；一次谈话不允许直接读出“真实利益”全表。

## 11. 信息传播与社会响应

08 负责消息为何需要流动；09 负责消息结构、真假、来源链、卜算与暗线。消息实体使用 09 的 `claimsById`；传播执行实例复用 `eventsById` 并引用 claim，不复制真假和来源链，不建立独立自发推送全知新闻的循环。

1. 行为产生 `factsById` 事实，确定实际在场或合法获知者。
2. 观察者形成自己的认知，可以真实、误解、不完整或刻意隐瞒。
3. 口信、信札、商队、师门、碑告与调查形成传播机会，消耗既定模拟时间及条件。
4. 接收者保存来源和观察时刻，结合关系、旧经验、利益与证据判断。
5. 人物和势力按自己相信的信息作选择；后续调查可以纠正。

已知来源没有目击的消息不能自动升级为真相；十个人复述同一封信也不是十份独立证据。真实讯息亦可能陈旧，例如“此人正在石桥”到掌门获信时对方已离开。

雨阻信使、山雾失联、坊市闭门可能改变传播机会。私下救助只有知情者先产生恩义；公示后才扩大声誉。救人时没有旁观者，不得立即全大陆仁义上涨。

世界地图和日志应展示获知版本、时刻、来源与当前可调查方向；隐藏事实、作者暗线和调试随机种子仅存在开发诊断中。

## 12. 局部模拟与离屏摘要

模拟层级由实际位置、事件要求和受关注实体的交互关系决定，不能由当前摄像机可见性决定。掌门在别院，切到世界地图后别院人物仍需工位、材料和路径；掌门出行时留守宗门仍按同一规则经营。

| 模式 | 适用范围 | 必须保留 | 可简化 |
| --- | --- | --- | --- |
| 局部活动 | 宗门生产、掌门到达地、需要实际干预的交互 | 实际身份、位置、槽位、材料、活动、命中与伤势 | 离镜头的动画和粒子 |
| 区域摘要 | 未到访的远方生活与生计 | 当前计划、阶段、合法机会、物资、关系、时间与结果 | 每步脚点移动、无关装饰 |
| 行程摘要 | 人物在地区间行动 | routeId、参与者、补给、进度、阶段边界与最后可靠位置 | 每米行走路径 |
| 危机过程 | 远方斗法/洞天危险 | 同一伤势、资源、阶段、行动时长、可干预窗口和结果 | 未干预前的细小动作；规则见 10 |

摘要任务不得免费绕过要害条件：无材料不打造、无人不产出、路断不到达、同一人不同时生产和远行。摘要生活仅计算定义允许的合法机会；精确工位尚未生成时记录受限容量与占用权，不编造第二份产物。

### 12.1 转换契约

- 摘要活动保存进度、阶段起止 tick、资源投入、实际位置类别与结果事务。
- 掌门真正到达、完成有效搜寻或触发同地交互时，将对应持久实体映射到合法场景锚点。
- 只为装饰细节首次生成种子；既有人物、宝物、伤势、参与者、天气和结果不重抽。
- 正在发生的斗法转换为同一事件、身体状态、资源和战术阶段；不恢复满血，也不先抽输赢再播放表演。
- 转回摘要后继续剩余进度，保存已发生的陷阱、清障、伤势、物品和关系。
- 进入渲染不能额外消费旅行时间；反复进出不能延长救援窗、刷新库存或阻止对手完成动作。
- 必须为转换中的无效位置和被拆目标提供安全修复，不能把死亡或任务失败当成几何缺失的默认补偿。

摘要推进可批量计算，但需按发生 tick 排序处理里程碑。遇到天气变化、人物中断、危机阶段、传播到达、产物完成或其他会改变条件的边界，先结算到边界，再重验剩余段；不能一次跳过整日后倒填不同因果。

关键结果相同的存档、种子与玩家命令，在不同镜头和等量 tick 批量下应产生相同事实。性能优化可以减少表现成本，不能改变谁先到、谁受伤、谁取得唯一物品。

## 13. 声画表现必须读实际状态

| 表现 | 状态来源 | 可读目标 |
| --- | --- | --- |
| 人物姿态、工具、短活动 | activityId、阶段、目标、装备 | 分清谁、在哪里、正在做什么 |
| 炉烟、读书灯、屋内人声 | 正在执行的设施活动、日相位 | 看懂哪个地方确实有人使用 |
| 雨、风、雾、滴水、衣袍摆动 | 区域天气与局部暴露投影 | 当前环境能被识别，但不遮住人物选择 |
| 灵植、泥路、工地、残痕 | 场景生态与事件事实 | 看见成长、消耗、建设和事情的后果 |
| 坊市喧闹、课堂、晚膳 | 开市阶段、人数、活动与场所 | 安静和繁忙来自真实生活 |

声音服从距离、室内外、活动阶段和用户音量设置；同一活动不因帧数重复播放结算音。静音与减少动态模式仍能辨识天气、危险和人物行为。

强雾、雨丝、法术与屋顶退隐不能遮住所有触控命中区；人物选择仍满足 03 的 44 CSS px 与重叠候选要求。纯环境动效可降级，模拟事实、提示、可读性和点击正确性不能降级。

禁止用整幅概念图、静态截图或“生活声效”代替空间、日程和生态状态实现。验收录屏需来自实际运行并展示状态变化、存档恢复及交互。

## 14. 代表场景与世界链

以下是内容制作样例，不意味着用户逐项指定这些剧情。样例应覆盖日常、可信帮助、冲突和暗线，不能全部改为骗局。

| 场景 | 可持续事实 | 可展开选择与后果 |
| --- | --- | --- |
| 雨后的别院 | 医者换药、药师暂停晾晒、门人搬入干燥处研读 | 掌门修排水或调整用途；雨停后恢复工作，不生成额外奖励 |
| 守约的魔道商人 | 其商队依契约交付，保护同行者，但索价严格 | 按约获可靠帮助；价格争议与道途偏见分别处理 |
| 正道义士与执事 | 义士先救被困山民，执事担心护送造成断粮 | 提供补给、分担责任或调整路线；两人的顾虑都有现实依据 |
| 鬼道安息院 | 收容亡魂，要求按约归还遗物，误被传成炼魂窝点 | 实地查证、取信村民或揭露真实冒名犯禁者；不预定全院反转 |
| 妖修守护的林地 | 药商过采与族地禁猎冲突，山民又急需药材 | 配额、替代药源、共护路线；暴力和协议留下不同记忆 |
| 伪君子的公议席 | 公开禁邪，私下接受带来源问题的材料 | 有实际交易和证据链；查证、交易、告发或另寻可靠渠道见 09 |
| 世家子弟的告假 | 为病亲寻药，隐瞒财务困境，自主前往险地 | 借药、代班、劝阻、同行或搜寻；危机按 10 演变 |
| 老匠归还借器 | 修好法器并兑现旧约，向后辈授业 | 稳定合作与师承机会，可信支线有完整兑现 |

### 示例链：雨、桥、药与人

1. 连雨使石桥通行变慢，商队选择驻驿，青溪实际药材交付减少。
2. 别院医者发现缺药，提出替代方或采购请求，掌门可亲自调查。
3. 一个正道护民者组织修桥，一个魔道商人愿供材料，但要求事后公平交易。
4. 有人散布“魔修封路索财”，传闻引用同一来源，不能当成独立证据。
5. 掌门可实地看桥损、查交易记录、听山民证词或接受合理帮助。
6. 修桥后路线条件和场景发生变化；药材由实际运输抵达，伤者按时间恢复。
7. 知情者产生恩义、公议可以纠正传闻；说谎者是否恶意、受谁驱使由既有事实和暗线决定。

该链可有干预与不干预的持续结果；世界不因掌门没有点接受而停止。它无需成为主线的唯一通关条件，也不能仅由消息文本宣布桥修好了。

## 16. 存档、迁移与规则版本

- 两个新增表、NPC 阶段计划、势力私约和传播引用均需进入存档与结构/引用校验。
- 旧档第一次迁移采用确定的地区气候与生态基底，保留当前日相位、已有天气、人物和结果；未知字段用兼容映射，不能重生成旧人物。
- 不对旧档追算之前的季节、雨损、暗中交易、生态透支或 NPC 致死危险；新规则从明确的迁移 tick 起生效。
- 已知公众立场迁移为已知事实，不凭单值旧声望捏造私人阴谋或某人犯禁。
- 未具备新生态资产时保留实际资源与设施，显示一致的临时表现和未完成状态，不删除事物。
- 当前实际存档仍为 v5；新增 schema 版本号及迁移路径由实施阶段决定，不能仅因设计 v1.1 就宣称存档已升级。

## 17. 分工与实现门槛

08 定义生态、天气、生计与社会结构；01 负责本人决策和关系；03 负责合法空间和表现；04 负责篇章锚点与地点；05 负责唯一状态和时钟；07 负责物资与组织；09 负责信息、计谋与作者暗线；10 负责危机、搜寻、斗法与生死；11 负责 AI 的受限可选内容能力。

先建立一条可观察的“天气 → 日程/生产/行程 → 信息传播 → 玩家实际介入 → 地点与关系后果”闭环，再扩天气种类和地区。仅创建字段、粒子和新闻模板不计闭环完成。

实现时须为每项环境效果记录定义、适用条件、数值来源、原因码与验收。离屏摘要和局部活动只保留一个权威写入者；任何批量优化需对照同等 tick 的参考演算。
