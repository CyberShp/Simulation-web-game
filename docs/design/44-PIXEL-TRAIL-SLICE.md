U-136：用户将当前剑气、火诀、护阵的动效确定为初级技能表现，并要求继续。U-137：用户选择“颗粒再细一级，保留清楚的像素轮廓”。本批沿用 U-135 已认可的纯 2D 山院与人物，把独立桌面演武扩为一次可连续行走的近山行程：**山院 → 石阶溪桥 → 绕松林道 → 谷地会武 → 实际返院**。

Windows 为主力平台，macOS 先验证。具体路线、图像尺寸、集结区和 16/32 人配置分别按 R-42、T-15 实施；这些实施参数不记作用户逐项确认。运行结果、截图和遗留画面问题见[近山行程实机记录](../art/hd-pixel-trail-20261014/RUNTIME.md)。

本批继续使用 [43](43-PIXEL-ARENA-SLICE.md) 的独立演武身份与档位。正式经营、剧情、物资、人物成长、三个正式存档和米制世界的完整接入另行验收；像素路线不承担正式世界迁移。原庭中演武、一对一和山院自动游览入口保留。

## R-42 · 连续行程实施契约（recommended）

### 同一空间、身份与规则

原山院占图像坐标 `0..1672 × 0..941`；南方林道与谷地继续使用同一二维坐标。人物沿地面实际寻路，跨区域不重建身份、不重置气血、灵气、冷却或已发生的事件。玩家只直接控制掌门，青方同伴自主随行，交战双方自主选择目标和施法。16 人与 32 人沿用同一个模拟模块和输入接口。

行程阶段为 `outbound → combat → return`。到场由 `trail-world.mjs` 的 `TRAIL_ARRIVAL` 与 `isTrailArrival()` 共同定义：掌门进入合法到场区，所有存活青方进入谷地集结纵深，且双方进入接敌距离后，才开始自动会武。

全部赤方力竭后进入 `return`，模拟继续运行，气血和灵气保留；掌门实际走回山院返程点的指定半径内才结算胜利。掌门力竭、双方同时力竭和主动退出沿用 43 的结果规则；结束后只结算一次并冻结。32 人属于负载与战斗观察配置，败退、平局和主动退出都按真实结果记录，战斗参数沿用 43。

### 地面、障碍与镜头

地面通行与招式视线分开判定。水面、悬崖、石岛、实体栏杆和既有建筑占地限制行走；开放水面本身不阻断远程视线，岩石、栏杆和其他实体遮挡会阻断招式。地面区域、障碍、寻路、移动与保存位置校验共用 `battleWorld(state)` 返回的导航对象。非法移动目标应明确拒绝，并保留已有有效路径。

镜头跟随、滚轮缩放、右键拖动、全景和小地图只改观察位置。缩放 1 继续显示原 1672×941 近景尺度，大地图扩展保持近景角色尺寸。小地图点击或双击不能向地图后方角色发攻击。返回近景后，人物身份、位置、行动和时钟始终对应同一模拟中的当前状态。

四份既有素材 `courtyard-v1.png`、`cultivator-v1.png`、`disciples-v1.png`、`garden-props-v1.png` 保持；南方地形使用 `trail-terrain-v5.png`。地形、树石遮挡与人物脚点分别呈现；视口外对象可停止绘制，但继续参与同一模拟。近景须检查人物轮廓、血条和技能反馈可辨性，尤其是 32 人交战时的文字、法阵及底部技能栏遮盖。

战斗跟随取掌门附近交战者的可见范围，并为下方技能栏留出空间。飘字围绕掌门及所选对象显示近期反馈；同类反馈只显示最新一条。掌门护阵保持完整效果，NPC 护阵使用短时环形提示与实际护盾血条。这些变化只影响呈现，完整伤害、护盾和事件仍保留在模拟快照中。

### 时钟与存读

唯一模拟仍由 `arena-sim.mjs` 的 100 毫秒整数步推进；共享前台计时模块精确复用 `src/simulation/ea-runtime.mjs`。渲染、相机、小地图和状态读取不能推进规则。失焦、隐藏、最小化、暂停及关闭后不积累世界时间，恢复前台不补离开期间的时长。

沿用独立 `pixel-arena/arena-save.json`，QA 使用各自目录。存档包含模式、行程阶段、稳定人物、位置、路径、动作、冷却与事件，不保存墙钟差值。原子写入、读取后校验、坏档保留和失败暂停按 43 执行。读取后暂停且关闭自动操作，玩家可选择继续或重新开启自动行进。旧 `team` / `duel` 演武存档保持兼容；正式游戏的历史布局迁移不由本切片代替。
