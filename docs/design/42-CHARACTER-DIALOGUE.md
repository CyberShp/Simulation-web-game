# 42 · 人物立绘与统一交谈

设计基线：DB-2026-10-05 v1.2。2026-10-12，依据 [U-125](DECISIONS.md) 登记人物交谈规则。用户已确认所有 NPC 采用人物立绘与聊天对话窗口，并要求先写好规则，再继续 [U-124 的普通新档开局全链验收](41-COURTYARD-VALLEY-IMPLEMENTATION.md)。本文件状态为 **designed**；统一人物窗的运行接入、存档接入及实机验收待实施。

依赖：[01 人物与自主](01-CHARACTERS.md)、[05 运行时契约](05-RUNTIME-CONTRACTS.md)、[06 局部验收](06-OPENING-ACCEPTANCE.md#9-人物交谈局部验收u-125)、[08 活世界](08-LIVING-WORLD.md)、[09 知情与线索](09-INTRIGUE-OPPORTUNITIES.md)。收徒资格继续读取有效决策与人物事实。

## 1. 同一人物、同一窗口

点击任何 NPC 都进入同一套人物窗口；招募前后、门派归属、职业、任务和临时处境只改变可见内容与回应。场景、立绘、人物志、商店、任务、同行和战斗始终引用同一个持久人物 ID。

| 区域 | 呈现与规则 |
| --- | --- |
| 左侧立绘 | 保持稳定外观；可见衣着、装备、伤势和神情取自当前可观察状态。秘密身份或动机不能直接生成暗示特效。 |
| 姓名与简况 | 显示掌门已知称呼、主要身份与当前关系；其他已知身份及经历进入人物志。身份未明者使用现用称呼，后续得知真名仍是同一人。 |
| 右侧聊天 | 呈现对方说话、掌门回应及本次已公开的事情；人物说法保留说话者，不直接标成已证实真相。 |
| 当前回应与话题 | 先提供当前一句话的回应，再提供此时可谈的话题；进入话题后在原窗口继续。 |
| 交易／委托展开 | 在右侧展开货品、委托条件、进度或交付信息；左侧保留同一人物，随时可返回交谈。 |

原型见 [陆知微静态画面](../art/character-dialogue-20261012/dialogue-lu-zhiwei-v1.png)及[制作说明](../art/character-dialogue-20261012/README.md)。左右区域沿原型组织；具体比例、字体尺寸、立绘细节和文案继续随实机评看调整。首屏显示 **3–4 个主要话题**、其余收进“另谈一事”是本版呈现建议，并非用户逐项定标。

## 2. 十六类人物情景

下表是内容覆盖清单。职业、组织身份、个人关系、事件参与和暂时处境可以叠加；每行不建立独立窗口。所有邀约仍受本人意愿、真实位置、身体、承诺及实际资源约束。

| 情景 | 默认呈现 | 可谈内容 | 行为条件 |
| --- | --- | --- | --- |
| 1. 招募后门人 | 称呼与当前院中生活 | 近况、修行、差事、任职、同行 | 门籍与权限、本人意愿、能力、资源和时间 |
| 2. 求道者／来访者 | 来访缘由与已知经历 | 志向、求助、暂居、入门 | 收徒权限与名额、入门条件、双方意愿 |
| 3. 普通路人 | 寒暄与眼前见闻 | 问路、风物、打听消息 | 本人知道且愿意披露的信息 |
| 4. 不带委托的商人 | 营业问候与生意近况 | 看货、行情、议价 | 营业状态、现货、财力和交易条件 |
| 5. 带委托的商人 | 生意与已知约定 | 买卖、问需求、接取、交货 | 委托阶段、真实货物、期限与付款能力 |
| 6. 其他门派普通成员 | 已知门派与个人称呼 | 见闻、修行、私人往来、切磋 | 个人立场、关系、能力及可公开内容 |
| 7. 掌门／长老／使者／管事 | 当前职务与来意 | 拜会、交涉、合作、门派事务 | 实际授权范围、组织规则与已知立场 |
| 8. 委托人／证人／事件相关者 | 当前事件中的已知关系 | 问条件、核实、追问、交付 | 已获线索、当事人知情与事件阶段 |
| 9. 神秘人／身份未明者 | 可见形貌与现用称呼 | 询问来意、试探、交换消息 | 本人披露、掌门观察及已有证据 |
| 10. 医者／匠师／鉴定者 | 手头工作与可提供的服务 | 求医、修器、制作、鉴定 | 真实能力、材料、费用、工位和时间 |
| 11. 师长／隐士／传艺者 | 当前交往语气 | 请教、论道、求艺、授业约定 | 已知所长、传承权限、授受意愿与机会 |
| 12. 守门人／巡逻者／执法者 | 值守、查问或当前事件 | 通行、拜会、说明来意、询问规则 | 凭据、现场情况、规章与实际职权 |
| 13. 旧友／离宗者／旧日对手 | 共同经历与当前态度 | 叙旧、旧约、近况、再合作 | 持久关系、既有恩怨与当下意愿 |
| 14. 同行者 | 当前行程与已同意约定 | 休整、去向、风险、分工、离队 | 实际位置、补给、身体与队伍约定 |
| 15. 妖修／鬼修等 | 已知形貌、自称与社会身份 | 按其职业、关系、经历展开 | 具体能力与交往条件，修行道路不预定态度 |
| 16. 负伤／忙碌／戒备／敌对中的人 | 当前可观察状态和回应 | 关怀、稍后再谈、解释来意、交涉 | 意识、身体、安全与是否愿意交谈；昏迷者只呈现可观察情况及合法行动 |

同行、伤势、忙碌、戒备和敌对可以改变；某人参与委托也不改变其基本身份。身死者继续保留人物记录，现场按遗体与已知事实交互。

## 3. 多重身份与个人、门派关系

同一个人可以同时是“他派外门弟子＋坊市药商＋旧识＋账册委托相关人”。窗口可提供“谈账册”“看看药材”“问近况”“告辞”，各话题读取各自事实，不因身份叠加复制角色、商店库存或委托。

个人亲疏、门派立场与职务权限分开判断。与他交好可影响私人帮助意愿，代表宗门的交易、通行、传授、结盟等仍须其实际授权。一个普通成员的回应不能自动代表全派态度；他解释的门派情况仍保留消息来源。

主要身份根据当前交谈场景与已知信息选择，人物志可查看其余已知身份；隐秘职位、真实阵营和未知事件关系不进入标签。入宗、离宗、任职或转变立场后，延续原外观、记忆、承诺、财物及历史称呼来源。

## 4. 动态话题与回应

话题由已知身份、双方关系、当前处境、已知事件和实际能力共同决定。当前正在谈的事情优先，随后是已知的紧急事项、约定及相关日常；排序不得利用未公开真相提示危险或机缘。

- 尚未知晓的人物、物品、委托和秘密不会以空白锁定项、条件提示或置顶话题提前出现。
- 已经知道但暂时不能做的事情，说明可公开原因，例如缺材料、尚未到场、正在忙碌或本人拒绝。缺少机会与不愿接受分别表达。
- 拒绝可由本人说出理由；解释只代表其说法，UI 不补写隐藏动机。同一邀请与相同条件下反复点击、关闭重开或读档，回应不重抽。
- 条件真正变化后可以重新评估，例如伤愈、补齐材料、关系变化或新证据。重谈旧事不重复增加好感、授予物品或生成奖励。
- 关怀、寒暄和叙旧可以只有对话结果；行为、承诺、知识或关系发生变化时，明确反馈实际变化及来源。

## 5. 交易、委托与重要操作

“看看货物”在右侧展示当前可交易物、价格、数量与对方；选择后显示本次买卖的物资、价款、归属和交接条件，确认才提交。返回交谈与关闭窗口均保留已经生效的交易事实；库存和报价按实际来源变化，不由开关窗口刷新。

委托在右侧展示对方已说出的需求、报酬、期限、交付地点和已知风险；有未知细节时使用当事人说法与已知范围。

| 玩家操作 | 实际含义 |
| --- | --- |
| 听取条件／询问进展 | 阅读或获得本次实际披露的信息，尚未承诺接取 |
| 明确接受 | 校验条件后登记约定与期限，按该委托规则处理资源预留 |
| 准备好物资 | 物品仍位于原货位或随身位置，等待实际交付 |
| 确认交付 | 校验人物、地点、数量、所有权和阶段后，一次提交物资与报酬 |
| 返回交谈／关闭 | 结束当前阅读，不改变已有委托状态 |
| 明确解约 | 展示已知成本和约定后果，经确认再处理 |

付款、大额赠予、正式收录、任职或同行约定、交付、解约及主动敌对等会改变财物、关系或职责的重要操作，应有清楚的对象、内容及已知后果确认。确认可在同窗内完成，不要求每句普通回应二次弹窗。未知结果不预告为确定事实；已确认行为按同一命令与结算规则执行。

## 6. 实际距离与人物状态

选中远处可见人物仍打开同一窗口，先显示可观察简况与“走近交谈”。此时不播放尚未发生的面对面对话，也不开放需要近身的交易、交付、治疗或邀请结算。

选择走近后，掌门按真实通路移动，到达本次行为允许的距离后重新检查对方位置、意识、忙碌、安全及意愿，再进入交谈。具体距离读取行为规则，本文不另设一个适用于所有行为的米数。对方移动、离场、道路被挡或条件失效时给出当时可知的原因和继续方式。

人物志或名单可查看已知记录；异地人物只呈现最后可靠位置与消息时间。面对面动作需要实际到场。昏迷、身死或无法交谈者仍使用同一人物呈现与记录，提供其当前合法的观察、照料或其他行动。

## 7. 阅读暂停与行动耗时

进入人物窗口的阅读状态时，**全世界一起暂停**：移动、生产、战斗、天气、伤势进程和期限均不推进。对话内的商店、任务和人物志阅读共用这一暂停，不局部冻结被选中的人物。

窗口暂停与玩家原有的手动暂停分别保存。正常运行时进入阅读，关闭后可继续运行；原本已经手动暂停时，关闭仍保持暂停。嵌套子页只在退出整个阅读状态后释放窗口暂停；前后台、失去写锁等其他暂停原因继续生效。用户在期间主动改变的暂停意图优先，退出窗口不能覆盖它。

走近、治疗、搬运、授业、同行出发、战斗等有实际耗时的行动，先确认或排入计划，再退出阅读进入世界推进。原本运行者恢复推进；原本手动暂停者保持暂停并提示继续后执行。暂停时允许提交的即时交易或剧情选择按现行命令规则结算，不把本需耗时的行动瞬间完成。行动后重新进入对话阅读时，再暂停全世界。

恢复推进重新锚定现实时间，不补算读字、后台或关闭时间；阅读也不累计 U-119 的三十秒手动期。

## 8. 状态与存读

谈话对象、委托、货物和关系均引用现有权威记录。重要对话保存实际披露的陈述、说话者、来源与世界时刻；已接受的约定、拒绝的结果及其条件、物资结算、关系变化和关键回应保存一次结果凭据。普通闲聊可摘要，不能挤掉重要承诺或已发生的事实。

显示用的当前页、展开话题、滚动位置与未确认输入只属界面状态。存读可以恢复阅读位置，或回到该人物的当前合法入口；恢复时重新校验距离与条件，不自动提交未确认行为，不重播有奖励的结算。对话、商店、委托与人物志不持有各自独立的生命、库存、关系或时钟副本。

保存加载遵守 [05](05-RUNTIME-CONTRACTS.md)：保留旧档人物、门籍、财物、重要经历、随机状态与已定事件；新增对话字段通过显式兼容映射补齐。首次打开窗口不生成另一名同名人物或重新抽取其意愿、天赋和外观。
