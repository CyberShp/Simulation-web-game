# 五洲修行谱 · 青衡洲扩写四十项

2026-10-11 作者评看稿。接续[五洲修行谱](19-FIVE-CONTINENT-ARTS.md)、[修行体系评看稿](21-CULTIVATION-SYSTEM-REVIEW.md)、[五洲修炼地评看稿](22-WORLD-CULTIVATION-SITES-REVIEW.md)和[扩写第一批](24-FIVE-CONTINENT-ARTS-EXPANSION-01.md)。本稿登记 `Y-108–147` 四十项青衡洲成形的独立可学内容；地点、持有人与高境篇章是待作者卡和地图落位的内容提案，尚未接入游戏或存档。

一项只选一个主类型；同一项的续篇、抄本、兵器、符箓和阵位不另编号。品相评价适用境界内的结构与用途，不能代替境界跨度、到手篇章、契合和流传稀度。表中“炼／筑／丹／婴／化／合”分别是炼气、筑基、金丹、元婴、化神、合体；写出跨度表示传承拟有相应篇章，不表示一位持有人已经拿齐。通常可在普通练位学基础段，灵地是增效或特定突破条件；导师只能教授自己理解的篇章。凡是战斗动作，位置、起手、结算和成本仍由同一世界步记录；“反制”栏对百艺也说明失效边界。
