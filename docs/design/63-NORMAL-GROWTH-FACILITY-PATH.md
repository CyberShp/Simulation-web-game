- 阶段 1：故事至少到 2，或已有门人。

## 3. 依赖较少的炼气接续顺序

### A. 现有桌面可以先做

1. 在原药圃详情使用正式启停按钮，恢复 GC20。该档药圃完好，当前只是停用；后续实际种植仍受种粮、工位和人物意愿约束。
2. 继续采集、搬运和有限交易备料，通过 GC16 预设入口营建采伐场。一级成本为 25 灵石、20 木、8 石；材料先实际到 HOME，再按既有营造运单送到工地。
3. 采伐场完工可运行后，掌门实际走近林长风，从同一人物交谈窗选择外门／内门／亲传及相应师承，正式收录。复用 `admitCourtyardVisitor`：同一 `personId`、本人既定意向、当前距离、十五人上限、可达实体床位和一次收录事实均由提交时重验。
4. 收录成功后，故事 2→3；门人由 1→2，连掌门共三人。阶段仍是 1。林长风的入住要等其本人实际到床，收录时先登记目的床承诺。

对应代码：[当前桌面命令](../../apps/courtyard/sect-sim.mjs)、[正式收录投影与提交](../../src/simulation/ea-courtyard-admission.mjs)、[开局故事适配](../../src/simulation/ea-opening-sim.mjs)。

### B. 主峰第一处应接藏经阁

1. 完成 GC02 固定建位与真实道路后，沿原营造流程建设一级藏经阁。其规则只需阶段 1，可在招足五人之前完成。
2. 在藏经阁／成长详情提供明确的“整理遗卷”操作，调用当前正式 `advanceStory`。schema 6 当前分派到 `advanceSRStory`：故事 3 时要求掌门在山院及可用藏经阁，登记家传札记事实，收入 **《春雨养脉法》与《青岚筑基篇》两书**，故事推进到 4。
3. 法门页现有 `study` → `masterStudy` → `studyArt` 已接实际阅卷席。春雨从理解 0 起，两次研习分别到 12、24，即达到医庐所需的 20；每次预留 2 口粮、到场研读 80 世界步（8 模拟秒），行路和休养另计。正式收书不会直接增加理解。
4. 若后续需要灵膳，可在取得春雨理解 20 后按真实来源取得《丹霞药理经》，再研习至 20；此项不是医庐基础诊疗的必要前置。当前 `obtainBook('alchemy')` 有旧规则与报价，但桌面尚无获取入口，接入时仍需核实其书籍来源和实际接触条件。

当前桌面仅有开局修殿时的故事 0 推进和林长风收录时的故事 2 推进，尚无故事 3“整理遗卷”的正式按钮。只补这一当前章节操作即可取得基础药理，不必把全部山外调查页面同时接入。

### C. 补足医庐阶段所需的真实成员

林长风加入后仍需另外 **3 名**自愿门人，才满足五名门人的阶段 2 条件。当前桌面收录适配只接受 `person:lin-changfeng`，这是医庐炼气路线的实际运行缺口。

旧公开 `recruit` 会支付 65 灵石、8 草、8 口粮并直接创建、接纳一个新人物；虽然已有床位事务，它仍没有求见行程、当面意愿与正式门籍选择过程。39§2–3 要求真实到访后再收录，因此不能只把这个旧命令直接挂到桌面按钮上。其旧档和已有公开调用语义继续保留。

最小接续建议只覆盖山门求见这一可靠来源：

1. 既有世界时钟产生有来源的求见机会，创建一次持久候选身份，保存意向和行程；沿现有南山路实际到院前。
2. 复用统一人物交谈窗及收录选择；本人同意、近身距离、身体可用、门籍／师承、十五人上限、供给及可达床位共同约束提交。
3. 接受、拒绝、暂缓、离院与再次来访保留原人物和结果；只在新的事实条件下产生后续机会。
4. 供给和居住实际承载成立后逐人增加名册；从同一连续档验证到五名门人，不预设三次邀请必然成功或固定总等待时间。

这一步使用 39 已批准的山门来源与 U-111 收录原则，具体候选节奏、接待成本及同意条件仍需作者参数登记。十五人完整分布、坊市求见与熟人引荐可另批接入。

程问舟当前是伤匠事件人物，校验明确要求其不在 `homeMemberIds`；行脚医师、讲师、阵匠访客当前是服务事件，均没有正式加入选项。它们不能直接计入五名门人。

### D. 医庐可建及启用服务

阶段 2 与至少一人春雨／药理理解 20 同时达成后，按实际库存准备医庐的 90 灵石、45 木、30 石、15 草，经 GC14 正式运料施工。

完工后仍须将疗程材料搬入医庐现场仓，并分别安排患者和合格医者到真实诊疗位／病床。掌门可以承担医者，另一位伤者作为患者；医生与患者不能共用一个身体。患者没有伤情时，保留设施可用，不以人为制造伤势来宣称正常救治验证。医庐病床继续独立于住宅常住床。

## 4. 少人正式立派的既有备用路线

阶段函数允许正式立派后直接达到阶段 3，因此“五名门人”不是所有世界唯一的医庐开放路线。当前 `foundingStatusSR` 的少人专业路线要求：

- 掌门真实筑基；至少三人（含掌门）。
- 可运行藏经阁；至少一人实际理解达到 60；至少一次兑现的共同生产。
- 至少一日共同口粮；立派费用 180 灵石、60 木、50 石、20 道韵。

当前陆知微青元理解 100 已可满足“成熟传承者”数值，林长风加入后可满足三人；仍须实际完成炼气六层到筑基的修为与材料、筑基续篇理解 35、筑基丹及立派事务。桌面目前显示突破条件但没有正式突破操作，也没有可靠筑基丹委托和立派入口。该路线所需成长交互更多，可作为后续主峰／护山亭的接续，不能据它声称医庐现在可开。

相关正式接口已经存在：`beginBreakthrough` / `masterBreakthrough`、`reliableFoundation`、`foundSectSR`。接入时保持每次真实修为、材料来源、到位、消耗与冷却；不把少人路线变成直接写入组织阶段的按钮。

依据：[实际突破与委托](../../src/simulation/ea-sr-cultivation.mjs)、[正式立派条件](../../src/simulation/ea-sr-organization.mjs)、[当前修行页入口状态](../../apps/courtyard/courtyard-panels.mjs)。
