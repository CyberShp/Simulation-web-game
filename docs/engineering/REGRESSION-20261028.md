## 产品修复与测试归因

**东台真实路径故障。** 长段每2.5厘米采样与实际短步的采样落点不同，一条压过尖角的规划段被判可行，执行时却拒绝并清空路径。掌门第二趟石料仍随身、施工未推进。现在仅对东台长段规划增加既有2.5厘米偏移余量，并保持室内/门槛豁免；实际身体半径、地形及执行检查不变。规划与执行缓存分别记为 `east:planning-margin`、`east`，相同房间几何之间共享时仍隔离。

- 原公共行走抵达、两批材料交付和施工完成断言保留。到达后的自治检查改读正式身体活动、开始时刻和工位预约，因为正式模拟可先自行进入修炼，并不一定产生控制器命令日志。
- 增加5个起点/方向 × 3种步速的实际步进回归，包含原浮点停点；在原基线立即复现清路停滞。
- 独立审查直接恢复原tick7292失败状态，125步后tick7417完成；第二批石20于7315实交，第一批木40记录及原工时保持。
- 这是现有采样规则下的执行验证；短边和起点连接保留原检查，不宣称所有细缝均获得连续几何证明。

**宿主和战斗测试契约。** VM 补齐产品已经依赖的路线规划器、剑术音频、实时视图与 `structuredClone`。当前单人场景按48×32米战场、实际sceneFrame、剑气射程和已完成动作记录验收；旧场景夹具明确移除新几何/规则标记。剑气接触点核对实际不透明身体行，保留命中一次、打断、成本、暂停和序列化边界。出口只在正式命令返回 `approaching` 时再次确认，已进入旅行的命令不重复发送。

**经营夹具与记账。** 客院使用正式开启命令及GC15批准位置；规划点列表反映已接入客院。让行夹具整体东移0.5米，仍验完整退让路径和唯一预约；未扩大让行搜索半径。旧访客加载保持原脚点，世界步后按已接入的可见地面恢复行走，并核对同人同货。生产金额在9位小数纳单位上验证精确守恒，避免用二进制减法尾差代替业务结果。
