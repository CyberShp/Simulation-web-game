# EA 1.1 原型接入与验收（浏览器验收完成）

用户已确认：沿用云岫别院场景，EA 全玩法开发并代验收；10 组、35 个原型画面全部纳入接入范围。03 与 05 使用修订图。

## 实际接入

- 主界面：全屏山院，八个图标＋短名称；桌面左栏，手机底栏与管理抽屉。
- 正式核心：沿用 `ea-sim`、`ea-society`、`ea-campaign` 的修行、经济、人物意愿、故事与战斗，不使用独立庭院演示的资源/升级规则。
- 人物：6种稳定外观；同一个门人按身份ID固定选择，院内、档案、出行和战斗共用。多名门人可复用一种外观；并未承诺无限独特模型。
- 行走：主画面石路、竹林、桥和台阶共用注册道路。途中位置与路线进入v5存档；旧v5及v1–4迁移保持兼容。
- 营造：14类设施与真实12×10地块，建造/迁移自动切地块视图；主场景点击区域只选择真实已建设施，未建区域显示筹建入口。
- 生产：府库、炼丹、坊市/委托三页；正式材料、消耗、产出、数量与交易限额。
- 山门：阶段画面依真实阶段切换，治理、任职、分峰、访客均使用实际意愿和状态。
- 山外：9个独立地点原型派生背景，实际路线、调查点、归山口；舆图真实锁定/解锁、同行邀请与实际行程。
- 战斗：同风格2.5D角色，通用开阔场与原型栖霞决战场；实际生命、真气、冷却、预警、胜负与同行伤势。
- 存档/设置：3个档位、滚动备份、恢复、导出/文件导入、校验后粘贴JSON导入；暂停/倍速/音乐/音效/减弱动态/文字大小。

## 验收范围与限制

本轮 189 项自动测试、48 个界面模板、正常玩家公开命令通关与浏览器验收完成。逐项证据和未覆盖范围见 EA-1.1-ACCEPTANCE.md。
验收入口 `ea-preview/?acceptance=1` 使用独立档位、独立锁及通讯命名空间，且不读取正式旧存档。正式网址的数据不用于验收。
山外自由点击会投影至当前场景的注册山路，远离道路的点击拒绝；战斗用实际开阔铺地平面。
前景遮挡只覆盖已有注册遮挡区域；不是完整3D碰撞。九个地点已检查场景与交互点，山谷桥面、遗址平台、栖霞台阶等已做实际行走检查。
手机浏览器尺寸可以验收，真实iOS/Android设备及长期实机性能不在远程浏览器覆盖范围。
