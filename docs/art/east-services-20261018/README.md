## 图像坐标与组合

服务图块候选全局原点为 `(8360,0)`，逻辑尺寸为 **1672×941**。作者量测统一采用 **1670×941** 坐标；最终逻辑横坐标为作者横坐标乘 `1672/1670`，纵坐标不变。

原生生成尺寸在版本间有少量差别，各图完整适配到同一逻辑尺寸。[ground-and-join-survey.json](ground-and-join-survey.json)为每张图提供原生尺寸与采样转换，使用时同时读取这些字段。empty-v5 的原生采样比例为 `(1669/1670,942/941)`，construction-v1 为 `(1,942/941)`；完整形象图为 `(1,1)`。

组合以 empty-v5 作公共底图，各址使用其独立 `stagePatches.complete` 或 `stagePatches.construction` 叠加屋身、附属设施、门阶和院前铺地。两院可以分别处于空地、施工、完工状态。图块接续另外使用 join-v2 的道路裁剪及景物过渡带。
