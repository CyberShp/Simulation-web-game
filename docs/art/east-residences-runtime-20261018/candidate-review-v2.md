## 投影接口与连续性

[布局模块](../../../apps/courtyard/courtyard-residences-layout.mjs)的 `createResidencesCandidateProjection({legacyToArt, legacyToWorld})` 返回 `toArt(x,y)` 和 `toWorld(artX,artY)`。结果是 `{x,y}`；非有限输入返回 `null`。模块自身没有运行时导入。

world x≤160 委托调用者的旧投影。新旧深度过渡在全局画稿 x6808–6906，即 world x160–162，内完成；这两个边界的横向锚点在前后两排相同。后排使用 y≤50 的横向列，前排使用 y≥60 的横向列，中间按深度连续插值。两列均严格递增，深度列也严格递增。

反算先在给定 artX 上求混合深度的分段线性逆，得到 worldY，再求对应横向列的逆，得到 worldX。此顺序利用了过渡区两个公共横向锚点；过渡区以东的画稿深度只取决于 worldY。完整锚点、边界值和外推检查保存在[审计 JSON](candidate-audit-v2.json)。

复算命令：`node docs/art/east-residences-runtime-20261018/audit-candidate-v2.mjs`。

## 左侧接续

join-v3 的图像原点为全局画稿 `(5852,0)`，尺寸1672×941。全局路心折线为：

`(6327,765) → (6356,775) → (6476,805) → (6688,820.56) → (6730,801) → (6763,775)`。

旧东台石阶旁增加石板平台，土石路由此接入新图西侧竖路。`RESIDENCES_JOIN.polygon` 负责图像裁剪，`walkPolygon` 负责脚下路面；两者用途独立。道路裁剪边缘羽化20像素，另以全局 x6632–6744 的窄全高景物带过渡两幅图的林石边缘，羽化24像素。

沿米制路心每0.1米取样，共195个位置，各检查32向、半径0.26米脚圈，均落在量测 walkPolygon 内。[接缝静态合成](join-composite-v3.png)显示土石路与两端地面连续；此检查没有调用正式寻路。

## 阶段合成

统一以 empty-v4 为底图，每址按 `stagePatches[stage]` 叠加 complete-v2 或 construction-v1。完工范围包含屋顶、侧墙、台阶和门前铺地；施工范围包含全部木柱、梁架、石基和现场材料。各阶段范围把周边林木与最大预留地面留给公共底图。

已分别目视[全完工](stage-composite-complete-v3.png)、[全施工](stage-composite-construction-v3.png)和[混合状态](stage-composite-mixed-v3.png)。三种静态合成的完整设施轮廓和背景连续性成立。混合图为 GC11 完工、GC12 施工、GC10 空地，可用于运行接入后的同状态对照。

运行层的阶段叠加、111像素人物比例、遮挡与点选仍按实际运行截图核对。静态几何与素材检查不承担营造、存读或玩家通行结果。
