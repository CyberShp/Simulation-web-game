## 当前实现

| 内容 | 本批实际范围 |
| --- | --- |
| 场景 | 1672×941 固定斜俯视像素山院，主殿、石阶、亭桥、山林合成在一张底图。当前开放庭院与主殿前阶导航区域。 |
| 独立图层 | 青衣、红衣、白衣三种人物外观共 20 张源帧，石灯和盆松两个可遮挡道具；地面法阵、空中特效与前景石栏遮罩分别绘制。 |
| 人物动作 | 青衣 8 张前／后行走帧、待机、出剑起势与释放、施法，共 12 帧；另外两种外观各 4 帧。人物脚点与遮挡按场景坐标更新。 |
| 行走 | 点击寻路、键盘连续移动、障碍绕行；屋顶、水域、崖沿、石栏占地、石灯及盆松占地拒绝通行。 |
| 镜头 | 1–2.8 倍缩放、右键拖动、全景、自动跟随与分段自动镜头。Canvas 2D 保持清楚的像素边缘。 |
| 技能 | 剑气、火诀、护阵的动作与独立像素效果；示例冷却为 2.8／5／8 秒，冷却内重复释放被拒。 |
| 人数与界面 | 16 名示例人物。两排各 12 个技能槽中，1–3 接入动作，其余为空位示意。 |

素材由内置 imagegen 生成，完整要求见[素材提示词](../../../archive/prototypes/pixel_scene_validation/assets/prompts.md)。运行使用透明图集的独立帧；人物、道具和特效由 Canvas 2D 绘制，Electron 提供本地桌面窗口。这是本批样件的制作方式，完整游戏的最终引擎选型仍另行确定。

## 评看边界

当前验证的是一处固定山院的画面、局部行走、遮挡、镜头与技能展示。底图中的其他亭桥、远山和建筑仍是画面，尚未制作连续大地图；16 人是本次样例，人数上限未测。技能效果的光感和细节仍比静态样板简化，完整方向动画与更多角色动作也待扩展。

样件不读取或写入正式模拟、世界时钟和三个存档；其人物与冷却只服务本地展示。正式实时战斗的伤害、目标、敌我规则、经营接入及存档迁移尚未实施，本批也不验证这些能力。Windows 运行与用户最终美术认可待完成。
