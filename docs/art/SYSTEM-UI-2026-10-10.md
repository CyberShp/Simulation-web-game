## 实际验证

2026-10-10 在本地 `http://127.0.0.1:8787/painted-game/?acceptance=qa-game-ui-20261010` 使用 Playwright CLI / Chromium 浏览器实际操作；截图留在本地 `.playwright-cli/`，未作为正式验收图上传。

1. 宽庭院打开，雕纹导航和卷册显示；新档资源为玉110、木65、石45、草22、粮50，掌门《青岚养元诀》理解40%、熟练0%，均与模拟投影一致。
2. 门人卷册可切沈砚与来访的陆知微。陆知微未入宗时明确标为来访者；场景人物是否室内由正式位置决定。
3. 新档伤势未好时点击“安排研习”被真实规则拒绝，未生成订单或扣资源。按页面暂停后，世界 tick 停在3633；保存和读档仍为3633且保留暂停。
4. 导入隔离 QA 档 `qa/acceptance-indoor-v12/opening-invite.json` 后，卷册读取三名成员；点击研习后粮38→36，生成 `order:cultivation:1`，真实结算后理解40→52。理解/熟练不够时邀请陆知微授业被拒，未生成授业订单或因此扣费。
5. 再次研习生成 `order:cultivation:2`，暂停并中止，预留粮28→30，订单消失；复测停止在同一世界时钟。`node --test tests/ea-godot-bridge.test.mjs tests/ea-godot-host.test.mjs` 17/17通过。
6. 桌面 1200×850、横屏 1194×834 与竖屏 834×1194 视口已检查画面、卷册和按钮。竖屏改为底部卷册并让庭院铺满画布；最新构建在画布中央点地使掌门从室内出行至院地，点“陆知微”使正式选择身份与来访者卷册一致。真实 iPad、DPR2/横屏触摸和更多人物遮挡回归仍待。

已知边界：绘画底图包含门人居和膳房的固定画稿，而导入存档中的营造实体可能不同；目前还不能把画稿当作全部正式建筑状态。除沈砚、陆知微外的人物缺少本场景对应二维动画。当前入口只作为本地系统预览，不替代公开正式游戏、已发布美术试游，也不推进 SR-XF-007/014 的完整验收状态。
