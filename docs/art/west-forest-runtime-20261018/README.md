## 生成提示词组

以下为最终生产目标的整理；原始调用包含对应参考图片与局部位置校准。

**完工图。** 生成 1672×941 的原院西侧高清像素山林图块，固定斜俯视、日光、蓝灰瓦与暖木构、松林岩坡、下方溪谷。小型木材棚与封闭工具屋坐落左侧林缘，屋前两处锯架与开阔土场，入口 `(500,607)`，道路经 `(772,640)`、`(1052,620)`、`(1342,580)` 到右边 `(1672,562)`。人物由运行层绘制。保持原山院的地形、材质和体量。

**未建图。** 编辑同一完工图，仅替换 `x145..625,y350..590` 内的棚屋和器具。该处呈现自然林缘空地、苔草、落叶和小径，保持入口、道路、树木、山岩、河流与桥的固定关系。

**施工图。** 编辑同一完工图，仅替换相同工作院范围。棚屋处呈现低石脚、立柱、少量横梁与工具屋木框；中央土场和入口畅通，已交付材料由运行层按实际数量绘制。

**西桥连接。** 将西林图右半与原院图左半作为同尺度参考，生成 1672×941 的连续桥谷图。中部呈现一座与原院尺度相称的灰石拱桥，桥面在 `y562` 附近；前后河水、松岩和远谷贯通，供运行时裁入接缝窄带。
