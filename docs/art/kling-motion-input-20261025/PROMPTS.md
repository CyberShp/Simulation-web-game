# Kling 动作输入包

2026-10-25。用途：由用户在 Kling 生成沈砚的待机、起跑、跑步与停步视频，返回原视频后再抽帧、统一尺度、核对脚点并制作游戏素材。本包尚无 Kling 输出或动作验收。

## 上传哪些文件

- **01-idle-start.png**：单人浅灰底待机首帧；待机、起跑和组合样片用它。
- **02-run-start.png**：同角色跑姿首帧；持续跑步、停步用它。
- references/：身份母图、场景比例、旧跑步接触表及GIF，只用于人工对照。不要把多人母图或八格接触表直接当单人视频的首帧。
- 两张首帧由内置 image_gen 依据角色母图新制，均是视频输入参考。主Agent已查看人物、四肢、剑尖及身份特征；背景为浅灰RGB，非透明。两张的精确脚点、像素尺度未作正式注册，不直接替换游戏素材。
- starter-image-prompt.txt、run-starter-image-prompt.txt 保存这两张图实际生成提示词。

## 推荐先试一条组合样片

使用01为首帧，正方形构图。如界面可选10秒，可按下面的10秒作者编排尝试；若所选模式不提供这个时长，按相同比例调整分段。下面是创作提示，不是已经验证的Kling输出结果。

复制以下全文：

```text
固定镜头的2D像素游戏角色动作样片。严格保持输入图中同一个蓝白衣装剑修的脸、发髻、长发、衣装、玉饰、身材比例、持剑手和像素画风。固定斜俯视三分之四机位，人物始终朝画面右方；全身、两只靴子和完整剑尖一直在画面内，镜头位置、焦距和人物大小保持不变。浅灰背景保持静止。

角色在画面中心原地完成一段连续动作，身体的地面投影不横向移动：
0—1秒：双脚落地的轻微呼吸待机；
1—2秒：身体略前倾、重心转移，支撑脚蹬地，迅速进入跑步；
2—7秒：持续自然地原地跑步，左右腿轮流承担支撑，清楚呈现落脚、承重、蹬离、腾空，两个半圈交替；髋部只有小幅自然起伏；
7—8秒：连续两步收短步幅、卸去前倾，平稳停下；
8—10秒：双脚落地，回到开头的待机姿态。

右手始终握住同一把刚性的细直剑，剑保持在身体侧后方，随手臂小幅自然摆动，剑身不穿腿；左手自然握拳配合动作。头发和衣摆随动作轻微滞后，停步后逐渐落稳。保持清楚的像素边缘和稳定色块，每一帧只有一个完整角色。动作清楚利落，正常速度，背景与光照保持一致。
```

可选约束文字（有负面提示栏就放入；没有则追加到主提示）：

```text
避免以下情况：镜头平移、跟拍、推拉、旋转、切镜头，人物转身、改变朝向、横穿画面、忽大忽小，换脸、换衣、换手持剑，新增武器、剑鞘或人物，肢体增生、双腿融合、鞋底漂移、关节反折，剑身弯曲或穿腿，夸张弹跳、慢动作、运动模糊、拖影，3D写实化、水彩化，光效、剑气、灰尘、文字、字幕、背景变化。
```

这是原地动画素材：支撑脚会相对身体向后运动，不要求鞋底在画面上固定。后续将根节点位移与步频对齐，才能检查游戏中的滑步。不要同时要求“原地跑”和“身体向右穿过场景”。

### 待机

```text
固定机位的2D像素游戏待机循环。输入图中的同一名剑修保持右向斜俯视三分之四朝向、原来的身材和画风，全身和剑尖始终完整可见。双脚牢牢落地，不迈步，只有很轻的胸肩呼吸和重心变化，发梢与衣摆小幅自然摆动。右手稳定握住原来的直剑，左手保持自然握拳；身体中心、相机、画面比例、浅灰背景和光照固定。动作平静克制，末尾自然回到开头的姿态和运动状态，适合截取循环。保持每帧身份、四肢和清晰像素色块一致。
```

### 起跑

```text
固定机位的2D像素游戏起跑动作。输入图中同一个剑修始终朝画面右方，保持原来的斜俯视三分之四视角、身材、衣装和像素画风。开始短暂站稳，随后重心略微前移，支撑腿蹬地，另一腿前摆，在很短的过渡内进入稳定的原地跑步，然后持续跑动。起步干脆，没有长时间蹲伏蓄力。左右腿真实交替支撑，髋部小幅起伏，头发衣摆跟随加速。右手始终持同一把直剑低置侧后方，左手自然握拳。人物地面投影始终居中，不横向穿越画面；全身与剑尖完整，相机、人物尺度、背景和光照固定。
```

### 跑步

```text
固定机位的2D像素游戏原地跑步循环。保持输入图中同一个剑修的外观、身材、衣装、右手持剑和清晰像素画风。人物始终朝画面右方，机位保持斜俯视三分之四角度；身体地面投影固定在画面中心，只有自然的小幅上下起伏。左右腿交替完成落脚承重、向后蹬离、屈膝前摆和短暂腾空，两个半圈都清楚呈现，节奏匀速而轻快。右手持刚性直剑低置侧后方，剑与手牢固连接，左手配合自然摆动，头发衣摆有轻微惯性。持续跑动直至结尾，末尾接回开头的腿部相位，适合截取完整周期。相机、尺度、背景和光照固定，全身与剑尖始终完整，不新增动作或特效。
```

### 停步

```text
固定机位的2D像素游戏停步动作。输入图中的同一名剑修先保持短暂稳定的原地跑动，随后一到两步连续缩短步幅，支撑腿吸收重心，身体从前倾回到稳定的双脚站立，接着保持轻微呼吸待机。头发和衣摆在停步后自然延迟摆动并落稳。始终朝画面右方，保持原来的斜俯视三分之四视角、身材、像素画风和服饰。右手始终持同一把直剑，左手自然握拳；没有跳跃、攻击或转身。人物地面投影居中，全身和剑尖完整，相机、画面比例、浅灰背景和光照固定。
```

## 操作与返回

- 时长、模型及分辨率按账户当前可用项选择；不依赖特定版本专属控件。优先保留清晰原视频，避免平台二次压缩或聊天软件转码。
- 首尾参考差异过大可能导致切镜头；这两张图是相近机位的候选，仍需看实际输出。若过渡出现变脸、缩放，先用单首帧生成。
- 保存每条使用的模型、提示词、首尾图、时长和原视频。返回后先核对人物一致性、双腿交替、握剑和镜头稳定，再选帧、去背景、统一像素密度与地面根点。
- 不要求Kling直接给出8帧sprite sheet或精确480ms循环。先获得可用运动，再挑连续完整周期；不能以强插帧或拉伸身体掩盖缺失动作。
- 本包未上传到Kling，未消费账户额度，未改运行代码或存档。
