2026-10-15。用户认可山域扩建总图方向，并在近景母稿交付后明确“可以开始还原吧”（U-144）。首屏以 `courtyard-v2.png` 为基准，直接复用环境像素，加入独立人物、状态与行走。实际受验配置和结果见 [首屏运行记录](RUNTIME.md)；实机美术认可由用户评看后登记。

## 2. 材质怎样保留

优先把经确认的近景母稿转为可直接绘制的二维素材：连续地面、建筑外观、前景树石、接地阴影和人物分别处理。能复用的像素直接复用；对象遮挡后的缺失地面、透明边缘、施工阶段和动画新增帧单独制作并对照原稿核验。

各素材登记母稿位置、裁切范围、原始尺寸、脚点、占地、入口和遮挡边界。接回同一镜头后，先看静态构图能否复原，再加入行走与经营状态。分块仅组织加载，块边缘沿同一地面连续衔接。

新素材以已确认的石板、瓦面、木构、松针、岩面、田土局部作为对照。逐项比较颗粒大小、纹理密度、色相明度、边缘清晰度、光照方向和接地关系。新生成的图并不自动继承认可状态。

## 3. 精度与比例怎样约束

先固定一份近景受验配置：窗口像素尺寸、显示缩放、镜头位置、视角、正常缩放及最近缩放。具体数值随近景母稿登记；当前样件的40×26投影和72像素人物只属于未通过画面审核的实现初值，不据此反过来迁就原型。

以人物、门洞、建筑占地、台阶和地砖共同校准视觉尺度。游戏坐标、人物脚点、建筑入口与画面必须一致；已有存档的位置和活动需要合法映射后才能改变布局。

素材制作尺寸覆盖约定的最近观察倍率。原始高精度母图始终保留；拉近时使用有足够细节的素材，不能将已经降采样的图块当作高清来源再次放大。像素采样方式、非整数缩放和屏幕像素密度分别用实机检查，单独关闭平滑并不能证明精度保持。

当前 `sect-renderer.mjs` 将材质图集中每块约627×627像素缩到200×130后绘入图块，再由镜头缩放。该链路会减少材质可见细节；后续制作必须依据母稿和受验显示尺寸重新确定素材分辨率与缩放方式。

## 4. 先过一屏实机，再扩山域

首个受验小样只需包含主殿、石阶、药田、松岩和两位人物，并能看到与总图相符的扩建出口。交付以下相同机位、相同显示尺寸的证据：

1. 近景母稿与实际运行截图并排比较。
2. 静态环境半透明叠加，核对建筑轮廓、台阶、道路、地标和地面边界。
3. 屋瓦、石板、树岩、田土及人物的同尺寸局部放大比较。
4. 正常操作短录屏，检查移动时的脚点、遮挡、贴图接缝、缩放清晰度和动态效果。

以下任一问题出现即继续修正该屏：建筑或人明显变形、比例失衡、材质颗粒突变、模糊或闪烁、重复铺块明显、贴图接地不实、跨块裂缝、场景出口与总图不符。代码测试、素材文件校验和静态原型不替代实际画面认可。

用户确认首屏实机达到近景母稿的质量后，再以同一素材标准推进东台与道路。后续区域仍逐处对照；首屏通过不代表全域已经通过。

## 5. 承诺的边界

能够约束的是基准文件、素材来源、分辨率预算、固定镜头证据和阶段验收；这些规则必须落实到后续制作过程。当前不能承诺整张山域在所有缩放、所有动态状态下与单张概念图逐像素相同。新增细节和可变化部分的质量，需要实际产出与对照证明。
