- GC-18与GC-19分别使用各自`patch`和`cropPatch`多边形，涵盖稻穗、田坎及对应整备区域；`selectionPolygon`同可见田块。两块田各自切换未建、施工、空田、秧苗与成熟状态。

- 各设施裁剪各自独立。GC-17器具裁剪右界640，GC-24裁剪左界642；仓房侧墙不会混入采石阶段。
