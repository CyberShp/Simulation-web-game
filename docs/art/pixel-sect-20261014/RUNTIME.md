对应 U-139 / U-140、R-43 / T-16；实施契约见 [45](../../design/45-SECT-IDLE-SLICE.md)。本批 macOS 应用名称为“云岫山院·宗门经营”，源码在 `prototypes/pixel_scene_validation/` 的 `sect-*` 文件。

## 来源与行为

起点由正式公开命令从同一普通开局建立：疗伤择卷、建立主殿、赠药、陆知微入院、营造药圃。起始世界步646，公库灵草6、灵石60、口粮50，主殿与药圃均已建成。完整命令轨迹及源文件／状态哈希记录于 `sect-seed.mjs` 的 provenance；重建脚本为 `sect-seed-build.mjs`。

全部资源、人物、导航、工位与物流使用正式 JS 模拟。桌面策略层依目标选择命令，镜像掌门控制元数据，以同一世界小步推进。人物自主生活仍服从正式规则：陆知微自行接受工作、安排休整修炼与成长。本人亲控后保留活动，新的移动或身体命令按原规则替换。

首版开放灵草目标、来源整备额度、守院生产／本地采集两种偏好。整备额度约束新增来源恢复花费；口粮、工资及人物成长另按实际结算。持续口粮补给、更多发展目标和近山冒险尚待后续接入，当前不会把灵草目标当成全部经营职责。
