# 云岫林间像素动作样板

依据 U-171，制作一名青衣剑修与一只山魈的俯视战斗样板。CrossCode 用于构图与动作可读性的参考；实际素材由已核许可的 LPC 帧和地形组合。本文记录制作目标，运行结果在 73 制作记录中另行登记。

## 角色与动作

- 沈砚：男性身体、青蓝长袖、浅色裤装、黑色长发与单手长剑。同一身体和服装图层覆盖所有选入动作。
- 山魈：壮硕的两足怪物轮廓，绿肤与棕色裤装，颜色与青衣剑修区别明确。
- 每个身份共用画布、站姿身高标尺和落地锚点。帧内抬脚和腾空保留原动作，播放时不另加整身上下位移。
- 移动切入从循环起点开始，连续转向保留循环相位；停步直接进入同源站姿。攻击和受击读取真实动作阶段，施法出手后按现行规则恢复走位。
- 采用完整逐帧图像。剑、头、衣服和身体在离线合成时对齐，运行时绘制整帧。

## 林地构图

- 保留当前 48×32 米战场与 22 米宽跟随镜头；药丛、桥与侧洞继续引用正式障碍的位置和尺寸。
- 地面使用安静的草色与少量纹理，树木集中于外围，中央保留移动和法术阅读空间。树木、地形和人物采用一致的像素颗粒。
- 环境使用 LPC Revised 的草地、树木与相应道具。源文件、裁切矩形、脚点及署名随资产保存；任何额外拼图均留制作配方。
- 小样覆盖正式交战画面。完整宗门场景与其他人物动作库继续按各自批次推进。

## 本批核对

逐帧复看人体尺度、双脚、持剑手、衣装层和透明边缘，再在实际桌面检查移动→停步→攻击→受击的连续切换、鼠标瞄准、技能释放与窗口失焦恢复。完整素材缺口、离线映射复用、实际帧间隔和用户视觉认可分别记录。

## 选入素材与复做

选入外部制作包 `combat-pixel-v003`，运行目录为 `assets/courtyard/combat-pixel-v1/`。两身份共40份动作manifest、198次帧引用，使用两张角色atlas；实际独立图像保持190格。人物与山魈均使用192×192画布、脚点[96,126]，站姿身高标尺分别49/45。主Agent已复看快步、带完整长剑的挥击、施法掌心、怪物反应及环境接触图。

移动是原生八帧walk以460毫秒播放的快步；guard复用施法帧，dodge复用两张走步姿势，hit/down使用正面受击源。manifest保存具体复用来源。攻击原列0–2为windup、3–4为release、5为recovery；短步的windup/release/recovery/evade分别使用原walk列4/5/5/5，阶段内保持原姿势。运行中的阶段持续时间与命中仍由正式战斗决定。

完整源文件与署名见运行目录的 `sources/`、`ATTRIBUTION.json` 和 `CREDITS.txt`。角色合成资产采用CC BY-SA 3.0，环境采用OGA-BY 3.0；生产脚本与锁定配方见 [LPC制作工具](../../../scripts/art/combat-pixel-lpc/README.md)。实际桌面验收与用户美术认可另列。

## 首次桌面验看

2026-10-25，根已查看实际桌面的四向移动/停步及双方受击截图。角色尺度、衣装及脚点使用同源整帧；当前视觉仍存在草地重复和场景层次不足，同行人物尚为旧样式。专用奔跑、闪避、防御及四向受击动作尚不齐全。本包用于评看整体像素方向与动作切换，完整角色设计和场景美术尚未验收。
