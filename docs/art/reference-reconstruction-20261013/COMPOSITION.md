# D 主殿与山院：固定机位构图基准

本批按用户选定的 [D 原图](../desktop-style-review-20261013/d-realistic-3d.png) 制作主殿及周边山院的静态实机还原。正式经营、新战斗和人物重做在后续批次处理。本文件提供作者从图测量的构图约数与调试建议；世界尺寸、位置、相机参数及误差阈值均为作者实施初值，不是用户逐项批准的数值。

## 画面坐标与八组锚点

原图为 **1659 × 948**。坐标原点在左上，`u=x/1659`，`v=y/948`；以下小数为目视约测，边缘有树木、栏杆及屋檐遮挡，通常有约 0.01–0.02 的读数余量。复核时使用完整场景画面，先统一宽高比，再对照相同实体部位；不把外层窗口边框或界面计入坐标。

## 相机与米制位置的试算起点

主殿正面朝 `+Z`，相机主要从 `+Z` 向 `-Z` 看，保持接近中轴的正面视角。原图能看到屋面和大片铺地，但主殿正立面仍很完整；主体垂直轴基本竖直，两侧不出现明显的大幅侧视。

下列为首轮共享试算参数，实际模型尺寸与摆放按当前源码和实机对照继续调整：主殿原点 `(0,4,-28)`、宽 30、深 16、屋脊绝对高度 23；石铺庭院 `x=±21、z=-12..24、y=2`，外围花园及外台延至 `x=±31`，连接两侧亭和右桥；中央纹样位于 `z=6`；主殿阶梯从 `z=-20` 向 `z=-12` 落到院面。作者相机试算起点为：

```text
PerspectiveCamera verticalFov = 48 degrees
aspect = 1659 / 948
position = (0, 25, 62)
lookAt   = (2, -5, -3)
```

这组参数把主殿屋脊 `(0,23,-28)` 投到 `(0.478,0.012)`，殿前阶脚 `(0,2,-12)` 投到 `(0.481,0.352)`，中央纹样 `(0,2,6)` 投到 `(0.482,0.452)`，院前中心 `(0,2,24)` 约投到 `(0.483,0.627)`。这是不启动 GPU 的 Three.js 数学投影计算，尚未证明屋面、台基或其他模型的实际轮廓与原图吻合。

左右亭试算初值为 `(-36,2,-16)/(37,2,-17)`；按 C03/C04 对实际屋顶与石台继续微调。右桥中心 `(34,1.7,16)` 约投到 `(0.898,0.531)`，可据 C08 微调。前道从 `z≈25` 延伸，朝画面右下缓弯，让画底裁切到连续路段。

外平台以树石、栏杆及退台收口，首帧应按 C06 核对中央石铺广场与两侧绿地的分界。所有米制值均为作者实施初值，图上锚点优先。

修改顺序建议为：先锁参考宽高比及相机朝向，再对主殿整体大小和上下位置，随后对庭院纵深、侧亭间距与桥道。若主殿和庭院无法同时对齐，应检查台基高度、屋面层次、庭院尺寸及局部位置，而不是只靠相机将所有物体挤进同一框。

## 材质与明暗关系

- **屋瓦与木构：** 屋瓦为偏冷的深灰蓝，瓦垄在日照下产生细长、克制的灰银亮边；檐下木构为深暖褐，斗拱、梁柱和门扇靠结构阴影分层。金色主要落在门饰、细边和局部装饰，面积较小。
- **台阶与铺地：** 石材为带暖意的浅灰，中央铺地是画面最大的明亮区域。铺地分块、接缝、磨损及浅色变化可读，中央纹样融入石面。台阶踏面比竖面明亮，阶缝保留连续节奏。
- **主光与阴影：** 原图明亮面及人物、旗杆投影显示主光大致来自画面右上，地面影子向左下延伸。屋檐下和石桥孔内形成深阴影，阴影中仍可辨认结构；从檐口到庭院保持明确的亮暗层次。
- **植物与崖石：** 前中景为深浅相间的松绿、橄榄绿，树冠有独立团簇与透光间隙。石块表面有灰白断面、暗缝和局部苔色，轮廓组合成可读的崖台、桥头和庭院边界。
- **水与远景：** 右侧溪流为偏冷青蓝，水面反光与白色浪沫分布在落差和岩石附近。远山随距离降低反差并偏蓝灰；远山、云雾和天空用于衬出近处主殿、侧亭及松树的轮廓。
