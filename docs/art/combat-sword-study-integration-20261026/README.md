# 持剑单人战斗正式接入

本批承接用户认可的剑气交手样板，将整帧人物、山魈身体命中、环境与音效接入 Electron 的正式单人山谷战斗。对应 SR-XF-007、SR-XF-013、SR-XF-029；沿用73的实时战斗与完整帧要求、U-172的针对性场景验证。完整动作库、同行与群战仍按各自范围验收。

## 规则与兼容

新建单人 `valley-open-v2` 战斗在创建时登记 `rulesProfile=sword-study-v1`。已有未标记战斗保持原参数与素材；身份、身体、伤势、奖励、胜负、确认与返院继续由原模拟处理。

WASD移动、鼠标瞄准、J或左键普攻、Q指定落点、Space闪避。普攻可移动释放；Q需要已学剑法，在第三个100ms世界步出手，随后恢复移动，下一步按锁定落点结算。未出手时闪避可取消，已出手落击独立继续。原术法与1/2/3快捷键继续保留。

本批调节值：剑气射程8米、可见平面速度12米/秒，核心长0.7米、宽0.1米；Q半径1.1米、射程8米、灵气16、冷却18步，正式伤害公式保留人物境界、剑法理解与装备因素。闪避与山魈原攻击规则沿用。以上数值属于当前实现的T值，长期平衡未验。

身体命中与Canvas共用整帧选择器、原生alpha≥64轮廓、脚点、缩放及镜像。山魈帧由正式整数世界步选择。人物身高标尺1.45米、山魈2.35米；战场48×32米，跟随视野22米。
