# 云岫山院 · 系统界面原型

本原型用于评看宗门经营中的信息与操作，使用示例人物、物资和队列。正式游戏规则、存档与开局场景另外接入。

- 《山门与幻境》弟子界面：[图文实拍](https://www.3dmgame.com/gl/3935515_6.html)。已目视核对生活状态、装备、中央人物、根骨特性和战斗技能的空间归属。

## 导航与每页任务

底部常驻入口：门人、功法、行囊、百艺、任务、山外、宗务。掌门头像直达掌门详情。营造是场景工具，选项目后在既定建位预览。农业、采伐、采石的人员与岗位在宗务的差事页；炼丹、炼器、傀儡的配方和工单在百艺。

| 页面 | 默认内容 | 玩家操作 | 进一步查看 |
| --- | --- | --- | --- |
| 门人 | 峰别、可筛选名册、当前事务与异常、所选门人摘要 | 找人、比较状态、定位、邀请承担事务 | 人物修行、装备、身况、关系 |
| 掌门 | 人物与装备部位、身况、修为、当前修行和攻守配置 | 调息、修炼、换装 | 招式、伤势、修行条件 |
| 功法 | 本门藏经目录、类型筛选、所选法门和可研习者 | 找法、看收益与条件、选择研习者 | 传承节点、境界跨度、已知来源 |
| 行囊 | 掌门装备部位、物品格、选中物品属性与用途 | 换装、服用、整理、移入公库 | 物品来源、可用对象 |
| 百艺 | 配方目录、材料到成品的关系、工位与人员、现有队列 | 选方、定数量、邀请匠人、安排工单、撤销 | 工序、缺料、等待原因 |
| 任务 | 正在进行的事务与故事线、目标进度、发生地点 | 追踪、定位、查线索 | 已完成纪事 |
| 山外 | 地图、已知地点与路线、所选地点、同行者 | 选目的地、看风险与耗时、筹备出行 | 地点情报与线索 |
| 宗务 | 具体岗位、空缺、门人当前承诺、库存供给 | 调整优先次序、发出邀约、查看生产点 | 公库、各峰权限 |
| 营造 | 院景、建筑目录、固定建位和投入预览 | 选择工程、确认或取消 | 施工进度与运料 |

## 页面构成

- 面板居中占大半屏，窄边框、短标题栏、边缘页签、方形道具槽，正文以人物/物品/工单为主体。
- 名册用行列展示比较；装备使用身体部位槽；功法使用法门目录与传承树；百艺使用配方与队列；山外使用地图。
- 主要操作在所选对象旁；次级详情回到原有选择位置。材料不足、无人可接、未得原卷均直接显示具体状态。
- 装饰只占框线、页签、槽位与图标；图案承担人物、装备、法门、材料和地点的识别。
- 竖屏保持可触达与局部滚动，具体画面以浏览器预览另验。

## 模块与接口

公共窗口、导航和场景工具由 `game-ui-core.js`、`game-ui.js` 与 `game-ui.css` 实现；人物与行囊位于 `game-ui-people.js`，功法与百艺位于 `game-ui-arts.js`。`build-game-ui.py` 生成可预览入口。

所有脚本为普通 JS，按 core → people → arts → main 顺序内嵌。`window.GamePanels` 为页面注册表，每项包含 `title`、`render()`、可选 `click(button)`、`input(element,eventType)`。根事件只分发当前页。注册键：`disciples`、`master`、`bag`、`arts`、`crafts`。

公共方法：`Game.refresh()` 重绘当前页；`Game.open(page,params={})` 切页并将参数交给目标 `enter(params)`；`Game.toast(text)` 显示短消息；`Game.icon(kind)` 返回 SVG，支持 person/sword/book/herb/pill/wood/stone/jade/robe/boot/ring/cauldron/forge/puppet/build/mountain/scroll/flag；`Game.portrait(index=0,large=false)` 返回人物图容器；`Game.bar(label,value,max,tone='jade')` 返回状态条；`Game.escape(text)` 做文本转义。页面返回 HTML 放在 `#screen-content`。

共同 CSS 类：`panel-tabs` + `button.active`，`pane`，`pane-title`，`subtle`，`gold`，`danger`，`good`，`game-button`（主要按钮 `.primary`），`icon-slot`（小图标），`data-row`，`stat-pair`，`toolbar`，`tab-row`，`scroll-area`，`empty-state`。专用类分别以 people-/profile-/bag-、arts-/craft- 开头。

按钮使用 `data-action` 分发；输入使用 `data-field`。模块内保持自己的样例状态，不写正式存档，不自动推进时钟。关键操作须有实际状态变化，且可见按钮都有明确用途。每个页面第一眼展示其主要对象与当前问题。

## 原型验证与用户确认（2026-10-12）

用户已认可本版画面并要求推送。该确认覆盖界面方向与原型，正式玩法接入按下一批实施与验收。

入口：`game-ui.html`。七个常驻系统入口，加掌门详情与院景营造工具；源文件按上文模块拆分，由 `build-game-ui.py` 内嵌样式和脚本。

- 人物、库存、工单、功法篇目与数值均为界面样例。研习、炼制和出行仅展示安排状态；正式世界步、规则、存读和数据迁移尚未接入。
- 已在 Chromium 1440×960 实点九个入口。已验证名册搜索与翻页、搜索焦点、人物与功法往返保持来源、换装后属性、服丹扣数与回血、行囊转公库记录、研习安排与撤销、制作工单增加/撤销、匠人技艺不足、损坏工位与缺料阻止、任务定位、切换出行地点、营造缺料与重复安排阻止。
- 已实看 820×1180 百艺竖屏，配方/材料/匠人/工位/队列与主要按钮可见。该证据是浏览器视口，未覆盖 iPad 真机。
- 山院画面沿用原型既有素材与 1440×900 构图坐标；地面、临时棚和人物在同一图层内等比缩放。
- 本轮未修改正式游戏源文件，未写正式存档，未部署 GitHub Pages。

实际运行截图作为本地评看记录保存；此目录提供可重建原型与素材。

## 字体与美术

标题、物名和按钮使用 Ma Shan Zheng；说明、数值与名册使用 LXGW WenKai。字体文件与许可在 `fonts/`；来源为 [Ma Shan Zheng](https://github.com/googlefonts/mashanzheng) 与 [LXGW WenKai v1.522](https://github.com/lxgw/LxgwWenKai/releases/tag/v1.522)。字体文件已本地载入并通过浏览器 font load 检查。

新增 `jade-cloud-frame.png` 使用内置 imagegen 生成，透明 PNG。素材来源与完整提示见 `ASSET-SOURCES.md`。其余山院、人物、丹炉、锻台和傀儡使用本项目原型既有素材。
