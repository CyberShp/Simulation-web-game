2026-10-12，用户确认本版画面并要求推送，决策编号 **U-120**。本目录保存可交互原型、源码、素材及字体许可，对应 SR-XF-029 的界面设计证据。

## 预览

在仓库根目录执行：

```sh
python3 docs/art/system-ui-20261012/build-game-ui.py
python3 -m http.server 8767 --directory docs/art/system-ui-20261012
```

打开 `http://127.0.0.1:8767/game-ui.html`。可使用 `?page=crafts` 直接查看百艺。

## 已确认的界面

底部七个入口为门人、功法、行囊、百艺、任务、山外、宗务；头像打开掌门，营造从院景进入。居中大窗口采用青玉云纹窗框，Ma Shan Zheng 书写标题、物名与按钮，LXGW WenKai 呈现正文与数值。

各页围绕名册、人物装备、传承树、配方工单、任务线索和地图组织。山院底图、临时棚及人物沿同一构图等比缩放。

原型中的人物、物资、配方及数值是交互样例，刷新后重置。正式人物、世界时钟、存档与玩法规则尚待接入；原型验证不关闭完整 SR/AC。

先在正式山院接入共同窗口和导航，完成真实门人名册、人物详情与掌门行囊。读取现有稳定人物与物品 ID，通过既有命令处理邀约、换装、服丹和搬运，并展示等待、完成及拒绝原因。重点验证同一人物往返、物品数量守恒、操作完成后的状态及存读。
