最终连接图需要覆盖 `(1536,374)` 处的正宽交集、整段上路、松下或松东阶面、旧画 y=0 拼接带及北台坡道。应先量出实际路面多边形、树干接地与遮挡轮廓，再把同一边界反算为米制。开通版本只在这条真实通路中切开北坡；其他北坡继续保留。

`geometry-candidate.json` 已固定用于制作前核心验算的作者线框：6条路心及各段0.6米半宽、台地多边形、北坡开口 `x33.672727..34.872727，y0..1`。台地最低世界 y 为 -18.0561；北界 -24 有足够余量。道路面按中心线矩形、圆形接头与端帽求并集。后续画稿应按该线框表现实际可走台面，量测发现的偏差须在同源数据中共同修正。

## 可逆映射接口与核验

纯候选接口在 `north-projection-candidate.mjs`：

```js
const north = createNorthCandidateProjection(previousToArt, previousToWorld);
north.toArt(worldX, worldY);
north.toWorld(artX, artY);
north.boundary(artX); // 旧 world y=0 的真实画稿曲线
```

旧世界 y≥0 正向直接调用原函数；反向在旧边界曲线南侧返回原函数的原值。负深度先沿用旧横向列到 y=-3，再于 y=-3..-5 过渡到北台列；此时深度已与横向独立。屋地的 x44→1376、x54→2176 对应 80px/米。这样保留 x1672..1673 处既有陡变，又使新世界北向移动保持画稿北向。

反向先在固定画稿 x 上求单调深度，再求该深度的单调横向列，两个有界一维求解不依赖初始猜测。左右边界混合回旧负深度，避免图块侧边的映射跳变。代码为文档候选，尚未加入运行模块。

`node docs/art/main-peak-library-20261018/audit-north-feasibility.mjs` 的当前结果：

- 9,750 个旧世界点的正向、反向结果逐值相同，其中 677 个旧点本来就处于负画稿 y。
- 20,352 个新点往返最大误差 `5.025e-14` 米，横向、固定画稿 x 的深度、固定世界 x 的纵向采样均保持正序。
- y=0 两侧 12 个接缝锚点的次序与往返成立。
- 原院至正式锚点的 193 段无核心碰撞失败、无画稿可走点失败，查询保留原状态。
- 6/8/10 米现有成人藏经阁共 18 个工位，在平移至旧域空地的室内夹具中，门至各工位路径和圆身碰撞成立。此项核验不代表北台已能营造。

完整数值、原路径、各级工位、源文件 SHA-256 位于 `spatial-feasibility-audit.json`。空间代理另做了独立的 18 工位核验，结果位于独立实施副本的 `library-existing-prefab-audit.json`。
