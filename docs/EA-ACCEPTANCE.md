# 模拟仙府 EA 独立验收记录

验收日期：2026-10-04。冻结基线：EA 1.0.1 / qa4。依据：`EA-ROADMAP.md`。此记录区分普通玩家流程、人工边界夹具、浏览器操作和真实设备，不以按钮存在或功能作者的声明代替完成证据。

## 当前结论

普通资源新档已通过「疗伤结缘 → 生产与传承 → 调查取筑基篇 → 炼丹筑基 → 四种准备 → 主动战斗 → 复仇收束 → 正式立派 → 两峰 → 30 门人 / 40 建筑」完整流程。另三个初始种子独立完成复仇和两峰。未使用调试资源、直接赋予功法、指定 NPC 行为、修改剧情或峰状态。

最终全仓 `node --test tests/*.test.mjs` 为 **162 / 162 通过**，其中新版 EA 126 项、旧版回归 36 项；独立集成 23 项。六个真实阶段状态的八页模板共 48 次执行通过，32 个 UI 直连命令均获应用派发白名单允许。30 门人 / 40 建筑 / 两峰继续运行六个游戏小时，通过资源、人物、岗位、存档与恢复一致性检查。桌面浏览器新建、疗伤、结缘、建造、刷新续档、双窗口接管、v4 迁移、最旧备份恢复、搜索焦点与窄视口部分页面已有实测记录。

上述证据证明已覆盖的逻辑可运行。真实浏览器、手机、数小时真人会话及朋友盲测的完成情况须分别记录，不能由 Node 模拟或模板 mock 推定。
