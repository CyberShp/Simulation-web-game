# 模拟仙府 · 历史EA设计基线

确认日期：2026-10-04。本文记录与玩家共同确定的方向；下列规划不等于全部已经实现。

## 定位与控制边界

单机、俯视 2.5D 仙侠门派模拟经营与角色养成。玩家只直接操控掌门，经营门派、提供条件、制定制度。弟子具有自己的志向、性格、记忆和有限精力。

- 玩家控制掌门移动、互动、修炼、功法学习、亲自游历；掌门可建造、收藏典籍、分配资源、发布差事、招募、任命与立规。
- 弟子自行判断接受差事、学习功法、使用丹药、善恶行为与守规意愿。制度影响动机和后果，不强制改变性格。
- 行为须有原因、机会、行动和后果；不能每隔固定时间无缘无故作恶。秘密事件被发现前不能公开全部真相。
- 掌门天资卓绝但不是绝对天赋上限。天才弟子可以超过掌门；师恩、认同和制度共同影响权威。
- 人物经历持久化，随机种子随存档保存，不能刷新重掷命运。

## 开局与第一大篇章《余烬立山》

暂用栖霞沈氏为家族名，后续支持随角色姓氏调整。家族为小型修行世家，依靠支脉灵地、灵植、丹药和护脉阵术生活。父亲为筑基中期阵师，母亲为筑基初期丹师。

主角修行数年已至炼气六层，天资卓绝，尚未获得成熟的筑基条件。地方小宗门赤嶂门的门主韩厉川（筑基后期）因自身灵地衰败，觊觎沈氏灵脉与护脉阵术。他长期通过交易与借贷渗透产业，收买外聘阵匠，在家族迁移前夜破坏山阵，并夺取灵脉。**2026-10-05更正（U-57）：本段此前的“伪造邪修罪证掩盖夺脉”方案已被用户撤回，当前为直接夺产，没有罪名或洗罪昭雪要求；以最新世界观记录为准。**

父亲逆转残阵挡住追兵；母亲以修为和生命代价发动遁行符送走主角。双亲身亡，主角携带部分传承，来到母亲早年在云岫山使用的偏僻采药别院。逃亡伤势只影响开局，不永久损伤资质。

带出的物品：完整基础炼气功法；残缺筑基篇；部分丹方与药理笔记；护脉阵法手札；记录往来的旧玉简；少量物资。炼气基础功法适性广，但拥有典籍不代表已理解、精通或能完整传授。关键筑基知识必须有可靠的获取路径。

| 段落 | 剧情与玩法 |
| --- | --- |
| 雨夜余烬 | 逃生、落脚、疗伤、保住典籍；掌门操作与基础生存 |
| 隐姓山居 | 救治山民、结交散修、恢复药圃与生产；自主门人和传承 |
| 旧账新证 | 调查账册、阵匠及被夺产业，获得可靠筑基线索；游历与筑基 |
| 削羽断援 | 解救知情者、截断敌方供应、揭露夺脉；制度、人才和经营兑现 |
| 重返栖霞 | 返回故地破阵，与韩厉川决战；清算直接责任人，取回遗物 |

篇章以复仇真正完成收束，不临时增加无限幕后黑手。结尾可选择重建栖霞故地或将传承带回云岫。此时首次分峰具有故事基础。敌方警觉随暴露与行动推进，开局不以无法应对的追杀倒计时压迫经营。

早期追随者各有自身生活目标：采药人与玩家因救治家人结缘；年轻散修需要安身和传承。加入山院不意味着必然赞同复仇。有人参战、有人守山、有人反对甚至离开，依人格与经历决定。

## 功法与学习限制

来源包括家传、交换购买、遗迹残卷、修士自带传承、后期研习改良。学习先满足接触、境界、基础、兼容和时间条件，再进行自主选择。

- 主修影响功体，稳定主修一门，转修消耗时间并受兼容限制。
- 辅修可相生或冲突，数量与修为、资质有关；普通弟子不能无成本精通一切。
- 术法、生产技艺需要练习；普通资质也能成长为可靠执事与熟练工匠。
- 功法拥有属性和路线标签；以标签相生相克为基础，特殊禁忌单独配置，不能将所有水火功法一概判为互斥。
- 书在府中、书可接触、有人练成、有人能授课是不同状态。封存规则可以被有动机且有机会的人违背。

## 阶段与分峰

人数为待平衡样例；正式门派制度与能力应有前置，避免循环锁。

| 大阶段 | 示例门槛 | 解锁方向 |
| --- | --- | --- |
| 结庐立足 | 掌门到达别院 | 基础居所、采集、生产、共同修行 |
| 山院初成 | 约 5 名弟子、稳定生产 | 藏书、讲法、简易炼丹、差事 |
| 正式立派 | 约 12 人、掌门筑基、基础传承成型 | 执事、完整门规、正式设施、对外交流 |
| 首次分峰 | 约 24 人、两条成熟传承、有主持者 | 支峰、分区、教学与资源预算 |
| 多峰宗门 | 后续规模、人才、修为积累 | 跨峰学习、协作、复杂事务 |

人口开放组织能力；掌门境界开放个人主持能力；门内人才与传承开放专业设施；资源和地势决定能否运行。达到里程碑获得资格，不自动免费建造。保留小而精的发展路线。

峰是传承和组织载体，前期同院共享少量功法。成熟导师、成型路数和愿意跟随的门人出现后，由掌门设峰。弟子依据适性、志向、关系选择归属。政治派系后置，不能把分峰等同固定敌对派系。

## P0 与 P1

P0：掌门角色；自主弟子；功法来源、兼容与有限学习；门规和后果；资源链与布局；阶段成长；经济节奏；开局和阶段主线；人物记忆；引导、存档恢复、兼容、移动端与长时间测试。

P1：变化的探索与访客事件；师徒、恩怨与关系深化；弟子个人支线；天气及世界反应；工作、行走、突破等表现完善。

不做多人联机。大规模战争、复杂派系和无限装备系统不列入首批。复仇可以先通过规模受控的探索、阵地交互和遭遇实现。
