# EA 1.3 独立验收矩阵

本矩阵区分公开命令通关、异常边界、浏览器画面及真机行为。正常游玩验收不得直接赋资源、修为、剧情 flags 或门人意愿；正常存档可以克隆，异常输入测试须标记其目的。单元通过不能代替画面与真机验收。

## 运行与证据口径

`node qa/ea-130-acceptance.mjs` 输出当前版本独立验收报告。完整通关由 `Player` 的公开命令完成，保留操作数、验证数和里程碑；扩展异常测试与正常游玩结果分别记录。

`node --test tests/ea-130-cross-system.test.mjs` 验证跨系统状态和恢复边界。实现接口尚未稳定时，不以跳过用例宣称通过。

浏览器由主 Agent 统一执行和记录，避免多个 Agent 干扰同一存档或会话。人工朋友无人讲解试玩、iOS/Android 真机锁屏/强退目前待用户设备验收；本环境不能宣称完成。

2026-10-05 最终集成：264/264 全仓测试、8/8 独立跨系统检查、48/48 实际管理模板、7/7 公开操作情景通过。报告版本 `1.3.0-ea`，生成于 2026-10-04T19:19:07.052Z；普通新档完成复仇、立派、两峰、30 门人和 40 栋建筑，1125 次公开命令、31 次整档校验、55 游戏日。最终七情景 Node 耗时 6.145 秒，不代表浏览器 FPS。

发现并推动修复的真实风险：互动意图保存旧入口造成设施搬迁后可能在原址完成；门人真实移动接入后，非工作活动每步重新路径搜索使完整验收超过两分钟。修复后跨系统脚本约 10 秒，七场景验收约 13 秒。这些属于 Node 逻辑验收耗时，不代表浏览器帧率。

浏览器实际覆盖与正式发布复验见 [EA-1.3-ACCEPTANCE.md](EA-1.3-ACCEPTANCE.md)。四地区站立区域、线索到场对白、移动控件尺寸、预览依赖闭包和人物档案等浏览器发现均已修复并复验。正式部署任务 37228022086 成功。390 像素移动视口通过布局检查；真机生命周期、文件磁盘往返和持续 FPS 未测，不归入通过范围。

八项跨系统证据包括：40 栋真实设施每条入口路径的线段碰撞检查；同类设施的精确 ID 与搬迁坐标；公开行走到旧入口后搬迁不能完成互动；停用/拆除取消互动；对白页码恢复与确认无奖赏；外出门人生活状态及家中排除；隐藏调度间隔不补计；实际同行者探索/战斗外观保持，真实伤害对应效果事件，冷却/障碍拒绝没有副作用。

## 风险复核

- 一套坐标必须覆盖渲染、路径、碰撞、入口、点击和存档校验；仅替换建筑投影不能算完成。
- 场景互动只负责让公开动作在合适位置发生；不能绕过原先的伤势、资源、传承、意愿和主线条件。
- 战斗效果须由真实伤害/技能事件驱动并有限保留；按血量差猜伤害容易在读档、治疗或多次命中时误播。
- 系统状态只有一个来源。院内动画、场景事件、按钮状态和存档不能各自拥有奖励或独立推进。
- 本轮正常通关耗时可作为逻辑性能数据；流畅度仍须在浏览器实际测量。
