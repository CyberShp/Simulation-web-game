# 云岫山院：可玩地形验证与验收

这次交付是一张独立可玩的山院样机。目标是验证可变同行人物、地形寻路、动态建筑占地、快速闪避碰撞和前后遮挡；不是将全部场景原型图或正式 EA 战斗替换完成。

在线入口：https://cybershp.github.io/Simulation-web-game/terrain-lab/?v=terrain-lab-1.0.4 。正式 EA 根目录内容不变。样机使用独立的 `xianfu-terrain-lab-v1` 本机体验数据，不读取或覆盖 EA 三个世界档位。

## 已实现的可玩内容

- 30 × 25 地图；主屋、门人居、医庐、可搬迁百工坊、院墙、树、岩石、山溪、石桥、药圃与试炼木人。东岸有台阶和高度层。
- 点选地面、五个地点快捷入口、地图平移、缩放和定位掌门；桌面方向键 / WASD 走路，空格闪避，手机宽度有画面按钮和可收起面板。
- 六名初始人物，可接纳至十人，任选至多两名同行。其余人物自行行走；拥挤时侧向避让，空闲人物给行人让路。
- 同一个人物 ID 和外观种子生成衣袍、配色、发式、体型与武器。面板头像、地图行走和试炼动作共用 `drawCharacter`。这是模块化二维角色，不是已完成的随机 3D 模型、骨骼绑定或美术资产流水线。
- 行走中搬迁建筑会更新占地并重新寻路；拒绝水面、桥面、台阶、斜坡、有人占地或封死关键通路的位置。新增人物也必须落在当前空地。
- 试炼木人提供落点预警、伤害、闪避和同行自主出手演示；攻击动作不能获得闪避保护。这不是完整战斗内容或胜败玩法。
- 「演示一圈」通过正常操作行走：归院 → 药圃（途中搬迁）→ 试炼场 → 试炼、换人、闪避 → 归院、恢复建筑。

## 通行与遮挡的实现边界

地面有明确的可走区域、高度和占地。A* 在世界坐标寻路，不能对角切过阻挡角点；人物半径为 0.26 格，移动和闪避沿整段轨迹采样，不能只检查终点。点击障碍会寻找附近可站立位置；不可达目的地明确失败。每次模拟推进还检查静态占地和人物间距，出现异常会暂停保留现场。

画面是分层绘制的实际 Canvas 场景：地面在底层，建筑、树、院墙、桥栏和人物按世界位置排序。桥的后栏与前栏分别参与排序。被遮挡人物可开启检查轮廓；人物名字作为独立覆盖层。碰撞以世界占地为准，树冠和屋檐的视觉遮挡不等于禁止树荫或檐外地面通行。

此图只有单层桥面通路，桥下水面禁止通行，不支持桥上、桥下两套可走地面同时重叠。未来精细素材要沿用相同占地、高度和遮挡规格重新验收；本轮结果不能保证任何新素材或复杂地形自动正确。

静态地面已缓存，只在建筑占地或检查模式变化时重绘。性能面板显示最近浏览器帧间隔 P95；该指标不是处理器耗时，也不代表手机硬件帧率保证。
