# Godot 二维绘画小院

山域成长的空间用途与阶段美术目标现由 [U-105 成长章程](SECT-GROWTH-PLAN.md)承接。本文件继续用于一殿、一道、两人的实际 Web 素材与交互验证；阶段原型不代替本表实机检查和用户美术认可。

当前按U-106以[五人开山院原型](art/sect-growth-20261009-v2/stage-01-5.png)对齐四处地标与人物比例。受验版本为`founding-courtyard-v2`，源码、网页证据和未验范围见[本批实机记录](art/FOUNDING-COURTYARD-2026-10-09.md)。

更新：2026-10-09。用户在 [U-104](design/DECISIONS.md) 明确“确认”制作方案：Godot 2D、固定斜俯视、统一绘画素材、二维人物动画与连续移动，先完成一殿、一道、两人的实际 Web 小院。整体美术参考沿用《山门与幻境》及已认可的[山院概念稿](art/reference/mountain-courtyard.png)。制作已获批准；实际美术效果和后续扩展标准由用户查看网页后确认。

## 本批范围与入口

| 对象 | 本批内容 |
| --- | --- |
| 一栋主殿 | 完整屋顶、墙门、台基与清楚入口；人物、门和建筑比例一致，封闭外观遵守 U-101。 |
| 一段山石道路 | 道路、山石、地面和植被组成统一绘画背景；可通行院地与路面对应人物脚点，背景山石区域不可进入，也不作为可交互营造。 |
| 两名人物 | 可辨认的外貌和服饰；二维行走、停止、转向与劳动动画，位置连续变化，身体、工具和脚步协调。 |
| 实际网页交互 | 点选主殿及两名人物、地面移动、镜头缩放与拖动、前后遮挡；反馈对应实际可见对象。 |

本批使用内置 imagegen 制作绘画素材，由 Godot 二维图层直接使用。当前采用与原型同构图的统一环境绘画、共享其坐标与纹理的建筑遮挡分片、两人64帧透明图集。主殿和人物可点选，山门屋顶与两侧实体分片保留门洞；碰撞仅围住实体占地，背景山石不可通行。生成图与 Godot 实际画面分别检查。导入后核对透明边缘、缩放清晰度、人物脚点、建筑基础锚点与图层遮挡，并保留素材来源和版本。

- 源场景：`godot/painted_courtyard/courtyard.tscn`
- 资源目录：`godot/painted_courtyard/assets/`
- 构建：`python3 tools/build-painted-web.py`
- 独立输出：`dist/painted-courtyard/index.html`
- 本地查看：启动 `python3 -m http.server 8080 --directory dist --bind 127.0.0.1`，打开 [二维绘画小院](http://127.0.0.1:8080/painted-courtyard/)。

这些路径是本批源文件和构建入口；实际构建、检查及部署状态查 [STATUS](design/STATUS.md)。

## 玩法与需求边界

样板仅有观察画面与动作所需的临时状态；原游戏规则、存档和三个正式档位保持。本批劳动是动作展示，正式生产仍由唯一模拟按真实到场、工位、材料与世界时钟结算。山石道路属于本批场景内容，正式铺路仍按原需求管理。后续玩法集成继续使用同一持久身份、空间与世界时钟，保留96米山院、2米营造格和0.5米导航约定。

本批为 SR-XF-003-AC-01/02 的空间与镜头、SR-XF-004-AC-01/02/03 的建筑外观、SR-XF-007-AC-01/03 的两人辨识与动作、SR-XF-029-AC-01/02 的输入积累局部证据。正式工位/生产、三人以上真人辨识、装备战斗、全部建筑阶段、旧档恢复与完整目标设备仍按原 AC 验收。样板结果不直接关闭完整 SR、AC 或 D/I/V/R。

U-103 的工程、素材、试验网页及证据保留在 [历史试验记录](ART-REALTIME-TRIAL.md)，当前制作从本文件的二维场景接续。
