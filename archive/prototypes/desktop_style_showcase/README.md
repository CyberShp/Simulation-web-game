# 云岫山院 · 双画风实机样板

U-129：在 macOS 原生 Godot 中自动播放同一段 72 秒流程，比较 D 国风 3D 和高清像素的实际表现。默认连续播放两版并循环；无需操作。按 Esc 退出。

这是独立的场景、人物与特效样板。角色、交战与冷却按导演时间线演示；正式游戏的存档、经营规则及战斗数值使用原项目。

## 自动流程

| 时间 | 画面 |
| --- | --- |
| 0–11 秒 | 山院、主殿、侧院与松溪河桥 |
| 11–21 秒 | 建筑近景，木构、瓦脊、台阶与投影 |
| 21–32 秒 | 掌门近景、连续行走与衣装 |
| 32–44 秒 | 剑击、飞剑、护盾与雷印 |
| 44–62 秒 | 30 人同场演示、范围预警与 12 格快捷区 |
| 62–72 秒 | 日光转为暮色，观察灯笼与材质 |

## 运行

用 Godot 4.6.3 打开本目录，运行主场景。终端也可直接启动：

```sh
/Applications/Godot.app/Contents/MacOS/Godot --path prototypes/desktop_style_showcase
```

单独播放一种：在命令末尾加 `-- --style=d` 或 `-- --style=pixel`。

## 制作方式

- D：真实三维建筑、骨骼人物、空间灯光、阴影及三维特效。
- 高清像素：同布局三维场景使用像素输出与相应材质；人物经共享低分辨率视口渲染为像素精灵；像素特效采用分段运动和块状碎片。本版用于评看这种制作方法的效果，人物动画由模型生成。
- 建筑与人物基础模型来自本仓库自制 Blender 源文件 `scripts/art/build_hall.py`、`scripts/art/build_characters.py`。环境、灯光、演示导演与特效在本目录。
- 72 秒、30 人、12 个主动快捷位均为本次样例配置，不定义正式地图大小、人数上限或修行数量上限。

原生运行记录、录像、截图和设备指标记录在本批交付文档中。引擎 Movie Maker 生成的录像应标明离线录制；运行帧率以单独实时播放的记录为准。
