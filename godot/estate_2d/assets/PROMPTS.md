# 云岫旧别院绘画素材

本目录 PNG 使用内置 `image_gen` 制作。统一要求：1536×1024、固定斜俯视、精致仙侠手绘游戏画面、同一春季光线和人物比例。建筑、田地与工位单独透明出图，保持封闭建筑外观；地面画稿不预先画出尚未营造的设施。

| 当前素材 | 最终提示词要点 |
| --- | --- |
| `estate-ground-v2.png` | 在原山院构图上保留古松、右侧泉水、远山、下方入口与上方主屋位置；把大面积整齐铺石、礼制纹章、花坛和完整栏杆改成荒地、杂草、断石与狭窄旧路；左右和下方四块地保持空置，作为将来营造的位置。只生成地面与背景，不生成建筑、人物、农作物或界面。 |
